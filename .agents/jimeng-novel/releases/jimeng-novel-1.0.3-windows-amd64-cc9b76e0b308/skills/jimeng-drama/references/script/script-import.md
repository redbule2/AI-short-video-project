# 导入剧本 / 小说：原文 → 统一格式 + 反抽设定与大纲

用户上传或粘贴剧本、小说、梗概、分镜，或说「按我的本子做」时用；往已有项目追加新集也用。

## 1. 原文只搬运

- 原文存进 `source/`，文件名不改，粘贴的存成 `source/source_01.txt`；之后不再改这个目录，它是对照台词的唯一依据。
- 你只做判断：每集起止行、每行是场头动作还是台词、谁在说。正文按行号从原文切片复制（脚本或文本工具），不凭记忆重打，重打会悄悄改字补字。
- 台词逐字保留，错别字、方言、语气词、标点都不改，明显错别字列进待确认清单。
- 转完把 story/ 的台词和原文逐行比对，差异应为 0；有差异重新切片，不手工修补。
- 导入稿默认只诊断，用户要改、要润色时才按 `episode-writing.md` 改，先说明范围。

## 2. 判断输入类型

| 类型 | 识别信号 | 处理 |
|---|---|---|
| 多集剧本 | 有「第X集」或场次头，有台词行 | 拆集 → 转格式 → 反抽 |
| 单集剧本 | 只有一集 | 见第 6 节 |
| 小说 | 大段叙述，台词在引号里，没有场次 | 改编，见第 6 节 |
| 梗概体 | 每集不到 300 字，没有场次和台词 | 当大纲输入，见第 6 节 |
| 分镜或镜头表 | 有镜号、时长、景别、画面描述 | 见第 6 节 |

## 3. 拆集

原文有分集标记时：按「第X集」「EP」「001」这类标记切，集号取标题里的数字（「第十三集」→ `E13`），不按出现顺序重编，免得和用户手里的稿对不上。重复的集标题以后出现的为准；跳号如实报告，不自己补。

原文没有分集标记时：集数和单集时长用户给了就照用，没给就按内容量取合理值并写进 README.md 的假设。每集字数上限取 `episode-writing.md` 第 3 节「全文字数」对应档，允许超 20%。

- 切点优先级：悬念或冲突的落点 > 时间跳跃 > 场景切换 > 段落分隔。
- 不在一句台词或一个动作中间切；上限前找不到语义断点，就在最近的场次边界切。
- 某集超过时长上限 1.5 倍时标出，问用户拆成两集还是保留（长集花费更高）。

## 4. 转成统一格式

目标格式见 `episode-writing.md` 第 1 节。只换标记，不动文字：

| 原文常见写法 | 统一成 |
|---|---|
| 【SCENE】/ 场景： / 1-1 日 外 | `## 场N 日/夜 内/外 地点`，下一行 `出场：` |
| （括号动作）/ 【动作】/ 无标记的动作行 | `△ ` 加原文 |
| 心声 / OS / 内心 | `人名（os）：` |
| 画外音 / 电话 / 广播 / 系统提示音 / 旁白 | `人名（vo）：`；无说话人写 `旁白（vo）：` |
| 字幕 / 话框 / 手机文字 | `【字幕：原文】` |
| 回忆 / 闪回 | `【闪回】…【闪回结束】` |

- 动作和台词同行时拆成两行，文字和语气括号不动。
- 场头缺日/夜或内/外从上下文推断，推不出的列进待确认清单。`出场：` 按实际有台词或被拍到的人补全。
- 格式里没有的标记（【下集预告】【结尾钩子】）和作者批注不进正文，钩子和预告写进 outline.md 对应集。
- 拍不出来的段落（心理描写、第一人称叙述、总结性叙述）原样放进 `△` 行，列进可拍性问题清单并附建议（改成 os、vo、闪回或删掉），用户同意后才动。

## 5. 反抽 setting.md 和 outline.md

资产和分镜都依赖这两个文件。只归纳原文里有的，不替作者补设定。

- setting.md：人物小传只收有台词或关键动作的角色；同一人的全名、昵称、称谓合并成一人、别名全记下，否则下游会做两套形象。原文没交代的字段写「原文未交代」。卖点、主线引擎、关系引擎可以从剧情归纳。
- outline.md：阶段、梗概、打点只按实际发生的写；结尾钩子按 `outline.md` 第 4 节如实评级，评出「弱」也照写，作为建议，原文不改。
- 出场、场景两行要特别仔细：同一地点的不同叫法统一成一个名字，写明日/夜。

## 6. 输入不完整时

- 只给了某一集：按用户说法定集号（独立短片就是 E01，系列里的第 N 集就是 EN），不编造其他集；setting 和 outline 只写这一集推得出的内容。要补前后集时按 `outline.md` 续写规则加集。
- 只给了分镜或镜头表：反抽人物、场景和梗概即可，用户没要剧本就不倒推 story/E0N.md；分镜整理见 `references/shots/segmenting.md`。
- 只给了梗概：说明这还不是能拍的剧本，整理成 outline.md 后按 `episode-writing.md` 写正文，标明哪些是新写的。
- 小说：集数、单集时长、忠实度用户没说时取合理默认（忠实度默认贴原著），写进 README.md，然后反抽 setting → 按集分配章节写 outline → 写正文。原著对白和金句优先原样用，叙述改成可拍的动作。
- 追加新集：集号接着编，已有的集不覆盖；用户要覆盖时先说明哪些下游产物（大纲条目、cast/ 图、shots/、视频）受影响。

多集剧本的拆集、转格式、反抽可以全剧一次做完，不花钱；往下游做图和视频的范围按铁律 1 报价确认。

## 7. 交付报告

1. 输入类型和处理方式
2. 拆集表：`集号 | 起止行 | 首句 | 字数 | 估算时长 | 结尾落点`
3. 台词逐字校验结果
4. 待确认清单：推断的场头、错别字、重复或跳号的集、做了哪些假设
5. 可拍性问题清单
6. 反抽出的设定摘要（主角、对立面、核心关系、场景列表）

可顺带用 `script-review.md` 诊断，只给建议。
