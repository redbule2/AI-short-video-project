# 分集大纲：setting.md → story/outline.md

写分集大纲、加集、改梗概时用。题材标准沿用 `story-setting.md` 开头：强钩子、反击、爽点节奏只用于爽剧/强对抗，其他题材按情绪、关系或线索推进，保留有作用的留白，不为凑数加事件。

## 1. 阶段规划

| 集数 | 结构 |
|---|---|
| ≤ 4 集 | 不分阶段，一行全剧弧线：E01 建立人物与期待 → 中间推进事件或关系 → 末集兑现与收束 |
| 5-29 集 | 3 阶段：建立 15-25%，对抗 45-60%，收束 20-30% |
| ≥ 30 集 | 4 阶段：建立 15-20%，发展 30-40%，升级 25-30%，结尾 15-20% |

每个阶段写：核心定位；阶段内情节（每段 ≤ 5 集，写清情节和关系变化）；阶段结局（大爽点或大反转收住这一段，同时引出更高层级的危机）。

## 2. 单集容量

| 单集时长 | 核心事件 | 打点 |
|---|---|---|
| ≤ 30 秒 | 1 个 | 1 个爽点或反转 + 结尾钩子 |
| 31-90 秒 | 1-2 个 | 1-2 个打点 + 结尾钩子 |
| > 90 秒 | 2 个 | 2-3 个打点 + 结尾钩子 |

3 个以上主要事件塞进一集，每件事只剩一两句台词，冲突演不出来；装不下就拆集或建议加集。

## 3. 每集一节

```
## E01 集名
- 梗概：……
- 【开场钩子】……
- 【爽点/反转/冲突】……
- 【结尾钩子】……（强·证据）
- 出场：女主、男主；场景：老宅客厅（夜）
```

- 梗概：主角主动做了什么 → 阻碍 → 结果 → 局势或关系怎么变。怀疑、调查、背叛、突然出现、改变立场这类关键行为，写出「触发依据 → 人物判断 → 行动目的 → 结果」，否则剧本阶段落不成动作。
- 【开场钩子】：本集第一个画面或第一句话里的冲突。E02 起是上一集结尾钩子的「下一拍」，即后果或紧接着的动作，不回顾。
- 【爽点/反转/冲突】：只写真实发生的打点，至少 1 个商业打点（爽点、反转、冲突、互动、卡点、期待点），凑出来的标签会误导剧本。
- 【结尾钩子】：末尾括注强度和类型，分级见第 4 节。
- 出场 / 场景：人名与 setting.md 一致；场景写「地点（日/夜）」，同一地点全剧一个叫法，这一行是整理 cast/ 的直接输入，叫法不一会被当成两个场景。
- 集名：从本集最大的反转或钩子提炼，4-12 字。

E01：开场事件里同时交代主角的身份、性格和处境，靠事件而不是旁白（「升职宴上，老板当众宣布把她调去做保洁」）；埋下核心期待点；爽剧里主角至少完成一次实质反击；结尾用强钩子。

末集：主线和核心关系闭环，结尾钩子写「无，故事收束」；用户要续集时留一个指向新阶段的强钩子。

角色首次出现时，同一句里写明身份和与主角的关系，否则像作者硬安排的工具人。

## 4. 钩子强度

| 强度 | 判定 | 用法 |
|---|---|---|
| 强 | 直接威胁主角的生命、核心目标或关键关系，停在最高点：证据将揭、身份将认却被打断、人已翻进窗户 | E01 和每个阶段末集用强钩子 |
| 中 | 有具体威胁或行动牵引，观众清楚下一集在等什么（「审计组明早九点进场，带队的是她」） | 可以用 |
| 弱 | 只有气氛没有指向（「神秘人在暗处一笑」「五年后」「更大的危机即将到来」） | 不用，观众没有理由点下一集 |

强、中钩子落在生命、目标、关系、身份、证据五类之一，并在下一集【开场钩子】里兑现或推进。

## 5. 节奏规则

- 每集：至少 1 个商业打点 + 中等以上结尾钩子。
- 每 2 集：至少 1 次有效互动（关系温度或权力位置因事件变化，普通对话不算），至少 1 个强钩子。
- 每 3 集：至少 1 次反转或局势翻转。
- 前 3 集：种下期待点，兑现第一个实质爽点。
- 爽点阶梯：口头反击、小证据 → 资源反击、身份露一角 → 公开审判、全面清算，后一个不低于前一个。
- 防同质化：同一冲突结构（施压 → 反击 → 完胜）不连续 3 集；新冲突至少换掉对手、规则、代价、场合中的一项。
- 反转要有铺垫：之前至少 1 集出现过线索（一个道具、一句话、一处异常）。
- 信息差记账：写明投放集和回收集。
- 爽点要有铺垫和代价：手段前文出现过，结果有实质代价；口头互怼、反派被吓退不算爽点。

## 6. 续写（加集）

- 从最后一集的结尾钩子接着写，集号往后编。要改旧集先说明影响哪些已写的剧本、已出的图和视频。
- 不重启设定、不把旧冲突换名重演；新增部分带来新目标、新代价或新关系后果。
- 一次加 5 集以上至少 1 个阶段性大反转或大爽点；加 10 集以上回收 1 个旧信息差、投放 1 个新的。
- 优先沿用已有角色，README.md 同步集数。

## 7. 自检与交付

集号连续、数量和 README.md 一致；第 2、3 节的容量和 E01 要求、第 5 节的节奏规则都满足；爽剧非末集是中/强钩子；出场人名和场景名全剧统一。

交付时用表概括：`集号 | 核心事件 | 爽点/反转 | 结尾钩子（强度·类型）`，并指出同质化风险最高的几集。多集的剧大纲连同 E01 正文一起交给用户，确认后再写后面各集（原因见 SKILL.md「授权」）。
