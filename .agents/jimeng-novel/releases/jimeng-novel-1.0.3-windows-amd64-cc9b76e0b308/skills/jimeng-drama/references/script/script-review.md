# 剧本自检与评分

交付自己写的剧本前自检；用户要评估、诊断、打分，或导入剧本后诊断时用。

题材标准沿用 `story-setting.md` 开头：强钩子、大爽点、笑点与冲击频率只适用于爽剧/强对抗。其他题材 D2 看下一集期待（末集看收束）、D3 看情绪兑现、D4 看发现与变化、D5 看题材趣味、D6 看节奏是否服务表达、D8 看目标与阻碍；无对白作品 D7 标不适用，剩余权重归一化。没有反派、笑点或密集冲突不扣分。

## 1. 怎么评

1. 一集一评；评多集时再加一轮跨集检查（第 5 节）。
2. 先查第 2 节硬门槛，命中就按规定封顶。
3. 逐维打分，先引原文证据（≤ 40 字）再给分。没有证据的维度最多 5 分。
4. 作者标的【爽点】【钩子】不算数，只看实际发生了什么。小口角、小占便宜不算爽点。
5. 1-10 整数分，不扎堆给 5-7 的安全分。
6. 加权总分 = Σ 维度分 × 权重，满分 10。≥ 8.0 爆款潜力，6.5-7.9 可上线，5.0-6.4 需打磨，< 5.0 不可用。

自己写的稿：命中门槛、总分 < 6.5，或 D1、D2、D5 任一 < 6，就先改再交，最多改 2 轮，仍不达标就如实说短板。自评分系统性偏高、越改越虚涨，对用户只说具体问题和改了什么，不报自评分。

用户导入或已确认的稿只诊断，给证据和前 3 条修改建议，用户要求才评分。

## 2. 硬门槛

| # | 条件 | 后果 |
|---|---|---|
| G1 非剧本 | 只有梗概，缺可拍的场次与动作，或仍是小说叙述体（不按字数判） | 总分上限 4 |
| G2 合规 | 明确违规：未成年人性暗示、血腥或犯罪手法教学、美化违法 | 标 `blocked`，不打分，重写 |
| G3 同质化 | 同一冲突结构连续 3 次以上，对手、手段、结果都没明显变化 | D3、D6 上限 5 |

字数偏离 `episode-writing.md` 第 3 节的区间只作提示，不封顶、不触发修改；有叙事作用的静默和情绪停留不当空白删。

## 3. 十个维度

| # | 维度 | 权重 | 不合格 | 合格 |
|---|---|---|---|---|
| D1 | 开场抓力 | 12% | 先交代世界观、天气或日常，30 秒后才有冲突 | 第一句台词或第一个画面就是冲突、危机或强反差，10 秒内交代清主角处境和对立面 |
| D2 | 结尾钩子 | 14% | 平收，或只有气氛悬念 | 停在生命、目标、关系、身份、证据的最高点，下一集开场绕不开 |
| D3 | 爽点兑现 | 14% | 主角一直在忍、在解释；金手指突然生效，前无铺垫后无后果 | 至少 1 个大爽点，手段有铺垫，结果有实质代价，强度高于上一集 |
| D4 | 反转与信息差 | 10% | 一条直线，或反转靠巧合、凭空冒出的设定 | 意料之外、情理之中，前文埋过线索，反转后局势或关系实质改变 |
| D5 | 梗与趣味 | 14% | 全程正经，或硬塞过时、跟人设不搭的梗 | 1-2 句让人想截图的台词或梗，从人物身份和处境里长出来 |
| D6 | 节奏密度 | 12% | 有明显的说明戏，信息重复、绕圈子 | 每 15-20 秒一个新事件，每 3-5 秒一个冲击点，没有废台词 |
| D7 | 台词质感 | 10% | 书面腔、套话、念设定、用 os 解释情绪 | 短句口语，有口吻和潜台词，遮住人名也认得出 |
| D8 | 人设与冲突张力 | 6% | 主角被动旁观；反派脸谱化、动机模糊 | 主角第一场就做决定；反派动机具体；关系里有能持续消耗的张力 |
| D9 | 连贯与逻辑 | 4% | 同一动作发生两次，状态前后矛盾，资源凭空出现 | 集内集间的因果、位置、伤情、知情程度都对得上 |
| D10 | 可拍性与格式 | 4% | 心理描写、第一人称叙述、一场塞几段时空 | 场头、出场、△、os/vo 符合 `episode-writing.md` 第 1 节，每句都能拍 |

## 4. AI 套话清单（D7 扣分依据）

写的时候就避开，自检时逐条搜：
`眼底闪过一丝` `嘴角勾起一抹` `声音很轻` `一字一顿` `目光微动` `这一次，换我` `空气仿佛凝固` `时间仿佛静止` `心中五味杂陈` `千言万语化作` `意味深长地` `不知为何` `莫名的情绪`

以及：互相介绍双方都知道的设定；集尾用 os 总结「我终于……」；句句完整主谓宾；多个角色口吻一样。

## 5. 跨集检查

- 钩子兑现：上一集钩子在下一集第一场是否兑现或推进。
- 同质化：把每集「冲突结构 / 对手 / 手段 / 结果」列成表，查是否命中 G3；集尾是否重复同一种钩子模板。
- 爽点阶梯：各集爽点强度是否在上升。
- 状态连续：位置、伤情、服装、知情程度不断。
- 命名统一：同一个物件、地点、组织全剧只用一个名字，下游资产和 prompt 按名字绑定，换个叫法就成了另一样东西。
- 人物时间线：逐场列出每个主要角色此刻在哪、怎么到的，不能同时出现在两处或没交代就换地点。自己能定的直接改并说明；要动用户原文或有两种合理改法时列出来让用户挑。
- 没提前演后几集的事。

## 6. 常见问题与修法

台词和可拍性的修法见 `episode-writing.md` 第 6、8 节。

| 问题 | 识别信号 | 修法 |
|---|---|---|
| 平淡没梗 | 找不到能截图的台词 | 回到反差人设，让主角用职业或身份语言处理本集冲突；补具体物件梗或信息差梗 |
| 拖沓 | 按 5 秒切格有连续空格；有寒暄、复述、抒情 | 删无功能的句子；合并做同一件事的场；一个动作替代一段解释 |
| 同质化循环 | 连续几集「施压 → 反击 → 完胜」；集尾同一镜头 | 换对手、规则、代价、场合至少一项；改成反转集或关系集；换钩子类型 |
| 衔接出错 | 已离开的人又离开一次；伤口凭空消失 | 动笔前重读上一集，列人物状态清单；E02 起第一拍只写钩子的下一拍 |
| 爽点没铺垫没代价 | 能力或资源突然出现；反派一出场就输 | 手段提前一集露一角；给反派一次小胜；结果加实质代价 |
| 钩子弱 | 开场先铺世界观；集尾是气氛或泛泛预告 | 最强冲突提到第一条 △；集尾往前挪，停在证据将揭、身份将认、人将出事的那一秒 |
