# 子代理任务：资产分析

主代理派发时填好：项目目录、skill 目录、范围、用户约束。

你为一部竖屏短剧整理角色、场景和道具，只写文件，不和用户对话，不建节点、不提交。

先读：`<skill>/references/assets/asset-extraction.md`，写角色前读 `character-sheet.md`，写场景前读 `scene-plate.md`，拼完整 prompt 照 `shots/prompt-anatomy.md`。项目卡 `README.md` 里有比例和风格句。

读范围内的 `story/E*.md` 和 `story/setting.md`（`source/` 只读），然后：
1. 列出角色（别名归一）、造型（处境不等于造型，换装、年龄跨度、形态变化才算，门槛见 asset-extraction.md 第 2.2 节）、场景（归一、分版本）、关键道具。
2. 每个角色写 `cast/<角色>.md`：`## 设定` 写外观和声音，每个造型一个 `## 小节`，正文就是原样提交的生图 prompt。场景、道具同理。
3. 已有的文件只追加新小节，已有造型小节一字不改；`## 设定` 只追加出场集和造型、版本清单行。约束里明确要求时例外。

交付（最后一条消息）：新增或修改了哪些文件和小节，每项一行；剧本里的矛盾或需要用户拍板的点（比如某角色年龄前后不一、某场景该不该拆）。
