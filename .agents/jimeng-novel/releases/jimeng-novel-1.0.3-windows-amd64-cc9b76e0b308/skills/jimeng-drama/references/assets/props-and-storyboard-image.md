# 道具图、分镜图、分镜草稿

关键道具设定图，以及两种可选的视频前置图。

## 1. 关键道具图

只给 `cast/<道具>.md` 里的道具出图（门槛见 `asset-extraction.md`），存为 `cast/<道具>.默认.png`。

- 画初始状态（合拢、未拆封、入鞘、熄灭、完整），打开、碎裂交给视频；剧本把异常状态设为常态的（作为物证的半截断簪）按设定画。
- 画出剧情要用的那一面（会亮屏的手机画屏幕，要读的信画正面），两面都出镜就正反并排：视频模型照图上看得到的面编另一面，背面会被当成屏幕亮起来。
- 纯白无缝背景，浅色物（白瓷、白玉、白纸）改浅中性灰免得融进背景。只画本体，没有手、人、展示台、场景。
- 比例 1:1；剑、卷轴这类长条物 16:9。
- 带字的道具（票据、信、证件、屏幕）按 `shots/video-prompt.md`「画内文字」处理，其余部分写成干净的样子（「泛黄的空白纸面，只有一道深蓝边框」）。

prompt 结构：风格句 + "一件道具的设定图：{描述}。道具单独完整地摆在{纯白｜浅中性灰}无缝背景的中央，从斜上方约 45 度俯视，主体完整入画、四周留出空白，约占画面六成。一个来自左上方的柔和主光，物体下方压着一道贴地的接触阴影。" + 2 处材料加表面处理 + "画面里只有这一件道具。" + 媒介重申句。

状态变体（剧本明示且跨多段出现）：以初始图为参考，记为新小节（`## 碎裂`），在描述后加"保留{{别名}}中仍然成立的本体造型、材质、比例与部件细节，只改变为：{状态}。"下一个状态仍以初始图为参考，从变体再派生会越改越走样。

## 2. 分镜图（可选）

视频的额外参考，锁住构图、站位和动作阶段；额外付费，还可能把视频锁死在静态构图上，用户想要才做。

- 一段一张，图内按动作阶段分 1–4 格，通常一个镜头一格，多了就合并相邻小动作。存为 `shots/<集>.<段>.png`（key 用 `shots/E01.S01`、`--out shots/`，不和视频的 `E01/S01` 撞）。
- 参考：出场角色的定稿图、场景对应版本、必要时道具，条数不超过模型上限（看 `model describe`），超了按"有台词的角色 > 场景 > 其他角色 > 道具"取舍。
- 每格是一幅完整的项目比例画面，总图比例取模型支持的最接近值：

| 格数 | 9:16 项目 | 16:9 项目 |
|---|---|---|
| 1 | 1×1，9:16 | 1×1，16:9 |
| 2 | 1 行 2 列，约 1:1 | 2 行 1 列，约 1:1 |
| 3 | 1 行 3 列，约 16:9 | 3 行 1 列，约 9:16 |
| 4 | 2×2，9:16 | 2×2，16:9 |

一行多格时写明"左右并排成一行"，不写模型常把它们上下叠起来。

正文剥掉三类内容：台词、字幕、屏幕文字（会被画成字幕或气泡，说话写成"开口说话，下颌收紧"，屏幕写"手机屏幕亮着"）；外貌描述（交给参考图）；画质词。

prompt 结构：风格句 + "同一个连续片段的分镜图：按时间顺序分成 N 个阶段，排成 R 行 C 列等大的格子，阅读顺序先从左到右、再从上到下；每格是一幅完整的{比例}画面，相邻格之间只有一道极细的接缝；所有格子同一时间、地点、人物、服装、光线方向，只有景别、视点与动作按阶段变化" + 每个参考别名一句用途（角色保持长相服装、不照抄参考图的姿势构图；场景保持结构陈设和光向）+ 逐格"景别，角度；谁在哪个锚点物旁、朝向哪里、在做什么" + "画面里只有画面本身，片名、字幕与台词在后期剪辑时添加。" + 媒介重申句。格子写这一阶段最有代表性的一刻；运镜写不进静帧，只写起止取景。视频 prompt 怎么引用分镜图见 `references/shots/prompt-anatomy.md`。

## 3. 分镜草稿（火柴人，可选）

便宜，不带参考不画脸，只用来和用户对构图、站位、动作顺序，不当视频参考。模板保持短：

```
分镜草稿：{R} 行 {C} 列等大的格子，按时间顺序先从左到右、再从上到下，每格是 {项目比例} 画面。白纸上的黑色铅笔线速写。每个人都是火柴人：头部是一个没有五官的圆圈，躯干与四肢各是一根单线，姿态能看出动作；主角的火柴人用唯一的一种强调色 {颜色} 画出，其余全是黑线。环境只用几根线勾出墙角、门窗与锚点物的轮廓。
第 1 格：{景别}，{谁在哪、做什么}。
第 2 格：……
```

往末尾追加逐项规则（"注意 X""确保 Y"）会诱发一格里再拆小格；哪格有问题只改那一格的描述。
