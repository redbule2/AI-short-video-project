# 资产整理：角色、造型、场景、道具

从剧本整理角色、造型、场景、道具，写成 `cast/*.md`；新增一集、用户给了自己的图时也用。

## 1. cast 文件的写法

每个角色、场景、关键道具一个 md。`## 设定` 不提交，是外观唯一来源：分级、别名、出场集、外观白描、身份标记、音色、易混差异，以及造型或版本清单（一行一个：名字、基于哪个、变化短语、出场集，如"西装：基于默认；变化：…；E03–E05"）。之后每个造型或版本一个小节（`## 默认`、`## 西装`），正文是原样提交的完整 prompt，备注写进去会被画出来。改外观先改 `## 设定` 再同步小节。定稿图 `cast/<名字>.<造型>.png`。

整理完给用户一份摘要清单：角色 × 造型 × 出场集、易混组和差异点、场景 × 版本、道具。

## 2. 角色

### 2.1 名单与分级

- 别名归一：小名、"X 小姐"、全名合并成一个角色，只凭同姓、同职业不合并。
- 分级决定做多少图、写多长：主角（几乎每集出场）、配角（有名有台词、跨集）、次要（只在一两场）、群像（不需要跨镜头认出个人的路人、宾客，只做群像图）。群体里有人后面有独立戏份就单列。

### 2.2 造型：基础造型 + 变体

- 每个角色一个基础造型 `## 默认`，取出场最长、最有代表性的常态；伪装、回忆、穿越前的首次出场不当基础。
- 所有变体都基于基础造型、只挂基础造型的定稿图，从变体再派生特征会一代代漂移。
- 变体门槛：物理外观确实变了、新样子至少在 2 个片段里保持，并满足任一条：整套服装换成另一种场合或身份（婚礼礼服、制服、宫装换便装）；年龄阶段跨越；形态变化（人形与兽形）；核心身份配饰得失且长期保持（摘下婚戒）。
- 通常 0–2 个变体，超过 3 个逐个重核门槛：造型越多，付费图和挂错参考的机会越多。

处境不是造型：淋雨、受伤、哭泣、汗湿、衣服撕破、头发凌乱、醉酒写进视频 prompt，剧情要看清、跨几段保持的另出状态图（见 `shots/segmenting.md`「其余绑定」）。身份转折的前奏（被背叛后淋雨）仍是旧造型，剧本写明换装、以新面貌登场才启用新造型；神态变化、同风格换色换件、临时加减外套、只出现一个镜头的造型也不建变体。

### 2.3 变化短语

- 只写变了的部分，按 发型发饰 → 面部 → 上装 → 腰间配饰 → 下装 → 鞋履，逗号分隔。
- 只写变化后的样子，"不再穿""取消了""由 X 改为 Y"会把旧东西召回画面。
- 年龄跨越：变年轻写幼态（脸更圆短、眼睛占比更大、五官位置偏低、鼻梁偏低平）；变老写骨点外显（颧骨、下颌角更突出）、皮肉松弛、纹理加深。

示意：`盘发，发髻左侧插一支金质步摇，正红色缎面立领旗袍，前襟金线盘扣，裙摆及踝，酒红色缎面低跟鞋`

## 3. 全剧角色区分

写外观前一次看全部主角和配角：模型会把同龄同性别的人画成同一张脸。

1. 易混组：性别年龄段相近，且常同场、同职业阶层、是亲属或被拿来对照（情敌、替身）。
2. 每组至少两项独立、稳定、不只是颜色的差异：骨相与脸型比例、发型轮廓、体型身高、服装廓形、主色明度、标志配饰（眼镜、耳饰、腕表）。
3. 辨识细节：主角和配角各从剧本写到的身份、经历、习惯、性格推出 1–2 个小细节，要说得出由来，同剧角色不共用同类细节。落在配饰、发型局部、服装的面料配色与穿法上，至少一个在全身格里也看得清（在头颈、躯干上，有颜色或轮廓）；不由性格推骨相。细节少而小，不改变一眼读出的身份、阶层和年龄，整体造型照样按身份做足；多了模型会堆砌、放大。辨识细节要每次出图都稳定，所以不放在手指上、不靠驼背歪肩这类体态（手和身体比例最容易崩），也不用黑眼圈、淤青、伤疤血迹、病态肤色、浓妆这类皮肤状态（常被画成脏污、拉低脸的质感）；剧情里的伤痛疲惫是处境，按 2.2 处理，原文写明的疤痣、题材公认形象的标志特征（经典角色的面部标记）按第 4 节身份标记写，不算编前提。细节写进外观白描对应部位，并在 `## 设定` 的「易混差异」一行点名。
4. 声音也拉开，不只靠音高。阵营用服装、配色、配饰、姿态表现，不靠丑化五官、伤疤、异色瞳，也不把善恶等同于美丑。双胞胎、替身保留相似，只在允许的细节上区分。

## 4. 外观白描（`## 设定` 正文）

不带风格的物理描述，一段连贯中文，从头到脚：

1. 外表年龄、性别、身高体型。
2. 族裔加肤色底调，如"东亚汉族，肤色偏暖的浅象牙色"。不知道就按剧本地域写，不凭名字或阵营猜。
3. 骨相：3–4 组相对比较，如"颧弓略宽于下颌，下颌角转折偏低、弧度圆缓""中庭略短于下庭"。
4. 五官：眉形、眼型与瞳色、鼻、唇，加"双唇自然闭合，目光平视"。
5. 发型：长度、发色、分线、束法，碎发、鬓角。
6. 身份标记：解剖坐标写位置和形态，如"左眼外眼角下方约 1cm 处一颗直径约 2mm 的浅棕色痣"，左右以角色自身为准。旧疤写成「愈合后与周围肤色接近、与皮肤平齐的浅色旧疤」，只写「疤」常画成新伤。
7. 服装从上到下：形制、面料、颜色、工艺、新旧；配饰写明戴在哪，道具挂在身上不拿在手里；最后写鞋。

篇幅：主角 150–300 字，配角 100–200，次要 60–120。

文学词换成可见特征（"气宇轩昂"写成"下颌线清晰、脊背挺直"）；锥子脸、网红脸会画成模板脸。不写风格、光线、背景、镜头词和临时状态（汗、泪、血、表情、动作），它们会被拷进每个镜头；不加原文没有的伤疤和病态特征。

服装合年代、地域、身份，落魄用磨损、褪色、材质降级表现，不用暴露。原文写明的外貌逐字保留，没写的可以定案并标"设计补充"，不补造经历。

## 5. 音色（`## 设定` 里一行）

按固定顺序写成一句：`[听感性别]声，[感知年龄]音色，音调[高/中/低]，音色质感[物理质感]，声音[穿透力/颗粒感]，发音方式[习惯]，[气息感]，[特殊特征/无特殊声音特征]，吐字[清晰度与节奏]`

用可执行的词（胸腔共鸣、轻微颗粒感、尾音下沉），不写"好听""有磁性"；没依据写"无特殊声音特征"，不凭性格猜口音。所有造型共用一个音色；跨年龄造型可以调音高和年龄感，音色质感继承，否则像换了人。易混角色在音区、质感、共鸣、节奏里至少两项不同。

## 6. 场景

### 6.1 名称归一

地点身份正确比场景少更重要，拿不准就不合并，合错了两个地方共用一套陈设。可合并：简称与全称；同一地点里的局部（"客厅沙发旁"并入"客厅"）。要分开：内和外（"车内"与"车旁"）；不同人的住宅、建筑、房间；城市总称和城内具体场所；带"另一间"的；不同地域、公司的同名泛称（"会议室"）。

### 6.2 场景设定与版本

`cast/<场景>.md` 的 `## 设定` 写：

- 描述（各版本共用）：空间结构、尺度、材质、2–3 件年代器物、固定陈设、在用痕迹。材质写"部位 + 材料 + 表面处理 + 现在的样子"，如"水磨石地面，靠门一侧磨出一道发亮的走痕"。不写人物、风格、镜头词。
- 锚点物：1–2 个大件固定物，写清数量、朝向、所在墙面（"靠北墙正中一张老式红木八仙桌，两侧各一把圈椅"），视频靠它定站位。
- 默认初始状态：门窗关闭、抽屉推合、屏幕熄灭，开门、打翻、破碎留给视频；本就凌乱的写明是常态。交互小道具（茶杯、手机）不写进场景。
- 版本清单：只有时段（日、黄昏、夜）或固定陈设状态（婚礼布置、被砸之后）变了才拆版本，每版一句光照和状态差异（"夜：只开靠窗一盏落地灯"）。机位不同不拆版本（反打见 `scene-plate.md`）。

## 7. 关键道具

同时满足两条才单独建 `cast/<道具>.md`：脱离角色单独出镜（特写、放在桌上、被递来递去）；跨两段以上出现要保持一致（交通工具、手机、钥匙、信件只靠文字会跨段走样），或剧情靠它成立（反转的物证、信物），只出现一段也要让观众认清。达不到的，随身佩戴写进角色外观，只出现一次写进那段视频 prompt；每段能挂的参考有上限，道具要少而精。描述写类别、尺寸、材质、颜色、数量（成对、几枚）、工艺、初始状态，画法见 `props-and-storyboard-image.md`。剧情里状态会变的（碎裂、变色、沾血），初始状态是 `## 默认`，之后每个状态一个小节（`## 碎裂`），原因见 `shots/segmenting.md`「其余绑定」。

## 8. 其他入口与增量

- 从分镜或口述入口：从出场角色、场景、动作里反抽，缺年代、年龄、关系就问用户。
- 新增一集：按名字和别名匹配已有 cast 文件，只追加出场集、新造型、新版本。已有定稿图的 `## 设定` 不改写，否则图和它对不上；新角色以已有角色为参照做区分。原文和已有描述冲突时告诉用户，由用户决定是否重做。
- 用户自己的实物（要卖的商品、品牌物件）外观只来自用户的图或原话，没交代的颜色、材质在出图前那次报价里一并问，猜错了图和挂它的视频都白做。用户点名要先确认的新角色，照原话写、不加特征，出图后先给用户看再往下做。
- 用户自带的图：按文件名、文件夹和用户原话对到造型或场景版本，对不上或多张时问；图里是可识别的真人时，按 SKILL.md 底线提示一句授权。照常写 `## 设定`，看得到的以图为准，和剧本冲突时告诉用户。图复制成 `cast/<名字>.<造型>.png`、注明"用户提供"，视频直接 `--ref` 它。
