# 角色设定图

角色设定图 prompt 怎么写：版式、主体段、造型变体、群像。固定段原文在 `templates/cast-character.<媒介>.md`，本文件讲怎么用。

## 1. 落地形态

- `cast/<角色>.md`：`## 设定` 是外观唯一来源，不提交（写法见 `asset-extraction.md`）；每个造型一个小节（`## 默认`），正文是原样提交的完整 prompt。定稿图 `cast/<角色>.<造型>.png`。建节点：`jimeng-novel node create --key cast/<角色>.<造型> --type image --model <id> --prompt-file cast/<角色>.md#<造型> --param ratio=16:9 --param count=1`，生成后 `--out cast/` 落到上面的路径。
- 模型用 `jimeng-novel model list` / `model describe` 挑参考一致性和质感好的，要支持 16:9（或最接近的横幅）和图片参考。选定写进 README.md，全项目角色图用同一个，否则画风和脸型在角色间跳。第一张先按 `asset-review.md` 看遮脸是否稳定，同一缺陷反复出现就换模型，换了先出一张小样。

## 2. 两种版式

人脸模糊三联（blurface，默认）做视频的身份参考：左格正面全身、脸部模糊，中格背面全身，右格 3/4 面部特写是全图唯一清晰的脸。清晰全脸（clearface）给用户要看脸、宣传时用。默认遮脸的原因：
1. 视频模型按字面读参考图。一张图里有两张清晰的脸，模型会在两者之间摇摆，身份就会漂。
2. 宽画布里全身像的脸只有几十个像素，糊成一团仍然是一张脸，会被当成身份来源拷进远景，越拷越糊。遮掉后，脸只可能来自右格特写。
3. 正面管体型、服装、站姿，背面管发型后部和服装背面，特写管五官，三格分工不打架。

## 3. prompt 组成

按顺序写进造型小节：

```
[资产风格句]   README.md 里的资产风格句，没有就用风格句
[主体段]       每个造型各写一段（第 4 节）
[固定布局段]   模板原文，按版式
[光与表面段]   模板原文，按媒介三选一
[身份标记段]   模板原文，有标记才加
```

通用拼装规则见 `references/shots/prompt-anatomy.md`。布局只靠固定段，内容只靠主体段：主体段写布局、遮罩、底色、分格、机位会和固定段打架；固定段改写后布局遵循会变差。固定段里有少量否定措辞是有意的：同一要求写两遍并给出可接受形态，模型才会听。主体段仍然用肯定句，否定句会召回实体。

## 4. 主体段（约 250–380 字）

从 `## 设定` 取材，按顺序写成一段：

1. 外表年龄、性别、身高体型；族裔与肤色。
2. 骨相：3–4 组相对比较。
3. 五官：眉、眼（瞳色）、鼻、唇；神态中性，双唇自然闭合，目光平视。
4. 微观质感：按下表挑 2–3 处。
5. 量化的不对称：2 处，至少 1 处带量，如"左侧眉弓比右侧高出约一根眉毛的宽度"。完全对称的脸是 AI 感的主要来源。
6. 发型：分股、碎发、鬓角。
7. 身份标记：解剖坐标，与 `## 设定` 一致。
8. 服装从上到下：形制、面料、颜色、工艺、折痕；配饰挂在身上；鞋。辨识细节（`asset-extraction.md` 第 3 节）照 `## 设定` 写在所在部位，具体到颜色、材质、位置，一个细节一句。
9. 末句用肯定句重申媒介，如"整张画面是真人实拍的写实照片质感"。

漫剧（anime2d / cg3d）主体段不写第 2 项的骨相比较和第 5 项的量化不对称，脸写成一句脸型轮廓加五官特征（眼型、眉形、标志点），篇幅压到 150–250 字。这两项是写实的去 AI 感手段，写进动漫角色会把画风拉向厚涂概念原画。

| 项目 | 写实（photoreal） | 漫剧（anime2d / cg3d） |
|---|---|---|
| 皮肤 | `[部位]+[纹理]+[光学状态]`：鼻翼两侧可辨的细密毛孔；鼻梁与额头中央一小片自然皮脂光泽，其余哑光；颧骨和耳廓边缘透出淡红 | 肤色平涂（cg3d 写柔和透光），一层硬边阴影落在下颌与颈部 |
| 毛发 | 发际线与鬓角几缕更细软的碎发单独出锋，眉毛逐根可辨 | 发束分组勾线，带状高光，发梢尖锐出锋 |
| 布料 | 可见织纹，随肘膝弯折出柔和折痕，领口轻微起毛 | 衣褶用简洁的线概括，折叠处一层阴影色块 |
| 眼睛 | 双眼虹膜同色，自然的眼神反光 | 瞳孔分层上色，一处高光点 |

风格句或主体段已经带了妆面、胭脂这类脸上的红，皮肤就不再写局部泛红：两处红叠在脸上，会画成浓重的腮红。

主体段不写背景、光源（光在光与表面段）、表情、动作、手持物、临时状态（泪、汗、伤、乱发）：设定图是之后每个镜头的身份来源，临时状态会被拷进所有镜头。也不写真人明星、公众人物的名字或"长得像某某"。会被取下当剧情道具的配饰（簪、玉佩、戒指）不画进基础形象，否则这件东西单独出镜时成片里会有两份；佩戴着的戏份多，就另做一个「佩戴」造型。

## 5. 固定段：直接用模板

按媒介复制 `templates/cast-character.photoreal.md`、`.anime2d.md` 或 `.cg3d.md` 成 `cast/<角色>.md`，用编辑工具把 `<< >>` 换成内容，固定段一字不改。光与表面段已按媒介换好；2D 版的灰底是 `#8f8f91`，深灰底会把明亮的动画配色压暗，整张图偏概念原画。身份标记占位换成 `## 设定` 里的标记，一条一行；没有就删掉那一段。
- clearface：在布局段里改两处，其余逐字不变。一是左侧（正面全身）一条里，把"面部区域被一层不透明的隐私遮罩完全覆盖，遮罩边缘到发际线、耳廓、下颌为止，"换成"面部五官清晰，与右侧特写是同一张脸，"；二是【全局硬性约束】里删掉以"左侧一格的面部被完全不透明的遮罩盖住"开头、以"全图仅右侧特写出现唯一一张面孔。"结尾的那一整条。拿 clearface 做视频参考，脸漂的风险更高，用之前告诉用户。

## 6. 定妆照（看脸的替代做法，不套固定段）

单人半身像，3:4 或 9:16，灰底，3/4 微侧，同一主体段加"画面是一张半身肖像"。只有一张脸，可用于确认长相、宣传或额外参考；身份参考仍用模糊三联。存为 `cast/<角色>.定妆.png`，prompt 写在 `## 定妆` 小节。

## 7. 造型变体

- prompt = 资产风格句 + 变体前缀句 + 模板里的固定段，同样出模糊三联；前缀句原文、挂哪张参考、跨年龄怎么改见 `references/shots/prompt-anatomy.md`。变化短语取 `## 设定` 里这个造型的那一行，跨年龄写幼态或老态。文件里复制 `## 默认` 整节改名为 `## <造型>`，主体段换成变体前缀句，固定段不动。
- 生成后和基础造型并排看：身份锚点丢了只重生变体；差异只是表情、光线、小配饰就删掉这个造型，写进视频 prompt。别为修变体重生已定稿的基础造型，用过它的镜头都会失效。

## 8. 群像图

群像角色不做个人三联。一张图 2–4 个不同的人，多了分张，比例跟项目或 16:9，存为 `cast/<群体>.群像.png`。prompt 结构：风格句 + "一组{群体类型}的群像参考图：{N} 名不同个体并排站在中性纯灰无缝背景上（色值同本项目角色模板），中景全身，人物之间留有自然间距" + 群体外观白描 + "每个人的五官、身形与神态各有细微差异，是各自不同的人" + 媒介重申句。人数照要用它的镜头写。它只给造型范围，不保证个体跨镜头相同。
