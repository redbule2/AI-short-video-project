# 成片合成

一集的片段都在 `out/E01/` 下了，要拼成片、加字幕、BGM 或转场时看这份。合成不花积分，随时可以重来。

## 拼接和字幕：jimeng-novel compose

`jimeng-novel compose` 按顺序拼接片段、统一编码和尺寸、烧录 SRT（烧不了自动降级成软字幕，并说明原因），还能裁剪片段、输出接缝拼图。用法看 `compose --help`。片段顺序照 `shots/E01.md` 的分段表；只保留某段前半、或去掉模型在段末自己加的黑场时，用它的裁剪参数，不另外手写 ffmpeg，也不为黑场重生成。

## 字幕怎么写

有台词就默认做字幕，用户说不要才不做。台词和字卡分两份：台词时间轴交给识别，字卡自己写。参数以 `transcribe --help`、`compose --help` 为准。

1. 先不带字幕合成一版 `out/E01.raw.mp4`。
2. 把 `story/E01.md` 的台词按顺序逐字写进 `out/E01.lines.txt`，一行一条字幕。每行不超过 12 字，长句拆成几行。
3. `jimeng-novel transcribe out/E01.raw.mp4 --text-file out/E01.lines.txt --srt out/E01.srt --wait 180`：文字用文件原文，时间轴取识别结果。输出里列出的对不上的行不会写进 SRT，要看是漏说、说错还是拆行不合适，修了再跑。识别可能扣积分但 `credit estimate` 报不出，报价时单列一行「字幕识别，计费见 `transcribe --help`」，和这一批视频一起确认，不为它单独请示；同一文件再跑同一条命令会复用结果。
4. 画外音、内心独白在 SRT 对应行加 `<i>…</i>` 斜体。
5. 字卡写 `out/E01.cards.srt`：剧本里的【字幕：姓名·身份】放在该角色首次出场那段开头；剧情关键的文字和数字（时间、金额、编号）也在这里叠加，不交给视频模型画。只写内容本身（「23:47 末班车」），不加「车票：」「手机消息：」这类标签。每张至少停 2 秒；字卡在上部、台词在底部，可以同时出现，内容绑在画面物体上的（屏幕、票据）覆盖那个物体可见的全程。
6. `jimeng-novel compose … --srt out/E01.srt --cards out/E01.cards.srt --out out/E01.mp4` 重新合成。台词在底部，字卡在上部、样式不同。

合成后用 `jimeng-novel frames` 抽几帧看：字幕不压人脸，字卡不挡主体。不用 PIL 逐帧画字幕。平台会自动识别字幕时用软字幕或不加。

## BGM 与转场

片段生成时不要 BGM：每段独立生成，音乐在切点会断开跳变。BGM 在合成后统一混，只用用户提供或确认可用的音乐，音量压在台词下面：

```bash
ffmpeg -y -v error -i out/E01.mp4 -stream_loop -1 -i bgm.mp3 -filter_complex "[1:a]volume=0.15[b];[0:a][b]amix=inputs=2:duration=first:normalize=0[a]" -map 0:v -map "[a]" -c:v copy -c:a aac out/E01.bgm.mp4
```

段与段之间默认硬切。要黑场转场时在后期给相邻两段加淡出淡入，不要写进视频 prompt，模型会把黑场当成画面内容生成。

## 超分：要更高清的成片时

片段默认按 720p 生成。用户要 1080p 以上的成片时，先用 720p 片段合成并定稿，再对成片整体跑一次 `jimeng-novel upscale`，不必每段都用高分辨率重新生成：改片、重拍都在 720p 上做，定稿后只超分一次。版本有快速版、标准版、影院版，越往后细节越好、越贵，各分辨率可选的版本和参数看 `upscale --help`。

超分是服务端处理，要花积分，`credit estimate` 报不出价：报价时单列一行「超分（版本、目标分辨率），按实扣」，和用户确认后再跑，报花费用命令输出的实扣。字幕先烧进 720p 成片再超分，或在超分后的成片上重新合成字幕，两种都可以；超分后用 `frames` 抽几帧确认画面没有变形、字幕清楚。

## 交付

别断言「没有 BGM」：视频模型可能在音轨里自带氛围音乐，你听不到就没法确认。如实说「生成音轨里可能带氛围音乐」，用户在意时给办法：重生成该段，或合成时压低、替换原音轨。

给用户成片路径、总时长、字幕方式，请他们重点看开场 3 秒、集尾钩子是否落在最后一个画面、段间有无跳变（compose 的接缝拼图可以先自己看一遍）。不满意的段只重做那一段再重新拼（根因判断见 `shots/shot-review.md`）。要把成片放进即梦资源库时用 `jimeng-novel resource upload`（返回 assetId，参数看 `--help`）。
