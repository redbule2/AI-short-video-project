# 成片微调与局部重拍

用户对已出的片段或成片提出局部修改时用：某几秒重拍、改一个细节、修穿帮、换一个动作。改动大到剧情或分段变了，回到分镜改 `## Sxx` 后整段重出，不走这里。

## 做法：截出那一段，用参考视频生成

整段重生会把没问题的部分也变掉，人物、构图、节奏都可能跑偏。把要改的那几秒截出来当参考视频，让模型在它的基础上只改要改的地方，其余尽量保持原样。

1. **定位**：用 `frames` 找到问题的时间段，对应到是哪个片段文件（`out/E01/Sxx.mp4`）、段内第几秒到第几秒。从片段文件截，不从成片截：成片烧了字幕，截出来字幕会被当成画面内容。
2. **截取范围**：贴着要改的内容，前后各留一点让模型接得上；起止点尽量落在 `frames` 报出的镜头切换处，接缝最自然。参考视频越长越贵，不多截。
3. **截取**：用 `compose` 的 `--trim` 把这一段截成单独文件，放 `out/E01/fix/`。本地操作，不花积分。
4. **选模型**：只有能挂参考视频的模型能做，看 `model describe` 的参考上限里视频是否大于 0。
5. **写 prompt**：参考视频挂成一个别名，prompt 先说保留什么（构图、机位、人物外观、动作节奏、台词），再说只改什么，一处改动一句。角色定稿图照常挂上，防止人物在改动里走样。输出时长和截取片段一致，替换回去时间轴不变，字幕也不用重做。
6. **报价并提示计费**：建好节点后用 `credit estimate` 报价，它已经算上了参考视频。报价时要明确告诉用户：用参考视频时，大部分模型会把参考视频的时长也算进计费，所以比同样时长的普通生成贵不少。同时给出更便宜的选项：要改的是一段的后半时，用切点那一帧做首帧补拍（见 `references/shots/continuity.md`「只重拍一段的后半」）；或按原 prompt 不带参考视频整段重生。这两种都保留不住原画面的细节。说清各自的后果和价格，让用户选。
7. **替换回去**：把原片段在截取点前后各截一份，和新生成的片段按顺序 `compose` 成新的 `Sxx.mp4`（`--out` 会把旧版移进 `old/`），再按原方式合成整集。新片段时长变了，就重新识别这一段的字幕。
8. **审片**：看 `compose` 输出的接缝拼图，两侧的人物位置、光线、动作要连得上。接不上就把截取范围扩到最近的镜头切换处，重新报价再做。
