# 台词、口型与声音

段里有台词、内心独白（os）、画外音或旁白（vo）、多人同框、音效时看。人声由视频模型直接生成并自带口型，不另做配音合成，否则口型对不上；BGM 和字幕在成片阶段加。

## 口型

- 出镜说话的固定句式：`{{名字}}嘴唇随每个字清晰地一开一合，说："台词"。说完嘴唇合拢`。超过 15 字可简写为 `{{名字}}嘴唇随字张合，说："台词"`。不写嘴部动作常会有声音嘴不动。
- 同框不说话的人写 `嘴唇紧闭不说话`，否则声音会安到别人身上。相邻镜头换人说话时同样：静默那一镜写明嘴唇紧闭，台词只写一次、紧跟说话人的 `{{名字}}`。
- 说话那一拍的画面主体就是说话人：这一拍先写说话人入画，不在这一拍画面里的人不写。被描写得最具体的那个人最容易抢到镜头和台词。
- 口型是视频模型最不稳的一项。说话那一拍用中近景到近景，正脸或侧脸可见，单句短（8 字以内最稳），长台词拆句或在句间切镜；远景、背身、多人、动作中做不出口型，切近景或改成画外音。大特写留给静默微表情，说完、嘴唇合拢再推上去。
- 过肩镜头里只有面朝镜头的一方带口型；背对的一方要开口，切正反打或改成画外声。
- 台词用中文双引号逐字照抄，不用花括号（留给参考），不转述。

## os / vo / 画外声

| 类型 | 正文写法 |
|---|---|
| 内心独白 | `{{女主}}嘴唇紧闭没有开口，画面中响起{{女主}}本人声音的内心独白："……"` |
| 旁白 | `画外响起旁白（低沉中年男声，语速平缓）："……"`；整段只有旁白时末尾加 `画面中所有角色全程不说话` |
| 不在画面里的角色 | `画外传来角色A的声音（五十岁女声，尖利急促）："……"`，这个角色没挂图，要写音色 |
| 电话、录音、广播 | `{{女主}}耳边的手机里传出男主的声音（男声，压低）："……"`，听者嘴唇紧闭 |

- os 和旁白期间出镜角色都写明闭口，不然模型会让人张嘴说出来。os、vo 是剧情事实，不改成当面说出口；都要计时（count_chars.py）。

## 情绪写法

写「声音质感 + 身体化」，泛化词只会演成模板表情。

| 泛化 | 改成 |
|---|---|
| 愤怒 | 咬着牙的低吼，压着爆发前的颤抖，拳头抵在桌面 |
| 害怕 | 带哭腔的哀求，声线不自觉上扬，肩膀缩起 |
| 冷漠 | 冷声，一字一顿，眼皮不抬 |
| 崩溃 | 嘶吼到破音，喉咙发干，身体前倾 |

- 一句台词一个主导情绪，叠加演不出来；要转折就拆成两句或两个镜头。不写心理描写。
- 言行裂缝最能拍出潜台词：同一帧里身体和台词矛盾（笑着答应，手里的杯子却攥紧）。
- 音色一致：从 cast/<角色>.md 的设定里截一句 ≤ 20 字的音色简述，角色每段第一次开口时写一次，全剧逐字复用；措辞一变就可能换一副嗓子。

## 对白调度

用户给了镜头时只在镜内调度（听者反应、画外音分摊、运镜启停），不加独立镜头（见 segmenting.md「导入已有分镜」）。对白段最常见的翻车是「谁说话拍谁，一镜到底」。调度跟着事件走：说话人交接、关键台词落地、视线转移、强弱翻转各是一次时机，切镜或运镜启停插在句间停顿或语义转折处。同一构图过了约 5 秒还没有事件，多半已经单调，插一处听者反应或道具。

| 方式 | 时机 | 要点 |
|---|---|---|
| 正反打 | 说话人交替 | 卡着台词硬切；说话方近景面朝镜头，带口型 |
| 听者反应 | 一方说长台词 | 切听者近景，嘴唇紧闭加一个微动作（指节攥紧、喉结滚动、视线躲闪）；说话方这句转画外声 |
| 道具特写 | 台词提到关键物件，或句末停顿 | 切道具特写 1-2 秒，写材质和光，再切回 |
| 环境反馈 | 情绪转折点 | 雨骤然变大、灯闪一下、门缝的光移动，配对应声音 |
| 视线三拍 | 角色看向画外 | 视线方向 → 落点物特写 → 切回反应；落点物是场景里已出现过的东西 |
| 构图重心偏移 | 强弱关系翻转 | 不切镜，同机位缓移，让一方越占越大 |

- 每次插入都要答得出观众此刻为什么要看这个，答不出就删。切回说话方时位置、朝向、姿态和切走前一致，重写口型句式。

## 多人同框与站位

- 精确描述最多 3 人，多了会混脸或漏人，其余降级为背景里模糊的人群，带一个微动作。
- 旁观者反应写 2-3 个有先后的个体（右侧一人先僵住，半拍后左侧一人放下酒杯）；「众人纷纷」会生成整齐划一的假动作。
- 两人以上写齐空间三要素：景别；近大远小（「胸部以上近景」「全身入画但身影偏小」）；可见的间隔物（「隔着八仙桌」「相距三步的空地」）。
- 距离和景别匹配：1 步以内用中景、近景；2-5 步用中景、全景；5 步以上用全景、远景，或分镜头交替拍单人。

朝向用绝对朝向（见 video-prompt.md「结构」）。对峙的选择顺序：

1. 过肩：从 A 肩后拍向 B，前景的肩属于此刻的施压方。
2. 前后纵深：近处一方背对镜头、身形大，远处一方面朝镜头、身形小。
3. 左右侧身：慎用，动作一多就退化。
4. 对立双方都面朝镜头：不要用，像在对观众说话。

180° 轴线：两人连线是轴线，同场机位在同一侧，切镜后左右不互换；跨段的轴线锁见 continuity.md。

看手机、读信：内容和表情不在同一机位兑现，要展示内容就过肩或俯拍对准屏幕，要拍表情就只拍道具背面（见 video-prompt.md「屏幕里的画面、监控、回忆」）。

## 音效

`<>` 里分两层：

- 环境床：持续低强度的底噪，如 `<窗外雨声，持续>`，同一场景各段逐字一致，否则拼起来底噪会跳。
- 事件音：画面里找得到发声动作，如 `<门被推开撞到墙>`；只写「有声音」不兑现。

- 声音嵌在它发生的阶段里，堆在末尾对不上时间。
- 声音也能叙事：爆发前环境音骤停 0.5 秒；最后 0.5 秒放大或掐断某个声音做听觉断点；远处脚步由远及近当钩子。
- 声音桥：跨场景时，前段末尾先放后一场的环境声（J-cut），或后段开头延续前段尾音（L-cut）。只写环境声，不写台词。
- 能听懂的人声（喊叫内容、广播词）算台词，写进台词并计时；无词人声（喘息、哭声、人群嘈杂）才写进 `<>`。
- 剧情里本来就有的音乐（乐队、手机外放）可以写，用（）注明来源和音量。
