# 分段：一集剧本 → shots/E01.md

讲怎么把 story/E01.md 拆成一段段视频生成、每段多长、装多少内容，以及用户贴分镜时怎么转写。用户给了镜头、分段或要求照原稿拍时，末节「导入已有分镜」优先于本组文件的调度建议。正文写法见 video-prompt.md，拼装见 prompt-anatomy.md。

## 落地形态

shots/E01.md 顶部一张分段表（表头照 `templates/shots.md`，给人核对用，参考列的别名和正文 `{{别名}}`、`--ref` 逐字一致），下面每段一个 `## S01` 小节，正文原样提交给视频模型。

## 两层粒度

| 层 | 是什么 | 约束 |
|---|---|---|
| 段 | 一次视频生成，产出 out/E01/S01.mp4 | 整数秒，在 `model describe` 给的时长范围内；参考数在它给的上限内 |
| 镜头 | 段内的一个时间区间，对应正文里的一个画面阶段 | 从 0 连续铺到段时长，不留空洞；一个镜头一个画面重心 |

模型一次生成里就能切镜、换景别、出台词和音效，段内衔接比跨段拼接顺滑，所以一次反打、一句台词结束只是新镜头，不是新段。每段都要能单独重生成，正文自包含（见 video-prompt.md「只写摄像机拍得到的」）。

## 先查模型上限

时长范围、参考图/视频/音频数量上限、是否支持首尾帧，以 `jimeng-novel model describe --model-id <id>` 为准，不凭记忆，查不到就告诉用户。超出范围的段可能被拒，也可能被悄悄截短照常扣费。换模型后上限变小，超长的段按叙事事件拆开，台词和镜头顺序不变；上限变大不必合并。

## 台词计时

所有能听见的文字都要计时：台词、路人喊声、电话广播、内心独白（os）、画外音和旁白（vo），漏算会被模型压成快嘴。

```
python3 <skill>/scripts/count_chars.py shots/E01.md --max-duration <模型上限>          # 写好分镜后逐段核算
python3 <skill>/scripts/count_chars.py --duration 10 "女主：……" "男主：……"             # 还没写进分镜时单段试算
python3 <skill>/scripts/count_chars.py --retime shots/E01.md#S02 --duration 12      # 改了某段时长后按原比例重排时码，看过 diff 再加 --write
```

分镜模式按分段表时长和引号里的台词逐段判超载，说话人取引号前最近的 `{{别名}}`；单段试算写成「角色：台词」才计换人停顿。字数秒数用脚本算，不手算。语速常量是经验值，用户反馈太快太拖就记进 README.md 的假设，后面照此调。

## 装箱

按剧本顺序把内容装进段。

这几处切新段：换地点或换场景版本（一段挂一个版本，混挂会被当成换了地方）；时间跳跃、闪回进出；再装就超时长或参考数上限；同一角色换造型（剧本要求当场换装时例外，挂两张造型图）。

应合并：同场、时空连续、同一轮对话攻防或同一条动作链，不超上限也不超载就放进同一段。应单独成段：开场钩子、集尾钩子、爆点反转、复杂动作或特效，它们最常返工，绑在一起重生成会连累好的部分。

切点落在叙事节拍边界、动作完成之后。一句台词、一个动作不劈两半；问与答、命令与执行、揭示与第一反应、出手与受击这类最小因果放在同一段，劈开后后一段不知道前因。装不下时把铺垫挪到上一段、删不推进的停顿、把切点前移到触发事件之前，不把回应推到下一段（有意留悬念除外）。用尾帧衔接的同场段可以在开门、转身这类自然掩护点切，见 continuity.md。

## 定时长

```
段时长 = 台词耗时下限（含换人停顿）+ 不与说话并行的独立动作 + 0.5s 收束，向上取整
```

- 不先定成上限再往里填：空出的时间模型会用呆站、重复台词或胡言乱语填满。
- 独立动作逐项列（「推文件 1s、桌面特写 1s、男主反应 1s」），列不出来这段时间就不存在。纯画面段按视觉事件计，每个约 2-4 秒，全集合计不超过 1/3。
- 计算值不在可选取值里时取不小于它的最近合法值，多出的时间补真实动作（反应、走位、道具），不补静止画面。

## 单段内容量

| 段时长 | 对白上限 |
|---|---|
| ≤ 8s | 1-2 句，每句宜 ≤ 10 字 |
| ≤ 15s | 3-4 句 |
| > 15s | 按镜头分，每镜头 ≤ 2 句 |

- 每段至少 1 个叙事事件（改变局势的动作、推进剧情的台词、新信息）；10 秒以上至少 2 个，15 秒至少 3 个。走路、站着、看风景不算。
- 15 秒内最多 3 个硬切，8 秒以内最多 1 个：切得越碎，每个镜头越短，越容易被整镜跳过。
- 动作的起手（拔刀）和结果（对方倒地）各占一个阶段、各有时长，只写结果起因会丢。剧情靠它成立的道具、动作和情绪节拍单独占一拍，给近景或特写停留 2–3 秒，放在全景背景里观众看不见。
- 群演不关键就写「几名」放进背景。出现在剧情关键镜头（爽点、围攻、众人反应）或人数本身是剧情时，先出群像参考（`assets/character-sheet.md`「群像图」），正文写清人数和各自站位；没有参考常出同脸、镜像、人数不对，这类镜头重做最贵。
- 超载时按铁律 2 腾地方：用户没定分段就拆段、在相邻段之间挪完整的句子，加时长是请用户选的选项。台词逐字保真，省略号破折号都保留；剧本台词本身有问题就回剧本改。

## 切镜头

镜头和正文的画面阶段一一对应，每个镜头想清楚这几项：

| 项 | 写法 |
|---|---|
| 时间 | 段内秒数，镜头通常 2-5 秒；对白按事件调度（见 dialogue-and-sound.md） |
| 景别 | 大远景 / 远景 / 全景 / 中景 / 中近景 / 近景 / 特写 / 大特写，连续变化写「中景→近景」 |
| 角度 | 平视 / 仰拍 / 俯拍 / 过肩（从谁肩后拍向谁）/ 主观 / 侧拍 / 背拍 |
| 运镜 | 取自 video-prompt.md 的运镜表，带速度 |
| 动作 | 位置、绝对朝向、动作过程、结果 |
| 台词 | 说话人、逐字台词、声音质感和身体表现；os、vo 标明 |
| 声音 | 环境床 + 事件音；能听懂的人声算台词 |

## 节拍与情绪档位

给每段定一个叙事功能（开场钩子 / 建置 / 对峙升级 / 反击 / 反转 / 揭示 / 情绪落点 / 集尾钩子）和一个档位：

| 档位 | 含义 | 镜头倾向 |
|---|---|---|
| 蓄 | 压抑、铺垫、埋线 | 固定或缓推，中景多，光压暗 |
| 推 | 冲突加码、逼问、证据露角 | 正反打、过肩，节奏加快 |
| 爆 | 反击、打脸、真相、动作高潮 | 急推、手持冲击，硬光，环境音骤停后爆发 |
| 收 | 余波、决定、悬念定格 | 缓拉或固定，留一个可见的未完成问题 |

## 全集导演方案

写正文前在 shots/E01.md 顶部列持续状态清单（栏目见 `templates/shots.md`）：反复出现的道具各一个固定名称和一句外观；关键地标的位置、哪几段看得见，两侧都入镜的写两面；中途出现的状态变化首次出现时写死形态；关键陈设的数量位置；每段在场的人（离场要写出离场动作，否则会凭空消失或多出来）；关键动作用哪只手、谁在画面哪侧；每场的环境状态。各段正文从清单逐字取用（原因见 continuity.md「持续道具与环境」）；地标陈设照 `cast/<场景>.md` 当前版本，图重出改了描述就一起同步（见 workflow.md「改上游」）。

然后在脑子里（或回复里）过一张「段｜时长｜功能·档位｜主运镜｜衔接」表，逐条判：

1. 开场 3 秒强信号：第一段 0-3 秒内出现可见冲突、异常或强关系句，没特征的中景人物开场观众会划走。起手可以是冲突直入、局部入场（鞋、手、背影）、建筑空镜、主观视角、承接上一集钩子。
2. 相邻段主运镜不同（主运镜是段内时长占比最大的运镜），否则成片看着像一个镜头在重复。
3. 情绪有起伏：不一路「推」到底；至少一个「爆」，之前有「蓄」或「推」；爽点阶梯升级，口头反击 → 证据 → 身份或资源 → 公开审判。
4. 集尾钩子落在画面上：最后 1-2 秒停在将揭未揭 / 将认未认 / 将赢未赢（悬念脸特写、证据露一角、门外脚步逼近、对峙定格）；只靠台词或问题不明的背影是弱钩子。
5. 呼应：至少一处镜头呼应，或一个道具的三态（出现 → 被使用 → 改变状态）。
6. 下一集起手：本集以悬念脸或对峙定格收，下一集用冲击台词开场；以危险逼近收，下一集用全景交代现场开场。

## 其余绑定

模型按字面读参考图，挂了什么就倾向画什么，所以只挂本段确实入画、且外观和图一致的东西。

本段要的样子和参考图不一样时，文字压不住图，场景、角色、道具都是这样：场景里多了或毁了大件东西，角色带着剧情要看清的伤和污渍跨几段，画面本身换了观感（见 video-prompt.md「屏幕里的画面、监控、回忆」）。剧情要观众看清的变化，以原图为参考派生一张该状态的图（母版句、换光句、变体前缀句见 prompt-anatomy.md），比白花一次视频钱便宜，从变化之后的段起挂它，露得再少也挂；一闪而过、不影响剧情的才只靠文字。同一样东西一段只挂一个状态的图，两张都挂会取错；状态切换放在段与段之间，或单独做一个特写段。

- 场景：同场连续的段用同一版本的同一张图，不因景别换图，换图会被当成换了地方。拍向图里看不到的方向（反打）或特殊视角（高处俯拍、窗外望进来）时模型会自编背景，这类机位要有自己的场景图（见 assets/scene-plate.md「反打与特殊视角」）。
- 角色：只挂本段完整入画（至少露脸或半身）的造型。多人段写明「画面中只有 N 人：…」，不入画的人不挂图、不写进站位，否则会多出一个人。画外发声的角色不挂图，写音色；只露局部（手、背影）的不挂全身设定图，局部用 `## 设定` 里的原句写，需要一致时另出局部特写图。
- 道具：只挂本段出镜、且外观和参考图一致的道具；会变状态的随身物不画进角色图，或另出一个角色造型。
- 写完按 shot-review.md 自检一轮。

## 导入已有分镜

用户贴镜头脚本（镜头1、镜头2……带台词）要直接出视频时：

- 原文存进 source/，只读，之后对照它核台词。
- 转写成 shots/E01.md。用户的镜头说明画面怎么组织，不等于生成次数，可以按上面装箱（几个短镜头合成一段）；用户明说了段数、段长或总时长就照它分。
- 用户指定的台词逐字照抄，机位、运镜、动作、镜头顺序和硬约束全部保留，按本组文件的写法补齐站位、朝向、视线、口型、音效。用户给的镜头、景别和动作顺序是骨架：不新增独立镜头、不换序、不删；骨架里一个构图停太久的对白仍按 dialogue-and-sound.md「对白调度」做镜内调度。原稿只有动作行或用户要求照原稿时，不加原稿没有的硬切。多出的机位只作可选建议列在交付里。
- 用户给了分镜图，就作为参考挂到对应段，正文写明按图上哪几格展开。时长和台词冲突按铁律 2。
