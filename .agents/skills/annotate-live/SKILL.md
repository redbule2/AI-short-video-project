# 右边批注联动

项目管理就是流水线，没有别的页面。

1. 打开：跑 `node "E:/AI短视频项目/.agents/skills/annotate-live/server.js" open [文件]`，服务没开它会自己开；写了文件就盖上来看。
2. `navigate` 到它打印的网址，再用 `show_pane` 显示 `preview`。
3. 等批注：后台跑它打印的那条命令。
4. 它打印「按批注修改 …」后退出：照 AGENTS.md「按批注修改」改，改完回第 3 步。
5. 批注文件已经不在的，跳过。
6. 用户说「看右边」：跑第 3 步，排着的马上收到。
7. 用户说「下一段」：写下一个分段，照第 1 步打开，再等。

## 两种批注

- 剧本批注：剧本、镜头表。
- 提示词批注：只批各段的视频提示词。
- 两种各等各的：`wait 剧本`、`wait 提示词`。
- 打开时不写文件：两种都等。
