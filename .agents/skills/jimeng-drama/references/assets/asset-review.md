# 资产图验收与修法

角色、场景、道具、分镜图下载后怎么验、缺陷怎么修；用户说某张图"不像""有问题"时也用。

## 1. 怎么验

能看图就逐张逐项判断，不过的写一句在哪、是什么；看不了图就把清单列给用户，不假装看过。并排对比新角色和已定稿角色、变体和基础造型、场景版本和母版。阻断项不过即不合格；只有一般项不过，告诉用户由用户定。

## 2. 角色设定图

阻断项：
- 三联：左正面全身、中背面全身、右 3/4 面部特写，大致均分。
- 左格看不出五官（模糊、马赛克、柔焦都算过）；画成光板假人头、面具或没头不过。全图只有右格一张清晰的脸。
- 三格同一人：发型、服装、配饰、配色一致，配饰在同一部位。
- 左中两格头顶到脚尖完整，鞋在画内，上下留灰底。
- 没有文字、标签、水印、分割线、边框；背景是连续纯灰，没有房间、地板纹、虚化背景。
- 中性状态：没有泪、汗、血、伤、夸张表情。
- 年龄段、标志服装、身份标记的颜色形态和左右与 `## 设定` 一致。不符时修图；想改设定迁就图先问用户。

一般项：年龄感、族裔、体型、服装年代与 `## 设定` 一致，没多出配饰或手持物；画风与已有资产一致；与易混角色有两项一眼可见的差异；没有 AI 塑料感，下面命中 2 条判不过：蜡质磨皮无毛孔；大眼尖下巴完全对称的模板脸；发丝成块像头盔；面料无织纹折痕；刺眼轮廓光或边缘发光；两眼高光不一致；手指、牙齿、耳朵结构异常；过饱和 HDR；皮肤布料质感一样；写实项目像游戏渲染。漫剧把皮肤、面料、质感那三条换成：线条粗细机械均匀；色块和线稿严丝合缝像矢量描图；阴影层数过多像喷枪。

清晰全脸版跳过遮脸两项；群像图查人数 2–4、长相各异、灰底。

## 3. 场景图

阻断项：纯空镜（九宫格逐格看，没有人、影子、倒影里的人、手、动物、像人的雕像）；看得到两面墙、墙角线是斜的；锚点物完整、数量位置对；没有文字、水印、黑边（等宽笔直的纯黑条带，暗角不算）、装裱边。

一般项：三层纵深有物件；单一主光源、家具有接触阴影；年代器物对；有在用痕迹；没有表面油亮、样板间全新、无来由发光、同物克隆、伪文字；版本和母版同一空间、陈设不动；反打换了主背景墙而非镜像。

## 4. 道具图与分镜图

- 道具：只有这一件、完整居中、没有手和人、背景干净；颜色、材质、数量、形制逐项和描述对上；初始状态对；状态变体和初始图是同一件。
- 分镜图：格数行列对，并排的没叠成上下，格里没再分小格；没有字幕、气泡、编号；人物和参考图同人同服装，站位符合锚点物，各格光向时段一致。草稿：都是无脸火柴人，只有一种强调色。

## 5. 修法

- 可读文字、乱码和品牌标识不放行，视频会按字面继承（写法见 `shots/video-prompt.md`「画内文字」）。
- 局部缺陷（文字、多余配饰、场景里的人影）点改优先：以这张图为参考，只写要改的那一处；整图反复重生会让脸越来越对称、塑料。点改句："以参考图为准，保持构图、人物长相、服装、光线方向与配色完全不变，只修改：{位置与要改成的样子}。"
- 要改画风（太写实、太暗）时不挂旧图作参考，旧图画风会和脸一起被锁住；想保住的长相写进主体段，接受脸有小幅变化。
- 先查 prompt：电影类词、否定句、条件句、混写语汇、主体段写了布局，不修 prompt 重生只是重抽。
- 同一缺陷重生两次不过，把缺陷和选项（换模型、改描述、接受、改清晰全脸版）告诉用户。
- 修定后把最终 prompt 写回对应 `## 小节`，让 md 和定稿图一致；被替换的图由 `--out` 自动移进 `old/`。

| 缺陷 | 修法 |
|---|---|
| 左格脸清晰；第二张清晰脸 | 点改左格面部为重度模糊、保留发型轮廓；两次不过换模型 |
| 光板假人头、肤色平板、黑条 | 点改成柔焦模糊的真实头部，保留头颅轮廓和发际线；同一模型多张都这样就换参考一致性更好的模型，再不行改 clearface 并告诉用户脸漂风险 |
| 裁脚裁头贴边 | 直接重生；反复出现就把主体段压到下限（写实约 250 字、漫剧约 150 字），太长会挤掉布局遵循 |
| 三格不是同一人 | 以另两格为准点改不一致的那格 |
| AI 塑料感 | 点改：皮肤补毛孔和不均肤色，布料补织纹折痕，发丝分股补碎发，其余不变 |
| 不像人设 | 核对 `## 设定` 和主体段写清没有，补写后重生 |
| 易混角色撞脸 | 加大骨相和发型差异，改 `## 设定` 后只重生后做的那个 |
| 画风漂移 | 查首尾媒介句和语汇混写，修 prompt 后重生 |
| 墙纸感正面平视 | 删掉"正对""对称"之类的词后重生（原因见 `scene-plate.md` 第 1 节） |
| 双重阴影 | 主体段只留一个光源技术句后重生 |
| 黑边、装裱边 | 删电影类词，点改把边缘补成空间延续 |
| 反打成镜像 | 强调"视点背后那面墙成为主体"重生；两次不过改用母版的不同局部 |
| 分镜格叠成上下或格中分格 | 写明"左右并排成一行"，删掉末尾追加的规则后重生（原因见 `props-and-storyboard-image.md`） |
