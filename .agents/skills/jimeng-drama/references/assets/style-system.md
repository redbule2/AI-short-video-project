# 风格体系

怎么定风格、写风格句和资产风格句，哪些词会把画面带偏。定风格、写生图 prompt、换风格时有用。

## 1. 选风格

按题材、年代、情绪、受众从第 4、5 节挑 3–6 个推荐，每条给画面示意、适合理由、主要风险，真人和漫剧各至少一个（用户已限定除外）；用户说"你定"就取第一推荐并说明理由。

| 题材 | 首推 |
|---|---|
| 都市甜宠、职场 | 韩剧都市柔光、现代都市写实、韩剧清新 |
| 复仇爽剧、豪门 | 现代都市写实、青橙港风、美剧蓝橙 |
| 古装言情 | 古偶柔光；权谋配宫廷；江湖配武侠 |
| 悬疑犯罪 | 现代悬疑冷调、HBO 式低饱和、韩国电影冷调 |
| 年代、民国 | 年代写实、民国、90 年代港片 |
| 玄幻修仙 | 国漫 3D、国漫二次元、厚涂 |
| 校园青春 | 日漫赛璐璐、韩剧清新、韩漫条漫 |

用户自带风格参考图：路径写进 README.md。写实项目的风格图里不能有人（人脸会泄漏到所有角色身上），有人就请用户换纯场景图。有参考图时风格句只留媒介半句，色调和光交给图。

## 2. 写进 README.md

- 媒介：photoreal（真人）、anime2d（2D 漫剧）或 cg3d（3D 漫剧），决定用第 3 节哪一桶语汇。
- 风格名和风格句：从第 4、5 节逐字取或按第 3 节定制，场景图、道具图、视频用它。用户自己写了画风词时以它为准，预设句里和它冲突的分句（常是线条、阴影）换成用户原词。
- 资产风格句：角色设定图用。风格句含环境光、夜景、霓虹、窗光这类"光的总倾向"时，另写一句只含媒介、成像或笔触、色板的（"真人实拍的写实照片质感，35mm 彩色负片的细颗粒，色彩浓郁、肤色自然"），否则灰底棚拍会被拉成街景夜景；不含环境光时两句相同。
- 色板和禁用词：人读和自检用，生成接口没有负向字段，禁用词不进 prompt。

风格句逐字复制，同义替换会被当成另一种画风（"国漫 3D"写成"中式 3D 动画"）。风格句和媒介重申句放哪、个别段换观感时删哪些分句，见 `references/shots/prompt-anatomy.md` 第 1 节。换风格要重做全部图和已生成的视频，换之前把影响清单列给用户。

## 3. 风格句的结构

`[媒介/画种] + [成像档或笔触] + [色调与色板] + [光的总倾向]`，40–90 字，只写怎么画，不写人物、地点、情节。

| | photoreal | anime2d | cg3d |
|---|---|---|---|
| 媒介句 | 真人实拍的写实照片质感 | 2D xx 插画 / 动画画面 | 3D xx 动画 CG 渲染 |
| 成像或笔触 | 35mm 彩色负片颗粒（年代、复古）；全画幅数字成像（现代） | 线稿粗细与抖动、平涂或渐变、阴影层数 | 材质分明、柔和透光、描线与否 |
| 光 | 技术句：光源、方位、色温、软硬、光比 | 程式化：明暗两分、硬边阴影、留白 | 单一主光造型 |
| 不用的词 | 线稿、描边、赛璐璐、厚涂、二次元、插画 | 毛孔、眼神光、布光、胶片、照片、光比 | 毛孔、负片、照片；纯 2D 词按需 |

两桶语汇混写，写实会画成动漫、插画会画成照片。三渲二按 cg3d 记，线和阴影用插画语汇。

2D 动漫（尤其国风、修仙）模型默认往偏暗偏写实的厚涂原画走，风格句里写出亮度和平面感：高明度、色彩明亮干净、平涂或赛璐璐上色、干净勾线；不写体积光、厚重质感、电影感、写实比例。角色设定图底色同步换浅灰（见 character-sheet.md 第 5 节），资产风格句同样带上高明度。

## 6. 降 AI 感（真人必用，3D 漫剧用前四条）

1. 单一主光源技术句：`[光源] + [方位与入射高度] + [冷暖] + [软硬] + [光比] + [随距离衰减]`，如"左侧窗外阴天散射光，从略高于视平线处斜射进来，偏冷，柔和，亮暗约 2:1，越往房间深处越暗"。写两个光源会画出两套阴影。
2. 材料 + 表面处理："氧化发暗的黄铜门把手"，不写"金属""高级材质"；同一材料不同位置磨损不同。
3. 年代器物：每张图 2–3 件（搪瓷缸、BP 机、绿皮台灯），不写会被拖回"今天"。
4. 在用痕迹：门把手磨亮、桌角掉漆、挂过画的浅色印；长期磨损写，正在发生的事不写。
5. 可信优先于好看：脸写自然的不对称，皮肤布料发丝写微观纹理；色板按 60/30/10，强调色落在具体物体上（一把红伞）。风格句的色名会渗进道具、液体和伤痕：颜色关键的物件在正文写明颜色和质地，接近主色时写明区分，必要时用首帧锁定。

## 7. 会把画面带偏的写法

| 写法 | 后果 | 改成 |
|---|---|---|
| 电影、电影感、剧照、宽银幕、大片 | 画面被压成带黑边的宽银幕 | "实景照片质感"加成像档 |
| 否定句："不要人物""没有文字" | 否定词里的实体被召回画面 | 肯定句："平时会被人占用的位置此刻都空着" |
| 条件句："如果是夜景则……" | 两个分支都被画出来 | 你先判断，只写选中的那一支 |
| 相机、三脚架、柔光箱、影棚、景深、虚化、镜头 | 器材入画或背景虚化 | 写视点："从约 45 度斜角、略高于视平线处看去" |
| 唯美、氛围感、高级感 | 无法落地，结果随机 | 拆成可见的材质、光、色 |
| 轮廓光、发光描边、rim light | 塑料感和光晕边 | 单一主光源加反弹补光 |
| 皮肤写"色斑" | 被画成血迹 | "几粒浅褐色雀斑" |
| "去掉伪文字""无乱码" | 伪文字反而变多 | 不提文字，必要时写"画面里只有画面本身" |
| 导演、片名、演员、真实品牌 | 不稳，有肖像版权风险 | 写成可见特征 |
