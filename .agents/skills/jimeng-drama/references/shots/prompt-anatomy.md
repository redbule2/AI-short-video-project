# 完整 prompt 的拼装

一张图或一段视频提交时 prompt 由哪几段组成、按什么顺序排，写好正文、建节点前对照。正文写法见 `assets/character-sheet.md`、`assets/scene-plate.md`、`shots/video-prompt.md`。

## 0. 前提：CLI 原样提交

`jimeng-novel node create --prompt-file <md>#<小节>` 把这个 `##` 小节的正文原样交给模型，不加任何文字：风格句、布局段、参考说明句、尾注都要你写进去。给人看的备注、元数据、待办会被当成画面要求，放到别的小节（如 `## 设定`）或文件顶部的表里。模板复制时只取代码块里的文字，不带 ``` 围栏。`#小节` 的匹配规则看 `node create --help`。

参考图用 `--ref <别名>=file:<路径>` 挂上，prompt 里写 `{{别名}}`，两边逐字一致。写了 `{{别名}}` 没挂参考，CLI 提交前拦下、不扣费；挂了参考没在正文点名，等于白挂。也可以写 `--ref 别名=node:<key>` 直接用画布上那个节点的图。`node create`/`update` 传了 `--ref`、`--first-frame`、`--last-frame` 任一个就整体替换原有参考，每次写全；清空用 `--clear-refs`。

## 1. 风格句：放在第一句，只写一次

- 每张图的第一句是 README.md 里的风格句原文，逐字复制：模型的风格理解来自开头，同义改写会被当成另一种风格。
- 角色设定图用资产风格句（定义见 `assets/style-system.md`），没有就用风格句；场景图、道具图、视频用完整风格句。
- 只写一次，重复的风格句会和后面的内容抢注意力。
- 角色设定图后面接着一大段布局，模型容易滑回默认画风，所以主体段末句再用肯定句重申一次媒介（见 `assets/character-sheet.md`）。
- 视频写成 `基础视觉风格：<风格句>`，单独一段（第 4 节）。
- 某段画面本身换了观感（见 `shots/video-prompt.md`「屏幕里的画面、监控、回忆」），这一段的风格句只删掉和这层观感冲突的色调与光分句，媒介和成像或笔触分句不改写，观感写进正文；留着冲突的色彩词，模型会照它拍回全片色调。

## 2. 角色设定图

顺序：

```
<资产风格句>
<主体段 或 变体前缀句>  ← 基础造型写主体段（见 assets/character-sheet.md）；派生造型写变体前缀句
<固定布局段>           ← blurface 或 clearface，逐字复制
<光与表面段>           ← 按媒介三选一，逐字复制
[身份标记段]           ← 有标记才有
```

各段之间空一行。固定段原文在 `templates/cast-character.<媒介>.md`（媒介名见 assets/style-system.md），复制后填 `<< >>`，固定段不改写。特殊版式（定妆照、群像）不拼固定布局段，整段按那个版式写。

变体前缀句（换装、换发型、年龄跨度这类派生造型；受伤、淋雨是处境，不做造型，要出状态图时也用这句）：

```
{{<角色名>}}是同一角色的基础形象，本图仍是同一个人。严格保留其骨相、五官比例、瞳色、肤色、体型与身份标记；只把以下部分换成当前形象：<和基础形象的差异，原文照写>。上文没有提到的部分与基础形象一致。
```

- 同时挂 `--ref <角色名>=file:cast/<角色>.默认.png`。只拿基础形象当参考，拿变体会让误差一代代叠加。
- 跨年龄的变体，把「严格保留其骨相」改成「保留五官的辨识特征与身份标记」。
- 派生造型不重写主体段，没变的部分再描述一遍会和参考图打架。

比例默认 16:9（三联横版），模型不支持就用最接近的横幅比例。张数 1。

`## 设定` 里的外观改了，同步改造型小节的主体段（派生造型改变化短语）：提交的只是造型小节，只改设定，重出的图不会变。

## 3. 场景图、道具图

场景：

```
<风格句>
[母版句 或 换光句]     ← 只有这个版本从同一空间的母版派生时才有（主机位、夜景版、破坏后、换季）
<场景正文>             ← 见 assets/scene-plate.md
<固定布局段>           ← templates/cast-scene.<媒介>.md 里的原文，变体见 assets/scene-plate.md
```

母版句（光照和母版相同的版本：竖版主机位、同一时段的状态变化）：

```
{{<母版别名>}}是同一空间的母版画面：材质、光源方向、色调、年代与陈设保持一致，不新增母版里不存在的大件陈设。
```

换光句（换时段、换光或换画面观感的版本：黄昏、夜、停电、只开一盏灯、黑白监控）：

```
{{<母版别名>}}是同一空间的母版画面。保持空间结构、墙地材质、陈设种类与位置、取景方位完全一致；只把时段与光照改为：<本版本的光源技术句>，阴影、反光与窗外亮度随之改变；状态改为：<本版本的状态>；整张画面的观感改为：<本版本的观感>。
```

- 换光的版本不用母版句：母版句锁住光源和色调，和新光源矛盾，模型常留下母版的日光。换光句只锁空间几何，光和状态跟本版本走。
- 状态、观感没变就删掉对应分句；只换观感时，光照分句照母版写。
- 「取景方位完全一致」只对和母版同画幅同机位的版本成立。换光版的竖版主机位挂同时段的 16:9 版本，用母版句。

同时挂 `--ref <母版别名>=file:cast/<场景>.<母版版本>.png`。别名用场景名，跨场景借用时用「场景名·版本名」避免重名。

道具：`<风格句>` 加道具正文，比例默认 1:1。

用户自带的画风图：挂在基础形象或母版之后，风格句后写 `{{风格}}仅参考画风、笔触与色调，不继承其中的人物、物件和构图。`；写实项目的风格图里不能有人（见 `assets/style-system.md`）。

## 4. 视频片段

`templates/shots.md` 是按这个顺序排好的骨架：

```
基础视觉风格：<风格句>
（空行）
画面具体需要展示的内容：
<参考说明句>           ← 每个挂上的参考一句，顺序和 --ref 一致
<正文>                 ← 场景声明、电影感基调、分镜数和各分镜，见 shots/video-prompt.md
声音只有角色台词、环境声和动作音效；不要生成 BGM，不要生成旁白字幕、台词字幕或对白字幕。
```

最后一行是固定尾注，后半句逐字照写；前半句按这段实际有的人声列，有旁白、内心独白就写进去（「声音只有角色台词、旁白、环境声和动作音效」），不然模型会把它们当成被排除的声音。没有角色台词的段，正文末尾加「画面中所有出镜角色全程不说话。」，前半句去掉「角色台词」，否则模型常自己加画外音。BGM 每段各生成会在拼接处断开，字幕常是乱码，这两项用视频模型惯用的说法点名排除，措辞不改。画内文字见 `shots/video-prompt.md`「画内文字」。

参考说明句，按参考的种类选一种：

| 参考 | 说明句 |
|---|---|
| 角色 | `{{X}} 是角色X的形象参考（长相、发型、服装以此为准）。` |
| 场景 | `{{X}} 是场景参考（空间结构、陈设、光线以此为准）。` |
| 道具 | `{{X}} 是道具X的外观参考。` |
| 其他（尾帧、参考视频、预演、分镜图、音频） | `{{X}}：<仅参考什么，不继承什么>`，写法见 `shots/video-prompt.md` 的参考用法表 |

- 排序：角色、场景、道具、其他参考，`--ref` 同序。别名用名字；同一段同一角色两个造型时用「角色名·造型名」。
- 还没有图的角色或场景：不挂参考、删说明句，`{{X}}` 改回纯文字名并写一个能辨认的外观特征；人物一致性没保障，先告诉用户。

首尾帧模式（用一张图钉住开头画面，可选再钉结束画面）：

- 先确认 `model describe` 支持首帧（钉结束画面还要支持尾帧），用 `--first-frame` / `--last-frame` 挂。
- 这个模式只收首帧、尾帧两张图，普通参考全部摘掉、说明句删掉，`{{X}}` 改回纯文字名；人物长相只能来自首帧，首帧里人物要清楚。
- 首帧、尾帧各一张图，和片段画幅一致；前段尾帧取法见 `shots/continuity.md`「怎么挂」。

## 5. 生成参数

参数用 `--param k=v` 写进节点，报价和提交读的是同一份配置：

- 比例：项目比例（竖屏短剧通常 9:16）写在 README.md，所有视频节点一致。角色设定图按第 2 节，场景图按 `assets/scene-plate.md` 第 1 节（16:9 母版加 9:16 主机位），道具按第 3 节。
- 时长：整数秒，和分段表一致，在 `model describe` 给的范围内。
- 分辨率：取 `model describe` 的默认值并显式写上，不写时报价和执行可能按不同分辨率算。
- 参数传错时服务端可能悄悄降级并照常扣费，拿不准先看 `model describe`。

## 6. 提交前对一遍

- 风格句是 README 原文，只出现一次；视频的风格句在开头的「基础视觉风格：」后。
- 每个 `{{别名}}` 都有对应的 `--ref`，每个 `--ref` 都有一句说明句，名字逐字一致。
- 角色图、场景图：布局段逐字复制（角色图还有光与表面段），主体段末句重申媒介。
- 视频：尾注一字不差；首尾帧模式下没有混普通参考。
- 小节里没有给人看的备注。
