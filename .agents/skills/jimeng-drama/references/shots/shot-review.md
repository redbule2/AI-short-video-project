# 分镜自检与视频验收

分镜写完提交前、片段生成后验收、用户说某段不满意时用。

## 提交前自检

机械项交给工具：台词是否超载用 count_chars.py；`{{别名}}` 和 `--ref` 对不上 CLI 会在提交前拦下；时长、比例、分辨率、参考数对照 `model describe`。

所有段一起过一遍（之后每次改分镜，用户约束、超载、口型声音三行再过一遍），列出全部不通过项集中改一轮；复核只看改过的地方，再动别处会引出新问题。给用户只报不通过项和修法，用户约束一项逐条报核对结果。

| 检查项 | 不通过的判据 | 修法 |
|---|---|---|
| 叙事紧凑 | 看完没多知道任何事；10 秒以上少于 2 个叙事事件；段头先铺环境 1-2 秒才进正题 | 从冲突进行中起拍；缩时长或并入相邻段 |
| 钩子在画面上 | 开场 3 秒无可见冲突；集尾只靠台词或问题不明的背影 | 按 segmenting.md 导演方案的起手和收尾改 |
| 拍得到 | 比喻、心理描写、抽象情绪、否定式描写 | 改成面部、肢体动作和音效 |
| 穿模风险 | 肢体纠缠（拥抱、扑倒、扭打）；物体穿插（戴戒指、系领带、插钥匙）；复杂道具交互（翻书找页、手机打字）；形变 | 中远景或遮挡；只拍结果；局部加音效；拆成动作前和结果两个镜头 |
| 运镜单调 | 相邻段主运镜相同；对白一镜到底超 5 秒且非有意长镜头 | 换主运镜；按 dialogue-and-sound.md 插调度 |
| 用户约束 | README.md 用户约束清单（机位、运镜次数、表演、动作顺序、检查点）有没落实的；分镜改了剧本 △ 的动作或结局画面 | 逐条对照改；确需偏离的交付时列出原因 |
| 超载 | 一个阶段多于 1 个主动作或 1 个运镜；有动作的阶段短于 2 秒；缓推、环绕、转身这类靠渐变才看得出的短于 3 秒（经验值，是下限不是每拍默认时长，切细阶段不会多出时间）；同框精确描述超 3 人；单镜头超 2 句台词；违反常态的动作（倒着走）照常写 | 删动作、拆阶段或镜头；次要角色降为背景；调分段。时长被用户定死时减镜头、无台词反应拍并进相邻镜头、短阶段用固定机位、旁白不卡在某一秒起；反常动作改成拍结果或换机位 |
| 空间朝向 | 有阶段没标绝对朝向或视线落点；正面机位的人直视镜头且非剧情要求；背面或远景承担表情、文字等细节；对峙双方都面朝镜头；切镜后左右互换；距离和景别不配 | 按 video-prompt.md「结构」和 dialogue-and-sound.md「多人同框与站位」修 |
| 口型声音 | 说话的人没写口型或不说话的没闭嘴；说台词用大特写；过肩里背对的人开口；os 期间有人张嘴 | 按 dialogue-and-sound.md 修 |
| 指代自包含 | 他、她、那人，「接上一段」；复写了参考图外观 | 改 `{{名字}}`；补起始状态；删外观 |
| 状态连续 | 前段动作没做完或后段重演；道具凭空换手或消失；处境措辞不一致 | 按 continuity.md 修 |
| 台词保真 | 和 story/ 剧本（或 source/ 原分镜）比有字词标点不同、漏句、换了说话人、os/vo 被改 | 恢复原文，装不下回分段处理 |
| 禁写项 | 命中 video-prompt.md「不兑现或有害的写法」 | 按那张表改 |

用户确认过的台词、动作、参考用途和硬约束，不为了过自检而改。

## 视频验收

交付前每段完整看一遍、听一遍，再用 `jimeng-novel frames --every 1` 每秒抽一帧，对照 `shots/E01.md` 逐个时间阶段比人数、道具颜色数量、背景结构；偏差逐条列出（哪段、第几秒、写的什么、画的什么）再决定重做还是交付，只抽几帧会漏。台词用 `transcribe <段> --text-file <本段台词，一行一句>` 核对（报价见 post/compose.md，无台词段给空文件）：对不上的行是漏说说错，多出的语音是模型自加；有说话人标注就对照，没有就看那一刻谁张嘴。宿主放不了视频或听不了音频时，标出未核验项请用户补看补听，不说已验证。

| 项 | 看什么 |
|---|---|
| 台词 | 逐字说完；没漏字吞字重复，没说剧本外的话；语速正常 |
| 口型（最不稳，先看） | 说话的人嘴在动且对得上；不说话的闭嘴；声音没安到别人身上 |
| 人物 | 脸、发型、服装和参考图一致；没多人也没人消失；路人没长成主角的脸 |
| 穿模形变 | 肢体、手指、道具没穿插、融化、多指；物体没凭空变形 |
| 运镜 | 方向、速度、起止景别兑现；没有莫名跳轴 |
| 空间 | 站位、朝向、站或坐和正文一致；在场人数对；场景结构和参考图一致 |
| 节奏 | 没空转、呆站、抢拍；结尾停在稳定画面，最后一秒没被模型自己压暗成黑场；钩子看得出 |
| 衔接 | 和相邻段连着看，站位、光线、道具接得上 |
| 违禁 | 字幕、乱码、水印（平台「AI生成」标识不算）、BGM、黑色光晕 |

结论按 `段 / 时间点 / 问题 / 建议` 列，附看过的拼图或视频，没问题也说明查了哪些。已核验部分分三档：通过；局部瑕疵可接受，交给用户定；不通过，先归因再改。未核验项单独标出。

## 不满意时：先归因，再动手

不改任何东西直接重抽，多半还是同样的问题，白花积分。

| 根因 | 典型症状 | 怎么确认 | 改哪里 |
|---|---|---|---|
| prompt | 运镜、朝向、口型归属错，而正文本就含糊或矛盾；出了正文里写着的禁写项；代词导致换脸 | 能指出是哪一句造成的 | 只改这段的小节正文 |
| 分段 | 台词说不完或语速过快；结尾空转、胡言乱语；动作太多跳变；和相邻段接不上 | count_chars.py 复算，看导演方案 | 回 segmenting.md 调时长或分段；衔接问题按 continuity.md |
| 参考图 | 脸或服装整体偏；场景结构不对；所有段都有同一问题 | 检查挂的造型和场景版本对不对、图本身质量 | 换图或补图，回资产环节；先告诉用户会影响哪些段 |
| 模型局限 | 正文清楚、分段合理，复杂肢体、手指、群戏、快速动作仍反复崩 | 换写法后仍复现 | 降难度：遮挡、中远景、只拍结果、拆镜头；不行就和用户商量改这个动作 |
| 随机性 | 同一 prompt 偶尔一次小瑕疵 | 前几类都排除 | 只有这种才不改 prompt 直接重抽 |

- 同一段连续两次不满意，把归因和可选方案列给用户。
- 改动只限当前段；波及站位锁、处境措辞或场景版本时列出受影响的段让用户决定；依赖它尾帧的段按 continuity.md 处理。

## 被内容审核驳回

默认先改写：原样再提可能还是被拒，侥幸通过也不知是哪句触发，下一段照样撞上。找出可能触发的描写（暴露、血腥、伤口细节、暴力过程），不改剧情换成含蓄拍法：遮挡、拍结果不拍过程、交给音效。敏感内容在台词里时按铁律 2 先问用户。告诉用户改了哪几句、为什么，把「按改后的版本提交」和「原样再提一次（审核有随机性，同样花积分）」作为选项，两种都按铁律 1 重新报价。图片被驳回同样处理。
