# 视频 prompt 正文写法

讲 shots/E01.md 每个 `## S01` 小节的正文怎么写。完整 prompt 怎么拼（参考说明句、风格句、尾注、首尾帧）见 prompt-anatomy.md；有台词和音效时同时看 dialogue-and-sound.md。

## 只写摄像机拍得到的

模型只看画面、听声音，理解不了叙事逻辑和抽象情绪。

- 比喻、心理描写、抽象情绪词、「不是 X 而是 Y」拍不到，换成面部和肢体动作：「她很震惊」写成「瞳孔一缩，手里的文件滑落」。
- 否定句会召回实体（写「没有狗」，狗反而出现）。要排除的东西不提，非提不可就写短而具体、绑定对象的约束。
- 表演幅度往小写：模型会把情绪演大（「流泪」演成号哭）。克制的情绪只写一个小幅度的可见动作（眼眶泛红、喉结滚动），不叠强情绪词。妆容和生理状态同样会被放大：「黑眼圈」常画成淤青，疲惫写成体态（肩膀塌下、揉眼）。
- 物理限制写成可见状态并说全程保持：「门链拉直，门只开一掌宽，整段保持」。只写「隔着门缝」，模型会按常态把门开大。
- 做减法：写得越多，每条被执行的概率越低。删掉后画面不变的句子不留；优先级是核心动作和台词 > 运镜 > 环境修饰。
- 自包含：每段独立生成，场景、站位、朝向、手中道具、伤痕污渍、在场的持续道具（没挂图的写外观）和环境状态（室内外、天气、时段）每段重写（见 continuity.md「持续道具与环境」）；上一段演过的动作、说过的台词不再演。段首的环境句只写空间、陈设和天气，人物的伤、妆、神情写进他入画的那一拍，原因见 dialogue-and-sound.md「口型」。

## 结构

```
本片段场景设定在：{{场景}}。[在场的持续道具、陈设与环境]。整体电影感基调：[本段的光影质感、构图与情绪，一句]。生成一个由以下 N 个分镜组成的视频。
分镜1：3秒：[景别]，[机位]。[每个出镜角色的位置 + 绝对朝向 + 视线落点 + 姿态 + 手中道具]。[运镜，带速度、距离、方向]，[动作过程] → [台词嵌在它发生的那一刻] → <音效>
分镜2：3秒：[切镜方式] ……
```

- 每个分镜就是一个画面阶段（下文和 segmenting.md、shot-review.md 说的「阶段」）。各分镜写整数秒，加起来等于段时长，N 和实际分镜数一致；换景别、硬切就开新分镜，每个动作才有自己的秒数。
- 电影感基调写明暗反差、景深、构图倾向这类质感和情绪，不另定主光方向和色温（主光跟场景图，见下）。
- 一个阶段只放一个主动作、至多一个运镜，多了模型会漏，多出来的拆到下一阶段。拆阶段不多出时间，每个阶段要够演完它的动作（「同一镜头延续」也算一个阶段），阈值见 shot-review.md「超载」。
- 要观众看清的东西，得在这个景别、朝向和遮挡下真看得清：背对镜头不写表情，远景、全景只承载空间、站位和大动作，不靠眼神、文字和手上细节，浅景深不虚掉关键物。看不清的描述模型要么硬改机位，要么丢掉；装不下就换景别或拆阶段。
- 每个阶段开头写出镜角色的位置、绝对朝向（面朝镜头 / 背对镜头 / 侧身朝左 / 侧身朝右）和视线落点（具体的人、物或画外方位）。不写落点模型默认让角色直视镜头；落点是画外的人时，让被看的人以过肩前景或虚化背影留在画内。「面向对方」多半被拍成两人都面朝镜头。硬切后重标朝向，并一句重申所在环境和机位背后看得到什么（正反打写明两人隔着同一物件），不重申切镜后会换地方。
- 每拍开头的姿态接上一拍结尾，姿态变化写成动作过程；大的姿态变化不放在硬切点上。
- 主光的方向和色温跟挂的场景图走，正文另起一套会让模型来回翻光。正文只写本段特有的局部光和剧情触发的光变化：光源、落在哪个锚点、变化后的样子（「落地灯从画面右侧打出暖黄侧光，{{男主}}半边脸落在阴影里」）。没挂场景图时主光也由正文写。「灯光昏暗」等于没写。
- 动作写过程不写结果（「翻身下马，缓步走近」，不是「下马靠近」）；剧烈动作绑环境锚点：倒在哪、撞到什么、哪只手撑住。
- 近景和特写写材质与光在表面上的样子：「纸面折痕在暖光下投出细影」。
- 段尾停在稳定画面：动作已完成、视线有落点、说完嘴唇合拢。停在挥拳、转身中途，下一段接不上，成片也像被掐断。

## 竖屏构图

9:16 画面窄而高，横向放不下多人并排。

- 主体放中轴附近，人物多用中景到近景，单人胸像最稳。
- 两人同框优先前后纵深或过肩，左右并排会被挤到边缘或裁掉。面对面的关系（对坐、隔桌）在竖屏双人镜头里常被画成并排同坐，文字拦不住：用正反打单人镜头，确需同框用过肩，或先出分镜图、首帧钉住站位。
- 竖向空间用起来：仰拍立压迫感，俯拍交代站位，上下摇代替左右摇。
- 远景、全景人脸小、长相会漂：要认出是谁的镜头（亮身份、反应、说台词）用中景到近景，远景靠服装色块和位置认人。

## 参考绑定与回指

- `{{别名}}` 和 `--ref 别名=` 逐字一致，对不上 CLI 会在提交前拦下。
- 只绑名字，不复写外观：「{{女主}}（黑长发、白衬衫）」会和参考图打架。文字只写图上看不到的、本段才有的变化（湿发、嘴角血迹、哭红的眼眶）。
- 回指都写 `{{名字}}`，不用他、她、那人、对方：空指代会被当成新人物，换脸或多出一个人。
- 场景在「本片段场景设定在」写一次 `{{场景}}`，后文用图里的锚点物定位（「八仙桌」「挂钟」），不编造图里没有的东西；段内换到另一个场景时，在那个分镜开头写「场景切换到：{{场景}}」。
- 没挂参考的人物（路人、群众）用一个辨识特征带过，例如「穿灰色保安制服的中年男人」，最多写 2 个，其余写成背景。

## 其他参考的用法

参考视频、音频、分镜图、预演、尾帧整体引用会把无关的人物、场景、色调带进来，正文用「仅参考 X，不继承 Y」限定：

| 参考 | 限定 |
|---|---|
| 参考视频 | 仅参考运镜轨迹与节奏，不继承人物、场景、色调、声音 |
| 前段尾段视频 | 仅参考站位、服装状态与光线，不继承台词，不重复已完成的动作 |
| 参考音频 | 写明仅参考音色与语速，还是仅参考环境声氛围 |
| 分镜图 | 按其画面内容与顺序展开，不继承格子分割 |
| 白模预演 | 仅参考镜头运动、景别变化与节奏，不继承画面、造型、颜色、文字（见 previs/previs.md） |
| 前段尾帧 | 作为本段之前的画面状态，只承接空间状态，不锁构图 |

能挂几个、参考视频多长以 `model describe` 为准，超了可能被静默丢掉。首尾帧何时用见 continuity.md，怎么拼见 prompt-anatomy.md 第 4 节。

## 画内文字

模型画字常是乱码，数字会崩，品牌会自己编，而这些字常是剧情线索。图和视频都按这条处理，屏幕、招牌、道具和陈设上的字（价签、名牌、按键、门牌、证件）都算：

- 剧情关键的文字和数字（时间、金额、编号、名字）不交给模型画：拍成读不出字的样子（拍背面、手指遮住、失焦、屏幕亮着但没有字），内容在合成时用字卡叠加（见 post/compose.md）。
- 非关键的写成无字形态：熄灭的屏、只有色块的海报、空白价签、只有符号的按键；设备写素面边框，不写品牌。「几行印刷字迹」这类空泛写法会让模型自己编。
- 例外：一两个不关键的大字号短词（2–4 字）可以写成【】里的原文，只留这一处。

## 屏幕里的画面、监控、回忆

这类画面不是此时此地，模型却会照挂的参考图和风格句把它拍成眼前的真实空间。

- 观感（黑白、噪点、褪色）写成这个镜头的画面质感；挂的场景图用同样观感的版本（见 segmenting.md「其余绑定」），风格句按 prompt-anatomy.md 第 1 节删分句。
- 屏幕里的内容要观众看清，就单独一个镜头让它铺满画面。人和屏幕同框时，屏里只放一眼能认的简单内容（一个人影、一片亮光），不挂屏内地点的场景图，挂了模型会把那个地点当成人所在的空间。

## 运镜表

运镜从下表选，补上速度、距离、起止景别；自由描述（「镜头慢慢飘过去」）的速度、方向、距离模型随机发挥。

| 运镜 | 标准写法 |
|---|---|
| 固定 | 固定机位，镜头位置和方向不变，由人物动作形成运动感 |
| 左/右摇 | 固定机位向右摇，只水平转动，画面重心移向 X |
| 上/下摇 | 固定机位向上摇，从 X 的鞋面摇到面部 |
| 缓推 | N 秒内缓慢前推，从中景推至 X 胸部以上近景 |
| 急推 | 1 秒内急速前推，从中景冲至 X 面部近景，带轻微冲击晃动 |
| 后拉 | N 秒内缓慢后拉，从 X 近景拉至全景，露出周围的人 |
| 变焦推进 | 机位不动，焦距逐渐收紧到 X |
| 急速变焦 | 机位不动，画面范围骤然收紧到 X，形成突然强调 |
| 希区柯克变焦 | 机位后退的同时变焦推进，X 大小不变，背景透视剧烈变化 |
| 左/右移 | 镜头向右平移，拍摄方向不变，前景与背景产生视差 |
| 横滑揭示 | 镜头从遮挡物后横向滑出，逐步露出 X |
| 升/降 | 镜头垂直上升，视角由平视转为俯视 |
| 俯冲 | 镜头从高处快速下降靠近 X，形成压迫感 |
| 拉升离场 | 镜头从 X 附近向后上方拉起，X 逐渐变小 |
| 环绕 | N 秒内镜头围绕 X 平稳环绕约 180 度，X 始终在画面中心 |
| 跟拍 | 镜头在 X 身后跟随，保持固定距离 |
| 迎面跟拍 | 镜头在 X 前方随其步伐同步后退，保持正面 |
| 侧跟 | 镜头在 X 侧方与其平行移动 |
| 稳定器行进 | 稳定器平滑向前行进，晃动很小 |
| 手持 | 手持拍摄，轻微自然晃动，近距离临场感 |
| 主观视角 | 第一视角模拟 X 的视线，带轻微头部晃动 |
| 高位俯拍 | 高角度俯视并缓慢滑行，交代人物站位与空间布局 |
| 甩摇 | 镜头快速水平甩向 X，带短暂运动模糊后停稳 |
| 过肩 | 从 A 肩后拍向 B，A 背对镜头作前景只露后脑和肩，B 面朝镜头 |
| 低机位仰拍 | 低机位仰拍 X，X 显得高大有压迫感 |
| 慢动作 | 在 X 的关键瞬间动作放慢约 1 秒，随后恢复正常速度 |
| 前景擦过 | 近处遮挡物从镜头前掠过、短暂覆盖画面，随后露出 X |
| 焦点转移 | 机位不动，焦点从前景 A 平滑转移到后景 B |

- 运动类运镜写速度（缓慢、快速、N 秒内）；组合运镜拆成两个阶段。景别或角度跨度大到连续不到的，写「硬切」。

## 不兑现或有害的写法

| 写法 | 后果 | 改成 |
|---|---|---|
| 「一秒摇头 3 次」这类时间戳控频次 | 不兑现 | 写意图：「连续快速摇头」 |
| 「占画面 1/3」这类分数 | 不兑现 | 景别加身体截取：「胸部以上近景」「全身入画但身影偏小」 |
| 8K、UE5、masterpiece、RAW 等图像词 | 白占注意力 | 删 |
| 段末淡出、入黑、渐暗、暗角收拢 | 渲染成黑色光晕伪影 | 实体画面收束，黑场在成片阶段加 |
| 形变特效：剑身弯曲、光柱缩成一点、连续变身 | 严重形变崩坏 | 一次性冲击白光、火星、碎裂粒子、光痕，配音效 |
| 「字幕：……」、要求屏幕显示台词 | 竖屏本来就易冒字幕和乱码 | 删，字幕在成片加 |
| 「接上一段」「同上」「延续刚才」 | 模型看不到上一段 | 重写起始状态 |
| 「所有人看着她」「两人对视」 | 全员面朝镜头或朝向乱 | 写绝对朝向，对峙首选过肩 |
| 「不要崩坏、不要变形」 | 白占注意力 | 删；确需负向约束就短而具体：「{{男主}}不直视镜头」 |
| 正文里写 BGM、配乐 | 生成阶段的音乐无法统一 | 删，BGM 在成片加 |

台词与剧本逐字一致，用中文双引号括起，不用花括号（花括号留给参考）。整段自检见 shot-review.md。
