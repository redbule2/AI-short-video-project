# Seedance 2.5 视频提示词 · 通用格式

本技能规定 Seedance 视频提示词的通用格式。

## 使用方式

1. 先读取本项目的 [sd25-pe](../sd25-pe/SKILL.md)。本技能只规定格式；和 sd25-pe 冲突时，以 sd25-pe 为准。
2. 普通视频生成：按「二、模板骨架」写，把 〔 〕 里的内容换成本片的，括号本身删掉；写完按「七、交付前自检」逐条过一遍。
3. 向前延长、向后延长和视频编辑：不套模板骨架，改用「八、局部重做：延长和编辑」的写法。
4. 每段交付一个提示词文件，文件名遵守本项目 AGENTS.md；文件里只放提示词正文，不加标题、说明或代码围栏。
5. 同一个项目里已经写好的段落用的是旧格式时，后面的段落继续用旧格式，保持全局部分逐字一样；新项目再用本格式。

---

## 一、总规则

1. **分区顺序固定**：说明｜基础设定 → 人物与参考图对应 → 声音 → 场景 → 规则｜镜头原则 → 分镜 → 保持一致。
2. **全局部分各段逐字一样**：基础设定里除“本段事件”以外的各项、人物特征句、声音、场景、规则｜镜头原则。
   **每段不一样的有四处**：本段事件、人物与参考图对应里的本段说明、分镜、保持一致。
3. **不写时间码和秒数**。时长在生成参数中设置。
4. **分段**：每段不超过 30 秒，按剧情和节奏分，段数能少就少；时长贴着内容定，多出来的秒数会变成干等。
5. **文件名**：遵守本项目 AGENTS.md 的文件命名规则。
6. **符号**：台词用 `{}`，音效用 `<>`；`<>` 只给音效，人物称谓不加 `<>`。提示词里不用中英文括号、不用引号；【】只用于 sd25-pe 规定的 `【未采用素材】` 这一处。没要求时不写“普通话”。
7. **生成参数不写进提示词**：画幅、时长、分辨率、声音开关都只在页面上设，提示词里不写“画幅：横屏 16:9”“横屏构图”这类字眼。参数是：全能参考，16:9，声音打开，720p，时长按实际生成参数。
8. **@编号只出现在三处**：人物与参考图对应（含首帧和【未采用素材】）、每个镜头的“本镜调用”、保持一致。动作、音效、镜头、台词、画面构图里只用称谓。

## 二、模板骨架

```text
说明｜基础设定
影像风格：〔片种和题材〕，〔写实电影摄影 / 其他风格〕，〔胶片或画面质感〕；〔保留哪些真实质感，如皮肤纹理、衣料、食物〕，不美颜磨皮。人物表演自然，情绪靠动作和表情带出来，不做夸张表演。
摄影与镜头：〔宏观镜头语言：焦段倾向、透视、景深、手持呼吸感〕。
光色基调：〔时间段的整体明暗冷暖〕；〔主光来源〕，〔对比度和饱和度〕，〔肤色〕，〔暗部〕，〔关键物件的颜色真实〕。
核心氛围：〔时间和地点的一句画面〕。〔人物在做什么，相处的感觉〕；整体〔真实、温暖……〕，不煽情。
本段事件：〔本段从头到尾发生了什么，几句话讲完，写到结束时的状态〕。

人物与参考图对应
女主对应@图片1，本段外貌、发型和服装以@图片1为准。〔全局人物特征句，只写看得见的表现〕
男主对应@图片2，本段外貌、发型和服装以@图片2为准。〔全局人物特征句〕
〔配角〕对应@图片3，外貌和服装以@图片3为准；〔始终在哪个位置〕。
〔本段特殊状态，如：女主的手机本段一直是黑屏；男主的手机正常。〕
〔关键道具没有参考图时：全程只有一个〔道具〕，只由〔谁〕拿，递出去以后只在〔谁〕手里。〕
〔关键道具有参考图时：〔道具〕对应@图片〔N〕，只采用结构、材质和颜色；全程只有一个，只由〔谁〕拿，递出去以后只在〔谁〕手里。〕
@图片4是〔场景名〕从〔哪〕往〔哪〕看的样子，只采用空间布局、陈设、材质和灯光，〔不采用它的拍摄方向〕。
@图片5是〔场景名〕从〔哪〕往〔哪〕看的样子，只采用空间布局、陈设、材质和灯光。
@图片N作为首帧。
该首帧定义〔开场的构图、人物位置、姿态、道具状态、镜头朝向〕。
本段画面里只有〔几个人：谁、谁、谁〕，只有一个〔店员〕；〔其他人〕没有。

【未采用素材】
〔只在上传了本段不用的图时写，否则整段删掉〕@图片〔N〕、@图片〔M〕未参与本段，不用于人物、场景、道具、动作或镜头。

声音
环境音全程铺底，不出现干净的静音。〔外景环境声〕。〔内景环境声〕。
人声近距离收音，自然、生活化，带真实的呼吸和口腔细节；说话的人口型与台词同步，不说话的人自然闭口；有台词时人声在前、听得清，环境音不断；〔画外喊声 / 旁白的距离感〕。
动作拟音清晰、贴近画面，只跟着画面里的动作出现：〔<音效1>、<音效2>、手上动作的声音〕都要听得清。
〔全片无旁白 / 心里话以画外旁白出现，角色不开口〕，画面不显示字幕。

场景
〔场景A〕：〔位置、外观、招牌、门窗、周边环境〕。
〔场景B〕：〔空间形状；从门口往里看，左手边是……，右手边是……；关键陈设和墙面〕。
〔场景C〕：〔……〕
时间：〔具体时间〕。
配乐：无配乐，后期统一加。

规则｜镜头原则
运镜：全片不使用完全固定的机位。以轻微手持呼吸感、缓推、缓拉、横移和跟随为主；人物说台词时运动放缓，幅度小而平稳；不做快速甩镜和炫技运镜。
构图：〔内景保留纵深，哪些背景元素要清楚可辨〕；〔外景什么是画面里最亮的部分〕。〔关键道具和人物的手〕是关键道具，出现时必须清楚可辨。主体清晰，背景适度虚化。
轴线：〔以什么为轴，两侧各是什么：从门口往里看，A在左、B在右；从里往门口看，B在左、A在右〕。同一场戏里人物的左右位置保持不变，不越轴。

分镜

镜头1｜〔标题〕
机位/景别/角度：〔景别，角度，机位在哪，朝哪个方向拍〕
本镜调用：〔画面里的每个人带编号，如女主@图片1、店员@图片3；只露局部的写露哪里；中途才进画面的写从哪个小节进来〕；〔本镜出现的关键道具〕。
画面构图：〔谁在画面哪一侧，隔着什么；背景是什么，〔柜台〕在画面哪一侧；不拍反打〕。
环境音：〔本镜的环境声由哪些声源组成，哪个离机位近、哪个在远处〕。
进入状态：〔镜头开始时每个人在哪、手里拿着什么、在做什么；不提前摆好后面的动作〕。
小节一
动作/表情：〔动作和表情，台词和手上的事叠着走〕。
音效：〔发声的物件和接触〕<〔音效〕>；〔画面外的声音写明画外〕。
镜头：〔怎么动〕。〔环境声〕从第一帧就有。
台词：〔说话人〕，〔语气〕：{〔台词〕}画内发声，口型与台词同步，看着〔谁〕说；其他人自然闭口。
小节二
动作/表情：〔……〕
镜头：〔怎么动，带一笔环境声〕。
台词：无
退出状态：〔镜头结束时的画面，下一镜的进入状态要接上它〕。
切点：〔跟着哪个动作切到哪里〕。

镜头2｜〔标题〕
机位/景别/角度：〔……〕
本镜调用：〔……〕
画面构图：〔……〕
环境音：延续上一镜的〔……〕；〔机位变了以后，哪个声源变近、哪个变远〕。
……

镜头N｜〔标题〕
……
镜头：〔怎么动〕。〔环境声〕一直持续到最后一帧。
……

保持一致
女主始终对应@图片1，男主始终对应@图片2，〔配角〕始终对应@图片3，几个人的脸、发型和服装不互换。
本段画面里最多〔几〕个人；〔道具〕全程只有一个，最后在〔谁〕手里。
〔轴线口诀〕，全段不越轴。
环境音全段不断。
```

## 三、各分区怎么写

### 说明｜基础设定
- 五项依次是：影像风格、摄影与镜头、光色基调、核心氛围、本段事件。画幅不写进提示词，在页面参数里设。
- **摄影与镜头只写宏观的**：焦段倾向、透视、景深、手持感。具体景别和运镜留给分镜。
- **核心氛围**用画面写，不堆形容词：写清“几点、在哪、谁在干什么”，再落一句整体感觉。
- 别写“店里很安静”“表演克制”这类词，画面会变单薄。
- **本段事件**是每段唯一要改的一项。写清因果和结束时的状态。

### 人物与参考图对应
- 人物拼版定妆图（面部特写加正侧背三视图）不加特殊说明，直接写：`女主对应@图片1，本段外貌、发型和服装以@图片1为准。`
- 拼版图被读成两个人、同一个人出现两次时，先在这一行后面补一句 `画面里只有一个女主。`；还不行，把拼版拆成一张脸部特写加一张全身图，分两行写同一个女主，再加一句 `@图片1和@图片2是同一个人，画面里只有一个女主。`
- 一行只对应一个人或一张图，不写“女主和男主分别参考@图片1、@图片2”这种合并句。
- **称谓定了就不换**：这里叫女主，分镜、台词、保持一致里都叫女主，不换成她、女孩、对方。同框有两个同性别的人时，一个代词都不用。
- 人物特征句只写看得见的表现，比如“不好意思时会抿嘴、眼神躲开”。不写“少女感”“强势气质”这类标签。各段逐字一样。
- **场景图**只采用空间布局、陈设、材质和灯光；镜头朝哪拍、景别和人物位置在分镜里用文字写。
- 同一个室内场景，两个朝向的图一起喂，防止方向弄反。写明哪张只交代布局、不采用它的拍摄方向。
- **关键道具有参考图时**单独一行，写只采用什么、全程几个、归谁；没有参考图时只写数量和归属。
- **首帧**单独写一句 `@图片N作为首帧。`，下一句接 `该首帧定义……`。文字描述要和首帧一致，矛盾时模型会听文字。首帧和关键帧必须是 16:9。
- **人数写死**：`本段画面里只有这几个人，只有一个店员`，否则会多出人来。
- 关键道具写死数量和归属。
- 只上传本段用到的图。如果上传了不用的图，在本分区末尾加 `【未采用素材】`，逐个列出编号，写明不用于人物、场景、道具、动作或镜头；不能写成“其他素材”。

### 声音
- 只写全局的，不在这里设计具体台词。
- 环境音必须有，分外景、内景写清楚来源。没了环境音，视频会很干瘪。每个镜头听到哪一层，在分镜的“环境音”里写。
- 写明：口型同步、不说话的人自然闭口、有台词时人声在前而环境音不断、画外声的距离感、动作拟音用 `<>` 点名、画面不显示字幕。
- 这里用 `<>` 点名的音效，只放全片反复出现的，比如碗筷、脚步、衣料；只在某一段、某一镜出现的声音，写进分镜的音效行。
- 心里话只能是画外旁白，角色不能说出来。没有旁白时写“全片无旁白”。

### 场景
- 每个场景一段。室内写清从门口往里看，左手边是什么、右手边是什么。
- 最后两行固定是 `时间：……` 和 `配乐：无配乐，后期统一加。`

### 规则｜镜头原则
- 固定三项：运镜、构图、轴线。
- 运镜：禁止完全固定的机位，至少带轻微手持呼吸感。
- 构图：不写“横屏构图”，画幅只在页面上设。
- 轴线：用稳定物体（过道、桌子、柜台）定左右，写一句方向口诀。

### 保持一致
- 放在全文最后，把最怕出错的几件事再说一遍；sd25-pe 的生成模板也是以保持一致收尾。
- 只写四句：谁对应哪张图、本段最多几个人和关键道具最后在谁手里、轴线口诀、环境音不断。不加新信息，写法和前面一致。
- 编号照本段的人物与参考图对应抄，换图重排编号时这里一起改。

## 四、分镜写法

每个镜头的结构：

```text
镜头N｜标题
机位/景别/角度：
本镜调用：
画面构图：
环境音：
进入状态：
小节一
动作/表情：
音效：
镜头：
台词：
小节二
……
退出状态：
切点：
```

要点：

- **机位/景别/角度**：写清机位在哪、朝哪拍。不写“女主过肩”这种有歧义的说法，要写“越过男主肩膀拍女主”。
- **本镜调用**：这一镜画面里有谁、有哪些关键道具，在这里点名带编号；其他行只用称谓。
  - 人物：画面里看得见的人全部列出，带编号；只露局部的写露哪里，比如 `男主只露右肩`。没列的人本镜不出现，容易被带进来的人补一句 `男主本镜不出现`。画外说话的人不列，台词里写画外发声。空镜、物件特写写 `画面里没有人`。
  - 中途才进画面的人和道具，写明从哪个小节进来，比如 `男主@图片2，小节二从门口入画`。不写的话可能一开场就在画面里，和进入状态不提前摆好是一个道理。
  - 道具：只列本镜出现的关键道具；在哪、在谁手里写进进入状态。
  - 不点场景图。场景和朝向写在机位/景别/角度和画面构图里。
  - 编号要和人物与参考图对应里的一致，换图重排时每一镜都要改。
- **画面构图**：写谁在画面哪一侧、背景是什么、柜台在哪一侧，容易反的镜头加“不拍反打”。不写@编号，更不写“以@图片N为准”。
- **环境音**：每个镜头一行，写这一镜的环境声由哪些声源组成，哪个离机位近，哪个在远处。
  - 中间的镜头写“延续上一镜的……”，再写机位变了以后哪个声源变近、哪个变远。
  - 换场景时写清怎么换，根据镜头位置和声源变化交代声音远近。
  - 安静的场面也写声源：冰柜低鸣、钟表走针、远处偶尔一辆车。不写“安静”“寂静”，道理和基础设定里不写“店里很安静”一样。
  - 续接下一段时，新一段首镜的环境音照上一段末镜的内容写全，不写“延续上一段”——模型看不到上一段。
- **进入状态**：只写开始时的样子，不提前摆好后面的动作。不得提前摆出后续事件所需的动作或姿态。
- **音效**：有要特别听清的动作声时，在发出声音的那个小节加一行；没有就不写这一行，交给声音栏里的动作拟音。
  - 写发声的物件和接触，后面跟 `<>`：`碗底碰到台面<咚>`、`筷子落在碗沿<嗒>`。不把人物动作再写一遍，比如不写“女主把碗放到台面上<咚>”；官方指南要求不重复描述同一动作。
  - 画面外的声音写明画外：`画外后厨传来出餐铃<叮>`。
- **镜头**：每个小节都写镜头怎么动，并带一笔环境声。第一个镜头写“从第一帧就有”，最后一个镜头写“一直持续到最后一帧”。
- **第一帧**就要有动作和声音，开场才不空。
- **退出状态**要和下一镜的进入状态说的是同一个画面。
- **切点**跟着动作切，写清切到哪里。也可以用声音带切：切点前先给出画外声，再写明跟随该声音切到下一画面。

## 五、台词写法

```text
台词：说话人，语气：{台词}画内发声，口型与台词同步，看着谁说；其他人自然闭口。
```

- 说话人不在画面里，写“画外发声”，并写画面里的人自然闭口，否则口型会配到画内人嘴上。
- 没有台词写 `台词：无`。
- 每句都写看着谁说。道谢看对方，问店员就看店员。
- 台词原文只在 `{}` 里出现一次，语气说明里不要用引号复述台词里的字词。
- 心里话写成画外旁白：`台词：女主，画外旁白，内心独白：{……}画外发声，女主自然闭口，不开口说话。`
- 语气写法：
  - 别写“语速快”，会说得又赶又硬。要急就写“慌慌张张，一口气说下来”。
  - 别写“停一拍”“拖一拍”“没出声”“没催”，会拍成干等。
  - 台词和动作叠着走，说话时手上的事不停。
- 台词里的多音字、生僻字被读错时，把读错的那个字换成读音相同的常用字再生成，其他字不动。

## 六、符号表

| 内容 | 写法 | 例子 |
|---|---|---|
| 台词 | `{}` | `{好嘞，扫这儿哈。}` |
| 音效 | `<>`，分镜里前面写清声源 | `筷子落在碗沿<嗒>`、`画外出餐铃<叮>` |
| 环境音 | 不加符号，写声源和远近 | `锅里的咕嘟声在近处，冰柜低鸣在远处` |
| 人物称谓 | 不加符号 | `女主`、`店员`，不写成 `<女主>` |
| 配乐 | 不写进分镜 | 场景末行写 `配乐：无配乐，后期统一加。` |
| 字幕 | 不出现 | 声音栏写 `画面不显示字幕。`，字幕后期加 |
| 未采用素材 | `【未采用素材】` | 全文唯一允许的【】，只在上传了不用的图时出现 |

屏幕文字（弹窗、聊天界面、余额不足之类）模型画不准，特写尽量简单，必要时后期贴字。

## 七、交付前自检

- [ ] 七个分区齐全，顺序对；基础设定是五项，没有画幅那行；规则里没有“横屏”。
- [ ] 全局部分和其他段逐字一样，只有本段事件、本段说明、分镜、保持一致不同。
- [ ] 全文没有时间码、秒数、画幅、分辨率；每段目标时长不超过 30 秒。
- [ ] 没有中英文括号、引号；【】只出现在 `【未采用素材】`；台词在 `{}` 里，音效在 `<>` 里，人物称谓没加 `<>`。
- [ ] 上传了不用的图时，`【未采用素材】` 逐个列出了编号。
- [ ] 每张参考图都写了只采用什么；首帧单独一句“@图片N作为首帧。”。
- [ ] @编号只出现在人物与参考图对应、本镜调用、保持一致里；分镜里没有“以@图片N为准”，也没有点场景图。
- [ ] 每个镜头都有本镜调用：列全了画面里的人，编号和人物与参考图对应一致；中途进画面的人和道具写了从哪个小节进来。
- [ ] 分镜里的称谓前后一致，没有用她、他、对方指人。
- [ ] 写了本段画面里只有几个人；关键道具写了数量和归属。
- [ ] 每个镜头写了朝向，容易反的加了“不拍反打”。
- [ ] 每个镜头都有环境音行，中间镜写了延续什么、远近怎么变；没写“安静”“寂静”。
- [ ] 每个小节都有“镜头：”，并带环境声；首镜“从第一帧就有”，末镜“一直持续到最后一帧”。
- [ ] 音效行里每个 `<>` 前写了声源，没有把人物动作再写一遍；声音栏里的 `<>` 只列全片反复出现的声音。
- [ ] 没有完全固定的机位。
- [ ] 每句台词写了说话人、语气、画内或画外、看着谁说、其他人闭口。
- [ ] 心里话是画外旁白，角色没说出来。
- [ ] 没有“语速快”“停一拍”“店里很安静”“表演克制”。
- [ ] 进入状态没有提前摆好后面的动作；每镜的退出状态和下一镜的进入状态接得上。
- [ ] 保持一致在全文最后，四句都在，编号和前面一致。

## 八、局部重做：延长和编辑

延长和编辑不套上面的七分区模板，按 sd25-pe 的写法单独写。台词、音效符号和人物定妆图的写法照旧；延长片段里要写声音时，环境音和音效的写法照「四、分镜写法」。

**什么时候用哪种**

- **只坏了开头**：把原片在没人说话的地方裁开，后段当 `@视频1`，用向前延长只补前面几秒。
- **只坏了结尾**：在坏掉之前裁开，前段当 `@视频1`，用向后延长补后面。
- **只改原片里的某样东西或某段声音**：用视频编辑。画幅和基本时长会跟原片锁定，不能另设。
- **续接下一段**：这是普通生成，拿上一段的最后一帧当下一段的首帧，照七分区模板写。
- 延长时只补新片段，不同时改原片。又要改原片又要延长，就拆成两步：先编辑，再延长编辑后的新片。

### 向前延长

```text
@视频1是需要向前延长的原视频。
女主对应@图片1，本段外貌、发型和服装以@图片1为准。
〔其他参考图逐张写职责，不改变@视频1的首帧画面。〕

向前延长@视频1。在原视频开始之前，〔补出来的动作、事件、镜头和声音，写到具体动作，台词照常用 {} 写〕。

延长片段的最后一个画面自然衔接@视频1的首帧：保持〔人物姿态与朝向〕、〔道具位置〕、〔背景与空间关系〕、〔机位与构图〕、〔光线〕、〔环境声〕和〔运动趋势〕一致。

延长过程中保持〔人物身份与服装〕、〔关键道具〕、〔场景布局〕、〔轴线方向〕和〔环境声〕连续。
同一人物始终是同一个连续的人，不重复、不分裂；人物外形和道具部件数量保持稳定。
只属于原视频后面的人物、道具或动作不得提前出现。
```

### 向后延长

```text
@视频1是需要向后延长的原视频。
〔参考图逐张写职责，不替代@视频1尾帧的画面。〕

向后延长@视频1。延长片段的第一个画面直接承接@视频1的尾帧：保持〔人物姿态与朝向〕、〔道具位置〕、〔背景与空间关系〕、〔机位与构图〕、〔光线〕、〔环境声〕和〔运动趋势〕连续。

随后，〔新的动作、事件、镜头和声音〕。结束时〔可观察的最终状态〕。

延长过程中保持〔人物身份与服装〕、〔关键道具〕、〔场景布局〕、〔轴线方向〕和〔环境声〕连续。
同一人物始终是同一个连续的人，不重复、不分裂；人物外形和道具部件数量保持稳定。
```

### 视频编辑

```text
编辑@视频1，只把〔原对象或区域〕修改为〔目标内容〕。
@视频1是唯一编辑母版，负责原始场景、机位、镜头运动、动作轨迹、遮挡关系和事件顺序。
@图片1用于〔目标对象〕的〔外观、结构或材质〕，不采用〔图片背景或无关人物〕。
只修改〔明确对象和区域〕。全片〔目标对象〕数量为〔数量〕。
除以上明确修改对象外，@视频1中其他可见人物、道具和背景元素保持原样，不参与替换或删除。
〔目标对象〕继承〔原对象〕每次出现、运动、遮挡和离开的时机、持续时长、路径和速度变化；其他人物动作、镜头运动、切镜和事件顺序保持@视频1。
```

写之前先把原视频里看得见的人、道具和背景主体过一遍：要换的、要删的逐个写进去，没点名的靠“除以上明确修改对象外……保持原样”那句兜住。

只改声音时，写清改哪个说话人或哪类声音、改成什么，并写明原视频的画面、口型时机、其他声音和剪辑节奏全部不变。只去掉背景音乐时，不需要目标音频，直接写移除背景音乐、保留对白、环境声和动作音效。
