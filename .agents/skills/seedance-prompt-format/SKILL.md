# Seedance 2.5 视频提示词 · 通用格式

## 使用方式

1. 先加载 sd25-pe，冲突时以它为准。
2. 普通生成按「三」先填分镜底稿，核对后转成连续正文，〔 〕换成本片内容。
3. 延长和编辑看「六」。
4. 每段一个 txt，只放提示词正文。
5. 文件名和存放照 AGENTS.md。
6. 七分区旧稿不动；新写、重写的段用本骨架。
7. 写完过一遍「七、自检」。

---

## 参考素材必须与审核页绑定

- 写好视频提示词时，同时在本项目 `资产/参考素材映射.json` 登记该稿，键为项目内的提示词相对路径。每个编号写明 `ref`、`name`、`path`、`sha256`，路径从本项目的 `资产/` 开始，图片、视频、音频分别从 1 连续编号。只登记本稿采用的素材。
- 登记 `prompt_sha256`，计算前仅去掉正文开头的 BOM，将 CRLF、CR 统一为 LF，再以 UTF-8 计算 SHA-256。素材 SHA-256 按源文件原始字节计算。
- 先逐张查看选定图片，再写素材职责。审核页、任务书、实际上传顺序共同使用这份映射。改稿、换图、改名或增加声音后，重新核对并更新该稿登记，不凭文件名、镜号或上传完成顺序推测编号。
- 交稿前运行 `python -X utf8 通用工具/核对参考素材.py --project <项目绝对路径> --prompt <项目内提示词相对路径>`，所有编号和文件校验通过后再交审核。工具文件位于工作区的 `通用工具` 下，命令从工作区根目录执行。
- 审核页显示未绑定或校验失败时，先补正映射再交审核。原稿和映射的历史按 AGENTS.md 归档。

## 一、写戏规矩

- 目标导向：要什么、怕什么？真人会怎么做？
- 反应要由刚发生的事引起。
- 听的人给一拍反应，不无故不动。
- 反应写成看得见的动作。
- 不过度演绎：被逼到了才爆发。
- 最重的那句，写被什么点着。
- 再写身体怎么使劲、话怎么往上冲。
- 夸张放在事上，人按常理反应。
- 禁止写一直不变的表情姿势。
- 禁止堆表情小动作，挑最清楚的一两处。
- 说话做事朝着对方，不无故冲镜头。
- 人多只写主要人物，次要人物各忙各的。
- 人少要写明具体人数。
- 放手：表情、小动作的细节。
- 不放手：人数、站位、道具。
- 不放手：台词原文、镜头顺序。
- 放手的底：一句台词配一个看得见的动作。

---

## 二、总规则

1. 全片不变的放基础设定，各段照抄。
2. 本段不变的放本段。
3. 随剧情变的放分镜。
4. 同一件事不无故写两处。
5. 图内外观少复述，动作变化写清。
6. 只带本段出现的人、分场景、道具。
7. 同一人物、物件、分场景，各段照抄。
8. 不写时间码、秒数、画幅、分辨率。
9. 不提上一段、下一段，模型看不到。
10. 每段不超过 30 秒，段数能少就少。
11. 台词用 `{}`，音效用 `<>`，称谓不加符号。
12. 不用括号、引号；【】只给 `【未采用素材】`。
13. 主体用称谓，关键状态可引图。
14. 称谓定了不换，不用他、她。
15. 页面选全能参考、16:9、720p。
16. 页面上声音打开。
17. 时长交稿时报出来。
18. 人和机位有钟面报钟点，否则靠固定物说。
19. 难出的镜头单独出一条，再剪。

## 三、先填底稿，再出正文

### 第一步：填写分镜底稿

先确定素材、基础设定和本段信息，再逐镜填写下面的栏目。底稿用于把内容想清楚、查漏和核对，默认不另存或交付；用户要看时再展示。最终 txt 只放下方正文骨架，不同时放两套分镜。已有稿按批注修改时，只对获准修改的镜头执行这两步，其余原文保持不动。

按已有剧情填写，不为填满栏目新增动作、表情、台词或转场。没有的项目在底稿标明无；本段已统一说明且本镜没有变化的声音、站位，标明沿用本段。

```text
镜头 01｜〔标题〕
机位/景别/角度：〔在哪个分场景、机位在哪朝哪拍、景别与角度〕。
画面构图：〔开镜时谁在哪、朝哪；前后景关系与必要道具；引用图时说明对应哪个阶段〕。
进入状态：〔开镜时人物正在做什么；已有剧情中是什么事引起当前反应〕。

小节一
动作/表情：〔谁做什么、对方如何反应；只挑一两处必要的表演，写清先后或同时〕。
镜头：〔固定还是移动；跟着谁、何时起动、怎样移动、到哪里结束〕。
台词：〔谁对谁、什么语气、画内或画外发声；台词原文用 {}；发生在上述哪个动作时〕。
声音：〔本镜新增或变化的声源、远近、起止及与动作的关系；音效用 <>〕。

退出状态：〔结束时人物位置、朝向、动作和道具状态；只写衔接所需的〕。
切点：〔哪个动作、台词或声音触发切换，怎样切；无特定要求不硬加〕。
```

确有多个连续节拍时，按先后续写小节二中的动作、镜头、台词、声音，不因分栏额外加戏。全段填完后，核对前后镜的状态衔接、空间、素材职责和动作因果；问题先在底稿解决。

### 第二步：转换成连续正文

- 每个镜号下只写一段，合并栏目名，按实际发生顺序组织句子。
- 机位、构图、进入状态合成清楚的开镜描述；动作、运镜、台词和声音写在各自发生处，保留先后、同时与持续关系。
- 只合并重复信息、调整语序和补必要连接词；不新增、删除或替换独立动作、人物反应、台词、声源、运镜、镜头或切点。
- 主体身份与数量、机位朝向、构图和空间关系保持不变。
- 台词原文、说话人、对象、语气和画内外位置保持不变；不把提高嗓门改成压低声音，不为行文顺畅改词。
- 保留必要的起止状态、位移路径、道具归属和素材引用的阶段；不把开镜或结束时的状态写成全程要求。
- 退出状态顺接动作结果，切点接在触发事件处；不能因为去掉栏目名就把信息一起删掉。
- 同一信息在底稿多栏重复时，正文只表达一次；不同阶段再次发生的动作不当成重复删除。底稿中的无、沿用等占位说明不进入正文。
- 转换后逐项对照底稿，确认只是换了表达形式，剧情、表演、声画关系和镜头设计没有变化。需要改内容时先回改底稿，再转换。

### 最终正文骨架

没有的行整行删掉。
多张关键帧才写顺序行。

```text
以〔按剧情先后排列的关键帧@图片N〕作为关键帧。

本段事件：〔谁要什么、情绪从哪来，所以发生了什么；结束时什么样〕。

素材
〔称谓〕对应@图片N，外貌、发型和服装以@图片N为准。
〔道具〕对应@图片N，只采用〔结构、材质、颜色〕。
@图片N是〔哪个分场景〕从〔哪〕往〔哪〕看的样子，只采用〔空间布局、陈设、材质、灯光〕。
@图片N作为首帧。
该首帧定义视频开始时的〔构图、主体位置、姿态、道具状态、场景、镜头方向〕。
@图片N定义镜头〔编号〕在〔阶段〕的关键状态：〔该刻可见状态〕。
@图片N作为尾帧。
该尾帧定义视频结束时的〔构图、主体位置、姿态、道具状态、场景、镜头方向〕。
【未采用素材】
@图片N未参与本段，不用于人物、场景、道具、动作或镜头。

基础设定
影像风格：〔片种、质感〕。
摄影：〔摄影机、胶片质感、景深，只写全片不变的〕。
光色基调：〔时间和天光；主光从哪来；色调〕。

本段
核心氛围：〔时间和地点的一句画面〕。〔人物在做什么〕；整体〔什么感觉〕。
分场景｜〔叫法〕：〔传了场景图的写参考@图片N〕。〔本段拍得到的地方：有什么、各在哪〕。〔项目 GEO 的场景段，照放〕。
轴线：〔项目 GEO 的轴线行，照放〕。
人物：〔本段几个人、各是谁〕。〔没有图的写长相、衣着〕。〔说话的人写声线：年龄、音色、腔调〕。
站位：〔开场时谁在几点、坐还是站、朝着谁、隔多远；有首帧时仅开场站位照@图片N；必要的图外关系补写〕。
物件：〔没有图的写结构、材质、颜色〕。
道具：〔几个、开场什么样、什么时候出现、最后在哪〕。
声音：〔配乐；不要就写无背景音乐〕。〔环境音、音效：点名的写声源、哪个近哪个远；交给模型的写只生成哪几类声音，根据画面内容适配相应的音效〕。〔有台词：口型同步，不说话的人闭口〕。〔旁白、字幕〕。

分镜

镜头 01｜〔标题〕
〔在哪个分场景；只有一个不写〕。〔开镜时看见什么〕。〔景别、机位在几点朝几点拍、高低、固定还是移动〕。〔站位变了的，写谁在几点、朝着谁；机位偏离6点朝12点或过肩的，写谁在画面左右〕。〔谁要什么，所以做什么、接着做什么；有关键帧的，写清动作做到哪一步时对应图中画面；台词 {}、音效 <> 写在发生处；听的人被哪句话引出什么反应〕。〔往哪移动、经过哪里、最后在哪；没有位移不写〕。〔必要的退出状态和切点，顺接对应事件；没有不写〕。音效：〔什么在响、怎么响、离机位远还是近；有明确触发时机的已写在发生处，本段的声音够用就整句不写〕。

镜头 02｜〔标题〕
〔……〕

保持一致：〔最怕错的两三条〕。
```

## 四、各处怎么写

### 本段事件
- 先写谁要什么，再写发生了什么。
- 写清情绪从哪来。
- 写到结束时的样子，不引台词。

### 素材
- 一张图一行，写只采用什么。
- 首尾帧角色句各自独立一行。
- 首尾帧定义紧接角色句。
- 首帧只定义视频开始时的状态。
- 尾帧只定义视频结束时的状态。
- 中间关键帧按需选用。
- 仅借外观的图不标作关键帧。
- 用户已定引用与职责不擅改。
- 多关键帧先列采用顺序。
- 关键帧逐张写明镜号与阶段。
- 每张关键帧只定义该刻状态。
- 动作衔接写进对应分镜。
- 图示状态须与对应动作相容。
- 不默认要求关键状态停留。
- 不承诺逐帧复刻。
- 按结尾对齐需求选用尾帧。
- 首尾帧画幅保持一致。
- 室内场景给两个朝向的图。
- 只上传本段用到的图。
- 不用的图逐个列进 `【未采用素材】`。
- 尾帧、白模、参考视频照 sd25-pe 写。
- 多组东西同框齐动，挂白模视频。
- 白模只放物件和运镜，不放人。
- 挂白模的镜头，人数和站位交给关键帧。
- 持续在动的火、烟不画进关键帧。

### 基础设定
- 影像风格、摄影按片子选。
- 摄影只写全片不变的，景别运镜进分镜。

### 本段
- 核心氛围用画面写，不堆形容词。
- 不写总场景，每段只管自己的场景。
- 只写本段拍得到的地方。
- 大环境也当一处分场景，拍到才写。
- 分场景一处一行，各起叫法。
- 同一处地方，叫法、方位、数量各段一样。
- 没有场景图的分场景，用文字锁定。
- 只用一次的分场景，写地点和固定物。
- 分场景照放项目 GEO，不现写。
- 场景段里的逐图句放进素材。
- 传了场景图，在对应场景开头引用。
- 照抄时@编号按本段的图改。
- 没有 GEO，先用 scene-geo 做。
- 人数和道具数量写明。
- 人物只写看得见的长相、衣着。
- 没有图的人，外形要一眼分得开。
- 没要求不写普通话。
- 后面才出现的，写明什么时候出现。
- 站位只写开场那一刻。
- 写谁在哪、朝谁、隔多远，靠固定物说。
- 离开锚物的，写夹在哪两样之间。
- 首帧站位仅用于开场。
- 图外必需内容写明何时如何出现。
- 必要空间关系仍须写清。
- 后上场的人，到上场那镜再写。
- 核心氛围只写在做什么，不写站位。
- 点名的环境音在本段写全，镜头里有变化才写。
- 安静的场面也写声源。
- 不点名声音，就写只要哪几类、按画面配。
- 心里话只做画外旁白。

### 分镜
- 先按「三」填分栏底稿、核对，再转换正文。

一镜写什么：

- 一镜按顺序写七样，没有的不写。
- 一、机位在哪、朝哪拍、景别。
- 二、画面里有谁。
- 三、谁要什么。
- 四、一个主要动作，开镜就做。
- 五、一句台词，配一个语气词。
- 六、听的人一拍反应。
- 七、怎么切。
- 一镜一段话，一件事写到底。
- 背景只当气氛，至多一句。
- 动作因果沿用剧情。
- 后面才出现的，前面的镜头不提。
- 禁止把结尾的状态写成全程的。

机位和运镜：

- 分场景不止一个，每镜开头写叫法。
- 镜头里不重写分场景。
- 机位写清在哪、朝哪拍。
- 运镜与固定机位按剧情选。
- 不以运镜代替主体动作。
- 过肩镜头写明越过谁拍谁。
- 要拍到反应，两人同框或切过去。
- 首镜第一帧起就在动，写清可见动作。

站位：

- 站位变了才在镜头里写。
- 关键帧位置仅限指定时刻。
- 站位随动作更新。
- 位移写清方向、路径与终点。
- 没有图的镜头，用文字写清站位。
- 位置靠固定物说，不只写画面左右。
- 同一钟点的人和机位，用远近或地标分开。
- 机位偏离6点朝12点或过肩，写画面左右。

台词：

- 台词写谁对谁说、什么语气。
- 台词原文只在 `{}` 里出现一次。
- 说话时手上的事不停。
- 画外说话写明画外发声。
- 禁止写“语速快”“停一拍”这类说法。
- 读错的字换成同音常用字。
- 屏幕文字留给后期贴。

声音：

- 音效写发声的物件，后跟 `<>`。
- 本段的声音不够这一镜用，才加一句音效。
- 与动作或切点有明确时序关系的声音写在发生处，其余声场补充写在镜头最后，不另起一行。
- 写什么在响、怎么响、远还是近。
- 一镜只挑一两样，不堆。
- 画面外的声音写明画外。
- 同一声音效只标一次 `<>`。

### 保持一致
- 只留最怕错的两三条。
- 不加新信息。
- 保持一致只列不变属性。

## 五、出了错再补

哪一镜出错补哪一镜，整篇不换写法。补之前先查这一镜是否写多了。

关键帧相关排查：

- 开头停滞：检查起始动作。
- 主体不动：检查全程位置约束。
- 图外缺项：检查出现时机与遮挡。
- 动作不接：检查关键状态可达性。
- 图文冲突：先统一该刻状态。
- 改图或改职责须遵从用户意图。
- 对照测试每次只改一个变量。
- 模式差异需多次对照验证。

其他问题：

- 进出画面、道具位置错：补开始和结束状态。
- 认错人或道具：这一镜补称谓对应@图片N。
- 朝向拍反：补机位在谁身后，不拍反打。
- 站错位、换边：补钟点和画面左右。
- 环境音断了：补这一镜的声源和远近。
- 冒泡、回音、啸叫：删水、浪、回音类词。
- 配乐删不掉：各种叫法都写上，首尾各写一遍。
- 切点生硬：补跟着哪个动作切。
- 拼版图读成两人：补画面只有一个〔称谓〕。
- 还不行：拼版拆成脸和全身两张图。
- 脸被镜头拉变形：补脸和手保持真实比例。

## 六、延长和编辑

模板照 sd25-pe 的「视频编辑模板」「视频延长模板」。

- 只坏开头：没人说话处裁开，后段向前延长。
- 只坏结尾：坏掉之前裁开，前段向后延长。
- 只改某样东西或某段声音：视频编辑。
- 续接下一段：普通生成，上段尾帧当首帧。
- 又改又延长：先编辑，再延长新片。

## 七、自检

- [ ] 已逐镜填写分栏底稿，先解决内容与衔接问题，再转换正文。
- [ ] 正文逐项对照底稿，未擅改动作、表演、台词、声画时序、素材职责和切点。
- [ ] 重复信息只合并表达，不同阶段的动作与必要起止状态未误删。
- [ ] 最终 txt 只有一套连续分镜正文，不含底稿栏目或占位说明。
- [ ] 本段事件写了目标、情绪来由与结束状态。
- [ ] 每张图写明采用范围。
- [ ] 首尾帧角色句各自独立。
- [ ] 首尾帧定义限定开始或结束时。
- [ ] 多关键帧顺序声明放在首句。
- [ ] 关键帧标明镜号、阶段与状态。
- [ ] 关键帧之间写了动作衔接。
- [ ] 图示状态与动作过程相容。
- [ ] 未将外观参考误作关键状态。
- [ ] 未把该刻站位写成整镜固定。
- [ ] 未自动挂齐所有关键帧。
- [ ] 用户已定引用与职责未擅改。
- [ ] 图内外观未无故重复细描。
- [ ] 必要空间关系未因有图省略。
- [ ] 图外必需内容写明出现方式与时机。
- [ ] 只带了本段出现的人、分场景、道具。
- [ ] 同一件事没有无故写两处。
- [ ] 随剧情变的没写进基础设定和本段。
- [ ] 基础设定、人物、物件、分场景照抄了。
- [ ] 分场景照放了项目 GEO。
- [ ] 没写总场景；场景只写了本段拍得到的。
- [ ] 同一处地方的叫法、方位、数量各段一样。
- [ ] 场景图在对应场景开头引用了。
- [ ] 写了几个人；道具写了数量和去向。
- [ ] 写了开场站位，各镜跟它对得上。
- [ ] 分场景不止一个的，每镜写了在哪个。
- [ ] 每镜写了机位朝向；站位变了的写了站位。
- [ ] 有钟面的，人和机位都报了钟点。
- [ ] 本段声音不够用的镜头加了音效。
- [ ] 声音行写明了要不要配乐、要哪几类声音。
- [ ] 镜头动静符合剧情需求。
- [ ] 首镜写明第一帧起的可见动作。
- [ ] 动作因果与剧情一致。
- [ ] 没有一直不变的表情姿势。
- [ ] 每句台词写了谁对谁说、什么语气。
- [ ] 有人听的台词，写了听的人的反应。
- [ ] 没有超过两百字的镜头。
- [ ] 没有时间码、秒数、画幅、括号、引号。
- [ ] 保持一致不超过三条。
- [ ] 未将变化中的状态要求恒定。
