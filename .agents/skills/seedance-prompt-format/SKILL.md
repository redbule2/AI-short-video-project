# Seedance 2.5 视频提示词 · 通用格式

## 使用方式

1. 先加载 sd25-pe，冲突时以它为准。
2. 普通生成按「三」先填分镜底稿，核对后转成连续正文，〔 〕与 < > 换成本片内容。
3. 延长和编辑看「六」。
4. 每段一个 txt，只放提示词正文。
5. 文件名和存放照 AGENTS.md。
6. 七分区旧稿不动；新写、重写的段用本骨架。
7. 写完过一遍「七、自检」。

---

## 参考素材必须与审核页绑定

- 写好视频提示词时，同时在本项目 `资产/参考素材映射.json` 登记该稿，键为项目内的提示词相对路径。每个编号写明 `ref`、`name`、`path`、`sha256`，路径从本项目的 `资产/` 开始，图片、视频、音频分别从 1 连续编号。只登记本稿采用的素材。
- 登记 `prompt_sha256`，计算前仅去掉正文开头的 BOM，将 CRLF、CR 统一为 LF，再以 UTF-8 计算 SHA-256。素材 SHA-256 按源文件原始字节计算。
- 先逐张查看选定图片，再写素材职责。审核页、任务书、实际上传顺序共同使用这份映射。改稿、换图、改名或增加声音后，重新核对并更新该稿登记，不凭文件名、镜号或上传完成顺序推测编号。
- 交稿前运行 `python -X utf8 通用工具/核对参考素材.py --project <项目绝对路径> --prompt <项目内提示词相对路径>`，所有编号和文件校验通过后再交审核。工具文件位于工作区的 `通用工具` 下，命令从工作区根目录执行。
- 审核页显示未绑定或校验失败时，先补正映射再交审核。原稿和映射的历史按 AGENTS.md 归档。

## 一、写戏规矩

- 目标导向：要什么、怕什么？真人会怎么做？
- 反应要由刚发生的事引起。
- 听的人给一拍反应，不无故不动。
- 反应写成看得见的动作。
- 不过度演绎：被逼到了才爆发。
- 最重的那句，写被什么点着。
- 再写身体怎么使劲、话怎么往上冲。
- 夸张放在事上，人按常理反应。
- 禁止写一直不变的表情姿势。
- 禁止堆表情小动作，挑最清楚的一两处。
- 说话做事朝着对方，不无故冲镜头。
- 人多只写主要人物，次要人物各忙各的。
- 人少要写明具体人数。
- 放手：表情、小动作的细节。
- 不放手：人数、站位、道具。
- 不放手：台词原文、镜头顺序。
- 放手的底：一句台词配一个看得见的动作。

---

## 二、总规则

1. 全片不变的放基础设定，各段照抄。
2. 本段不变的放本段。
3. 随剧情变的放分镜。
4. 同一件事不无故写两处。
5. 图内外观少复述，动作变化写清。
6. 只带本段出现的人、分场景、道具。
7. 同一人物、物件、分场景，各段照抄。
8. 不写时间码、秒数、画幅、分辨率。
9. 不提上一段、下一段，模型看不到。
10. 每段不超过 30 秒，段数能少就少。
11. 台词用 `{}`，音效用 `<>`，称谓不加符号。
12. 素材职责沿用 sd25-pe，普通参考项按“叫法：@图片编号接描述”排列。其他部分不用括号、引号。
13. 主体用称谓，关键状态可引图。
14. 称谓定了不换，不用他、她。
15. 页面选全能参考、16:9、720p。
16. 页面上声音打开。
17. 时长交稿时报出来。
18. 人和机位有钟面报钟点，否则靠固定物说。
19. 难出的镜头单独出一条，再剪。

## 三、先填底稿，再出正文

### 第一步：填写分镜底稿

先确定素材、基础设定和本段信息，再逐镜填写下面的栏目。底稿用于把内容想清楚、查漏和核对，默认不另存或交付；用户要看时再展示。最终 txt 只放下方正文骨架，不同时放两套分镜。已有稿按批注修改时，只对获准修改的镜头执行这两步，其余原文保持不动。

按已有剧情填写，不为填满栏目新增动作、表情、台词或转场。没有的项目在底稿标明无；本段已统一说明且本镜没有变化的声音、站位，标明沿用本段。

```text
镜头 01｜〔标题〕
机位/景别/角度：〔在哪个分场景、机位在哪朝哪拍、景别与角度〕。
画面构图：〔开镜时谁在哪、朝哪；前后景关系与必要道具；引用图时说明对应哪个阶段〕。
进入状态：〔开镜时人物正在做什么；已有剧情中是什么事引起当前反应〕。

小节一
动作/表情：〔谁做什么、对方如何反应；只挑一两处必要的表演，写清先后或同时〕。
镜头：〔固定还是移动；跟着谁、何时起动、怎样移动、到哪里结束〕。
台词：〔谁对谁、什么语气、画内或画外发声；台词原文用 {}；发生在上述哪个动作时〕。
声音：〔本镜新增或变化的声源、远近、起止及与动作的关系；音效用 <>〕。

退出状态：〔结束时人物位置、朝向、动作和道具状态；只写衔接所需的〕。
切点：〔哪个动作、台词或声音触发切换，怎样切；无特定要求不硬加〕。
```

确有多个连续节拍时，按先后续写小节二中的动作、镜头、台词、声音，不因分栏额外加戏。全段填完后，核对前后镜的状态衔接、空间、素材职责和动作因果；问题先在底稿解决。

### 第二步：转换成连续正文

- 每个镜号下只写一段，合并栏目名，按实际发生顺序组织句子。
- 机位、构图、进入状态合成清楚的开镜描述；动作、运镜、台词和声音写在各自发生处，保留先后、同时与持续关系。
- 只合并重复信息、调整语序和补必要连接词；不新增、删除或替换独立动作、人物反应、台词、声源、运镜、镜头或切点。
- 主体身份与数量、机位朝向、构图和空间关系保持不变。
- 台词原文、说话人、对象、语气和画内外位置保持不变；不把提高嗓门改成压低声音，不为行文顺畅改词。
- 保留必要的起止状态、位移路径、道具归属和素材引用的阶段；不把开镜或结束时的状态写成全程要求。
- 退出状态顺接动作结果，切点接在触发事件处；不能因为去掉栏目名就把信息一起删掉。
- 同一信息在底稿多栏重复时，正文只表达一次；不同阶段再次发生的动作不当成重复删除。底稿中的无、沿用等占位说明不进入正文。
- 转换后逐项对照底稿，确认只是换了表达形式，剧情、表演、声画关系和镜头设计没有变化。需要改内容时先回改底稿，再转换。

### 最终正文骨架

没有的行整行删掉。
关键帧素材按「四、各处怎么写」中的对应模板填写。

```text
本段事件：〔谁要什么、情绪从哪来，所以发生了什么；结束时什么样〕。

素材
【参考素材职责】
<主体>：@图片1用于<主体>的<外貌、服装、结构或材质>。
<参考视频叫法>：@视频1用于<动作、运镜或节奏>，不采用<容易误带的身份、服装或场景>。
<角色或声音类型>：@音频1用于<角色或声音类型>的<音色、台词、环境声或音乐>。

【未采用素材】
@图片2、@视频2、@音频2未参与本任务，不用于人物、场景、道具、动作、镜头或声音。

基础设定
影像风格：〔片种、质感〕。
摄影：〔摄影机、胶片质感、景深，只写全片不变的〕。
光色基调：〔时间和天光；主光从哪来；色调〕。

本段
核心氛围：〔时间和地点的一句画面〕。〔人物在做什么〕；整体〔什么感觉〕。
分场景｜〔叫法〕：〔传了场景图的写参考@图片N〕。〔本段拍得到的地方：有什么、各在哪〕。〔项目 GEO 的场景段，照放〕。
轴线：〔项目 GEO 的轴线行，照放〕。
人物：〔本段几个人、各是谁〕。〔没有图的写长相、衣着〕。〔说话的人写声线：年龄、音色、腔调〕。
站位：〔开场时谁在几点、坐还是站、朝着谁、隔多远；有首帧时仅开场站位照@图片N；必要的图外关系补写〕。
物件：〔没有图的写结构、材质、颜色〕。
道具：〔几个、开场什么样、什么时候出现、最后在哪〕。
声音：〔配乐；不要就写无背景音乐〕。〔环境音、音效：点名的写声源、哪个近哪个远；交给模型的写只生成哪几类声音，根据画面内容适配相应的音效〕。〔有台词：口型同步，不说话的人闭口〕。〔旁白、字幕〕。

分镜

镜头 01｜〔标题〕
〔在哪个分场景；只有一个不写〕。〔开镜时看见什么〕。〔景别、机位在几点朝几点拍、高低、固定还是移动〕。〔站位变了的，写谁在几点、朝着谁；机位偏离6点朝12点或过肩的，写谁在画面左右〕。〔谁要什么，所以做什么、接着做什么；有关键帧的，写清动作做到哪一步时对应图中画面；台词 {}、音效 <> 写在发生处；听的人被哪句话引出什么反应〕。〔往哪移动、经过哪里、最后在哪；没有位移不写〕。〔必要的退出状态和切点，顺接对应事件；没有不写〕。音效：〔什么在响、怎么响、离机位远还是近；有明确触发时机的已写在发生处，本段的声音够用就整句不写〕。

镜头 02｜〔标题〕
〔……〕

保持一致：〔最怕错的两三条〕。
```

## 四、各处怎么写

### 本段事件
- 先写谁要什么，再写发生了什么。
- 写清情绪从哪来。
- 写到结束时的样子，不引台词。

### 素材

下列素材职责和采用范围沿用 sd25-pe，按当前任务选用。普通图片、视频和音频参考项统一以项目中的正式叫法和中文冒号开头，再接素材编号与完整描述，例如“木工：@图片1用于木工的五官、短发和深蓝色工作围裙，不采用图片背景。”首尾帧角色句、关键帧控制句和未采用素材列表按对应模板填写。

#### 盘点和理解素材

素材较多时使用两遍理解：

1. 第一遍轻量盘点全部素材，识别人物、商品、道具、场景、动作、运镜、节奏、声音和风格候选。
2. 第二遍只深度查看与剧情匹配、存在冲突、作为关键帧或当前场景会调用的素材。

检查视频时至少确认主体、主要动作、镜头变化、开头状态和结尾状态；检查音频时至少确认声音类型、音色、语言、台词内容或环境声用途。

区分两类信息：

- **故事分配**：人物叫什么、年龄和关系是什么、承担哪个事件、道具归谁、结局如何。这些来自用户文字。
- **素材观察**：五官、发型、服装、材质、颜色、空间布局、动作、运镜、音色等能够直接观察或听见的特征。

素材只补充能够直接观察到的特征。不得从素材外观反推或改写文字中的身份、年龄、关系和剧情；无法从素材确认的品牌、颜色、职业、性格和道具功能也不得擅自补写。

用户只称为“人物”或“主体”时，继续使用该中性称谓；不得根据动作、姿态或服装擅自改称为舞者、演员、工人或其他身份。用户已经给出角色名或身份时再沿用该称谓。

称谓、排行、职业和关系只定义剧情槽位，不得自动转成幼年、年长、柔弱、强势等外观或性格。只有用户文字明确说明，或素材中存在可直接观察的对应表现时，才写入这些属性。

人物素材默认只写五官、发型、服装、配饰和可直接观察的姿态，不用“少女感”“成熟感”“柔弱气质”“强势气质”等总结性标签代替可见特征。用户明确要求这些表演方向时，再把它们改写成表情、姿态和动作。

映射优先级固定为：

```text
用户明确指定 > Prompt 中的描述 > 素材内容 > 文件名和元数据 > 上传顺序
```

用户明确映射已经覆盖全部必需实体时，未被用户点名的其他可用素材默认不激活。不得仅因内容相似就补成第二人物、第二场景或辅助参考，也不得为了增强同一职责再添加未点名素材。泛称的背景宾客、家具、装饰或环境元素不构成素材缺口，由已指定场景素材和文字描述承担。只有用户明确要求从全部素材中选择、要求组合多份参考，或一个被用户明确要求的核心人物、道具、场景、动作或声音仍无职责来源时，才评估未点名素材。默认不激活的编号仍写入 Prompt 的 `【未采用素材】`。

上传顺序不是身份或职责的语义证据，通常只用于生成稳定编号。只有用户要求直接输出且候选同等合理、槽位数量与候选数量一致时，可以把上传顺序作为最终稳定平局规则：按故事槽位首次出现顺序与候选素材顺序做一对一分配。该顺序只解决分配稳定性，不证明真实身份，也不得据此添加年龄、关系或性格。

如果输入是 JSON 或含 Asset ID 的长文本，按各媒体在输入中的出现顺序建立 `@图片N`、`@视频N`、`@音频N` 映射，再把文字中的 Asset ID 替换成对应引用。最终 Prompt 不得裸露 Asset ID。

如果只有本地路径而没有引用标签，按用户提供顺序、按媒体类型分别建立稳定别名，并在“素材理解”中列出路径与别名。最终 Prompt 使用这些别名，同时提醒后续上传时保持相同顺序。

#### 建立素材职责和主体映射

每个被使用的素材只承担明确职责：

- 图片：人物外貌与服装、商品结构与材质、道具、场景布局、光线或关键帧。
- 视频：动作、运镜、节奏、时间线，或作为唯一编辑母版、延长源视频。
- 音频：指定说话人的音色与台词、环境声、音效或音乐。

建立映射前，逐项核对故事要求的人物、道具和场景；建立映射时按以下顺序执行：

1. 从必需实体清单中逐个取出尚未分配的角色、群体、道具和场景。
2. 浏览全部素材候选，比较人数、服装层级、轮廓、结构、道具和场景职责；不得在找到第一份可用素材后停止检索。
3. 为当前槽位选择最匹配素材，再处理下一个槽位。不同已命名角色或群体默认使用不同的最佳候选。
4. 完成后做一次遗漏审计：每个必需实体在 Prompt 中恰好承担一个明确角色，每份被激活素材只承担已声明职责。
5. 把完整可用素材清单减去已分配素材，得到未采用集合。只要集合非空，就在 Prompt 的素材职责之后增加 `【未采用素材】`，按媒体类型逐个列出未采用编号，并明确它们不用于人物、场景、道具、动作、镜头或声音。不得只在 Prompt 外说明，也不得用“其他素材”代替具体编号。

不得把两个已命名角色合并为一个主体，也不得因为某份素材不够醒目而漏掉对应角色。有可区分候选素材时，不得复用同一素材覆盖多个已命名角色或群体；只有该素材画面本身同时包含这些角色，并且没有更合适的独立候选时，才允许复用。多份素材共同定义同一实体时必须显式说明，未被故事调用的素材可以不使用。

最终素材职责中，一行只定义一个主体、群体、道具或场景及其主参考素材。禁止把多个主体和多个素材压缩在同一句范围映射中，例如“人物A和人物B参考@图片1、@图片2”；应拆成“人物A：@图片1用于人物A的外貌和服装。”和“人物B：@图片2用于人物B的外貌和服装。”。

如果两个核心身份在文字中没有外观线索、候选素材也同样合理，不得假装能从画面知道隐藏答案。按“处理映射置信度”合并询问一次；用户要求直接按合理假设输出时，按上面的稳定平局规则采用一对一保守映射，并避免添加年龄、性格等无法确认的区别。

同一主体有多份参考时，分别说明每份素材补充的视角或属性，并声明它们共同定义同一实体，不生成多个副本。

不同主体必须逐条绑定，例如：

```text
<人物A>：@图片1用于<人物A>的五官、发型和服装。
<人物B>：@图片2用于<人物B>的五官、发型和服装。
<道具A>：@图片3用于<道具A>的结构、材质和颜色。
<场景A>：@图片4用于<场景A>的空间布局、建筑和光线，不采用图中人物。

【未采用素材】
@图片5、@图片6未参与本任务，不用于人物、场景、道具、动作或镜头。
@音频2未参与本任务，不用于台词、音色、环境声、音效或音乐。
```

不要用一个范围句代替多名角色的一一映射。

参考视频没有说明职责时，从动作、运镜、节奏、场景和声音中选择与任务有关的维度。生成任务不得默认继承参考视频中的人物身份、服装或完整场景。参考视频已经准确给出动作、运镜和顺序时，只说明继承哪些维度，不必逐动作复述；重复改写可能与素材本身冲突。

文字台词与参考音频内容冲突时，以用户文字决定台词内容，音频默认只提供音色、口音、语速和情绪。用户明确要求复用音频台词时例外。

同一主体的多份参考互相冲突时，先服从用户指定；用户未指定时，根据清晰度和剧情匹配度把外貌、服装、结构或材质分配给最合适的素材。只有核心身份仍无法判断时才澄清。

不要为了填满模板编造用户没有要求的视觉风格、运镜或声音。简单任务可以合并相邻段落，但不得省略实际使用素材的职责。

#### 填写示例

```text
【参考素材职责】
木工：@图片1用于木工的五官、短发和深蓝色工作围裙，不采用图片背景。
旧木椅：@图片2用于旧木椅的弧形椅背、深色木纹和磨损位置，不采用图中人物。

```

#### 多素材组织

多素材按以下顺序组织：

```text
逐份素材职责 → 主体映射 → 按类型分组 → 主体设定 → 分场景调用
```

素材数量多不代表全部素材都要进入 Prompt。只使用与当前故事和场景相关的素材；把实际可用但未分配职责的素材放进 Prompt 内的 `【未采用素材】`，逐个列出未采用编号并禁止激活。未采用素材可以按图片、视频、音频分别合并成紧凑的一行，但不能省略编号，也不能写成主体范围映射。

##### 类型分组

```text
【人物】
<人物A>：@图片1用于<人物A>的外貌、发型和服装。
<人物B>：@图片2用于<人物B>的外貌、发型和服装。
两人的外貌、服装、动作、站位和台词不互相交换。

【道具】
<道具A>：@图片3对应<道具A>，只属于<人物A>。
<道具B>：@图片4对应<道具B>，只属于<人物B>。

【场景】
<场景A>：@图片5用于<场景A>的空间、材质和光线。
<场景B>：@图片6用于<场景B>的空间、材质和光线。

【动作与声音】
<参考视频叫法>：@视频1用于<人物A>的<动作或运镜>，不采用视频中的人物和场景。
<人物B>：@音频1用于<人物B>的<音色和指定台词>。
```

#### 关键帧锚点

关键帧图片仍作为普通参考图输入，只在 Prompt 中逐张指定职责。不要把首帧和尾帧合并成一个范围句。

固定首帧时必须单独写出 `@图片N作为首帧。`；固定尾帧时必须单独写出 `@图片N作为尾帧。`。不得弱化为“仅作为首帧参考”“参考开场构图”或“首帧构图参考”，也不要把角色句和后续动作压缩在同一句中。精确角色句必须原样保留在最终 Prompt 中，再另起一句补充该帧定义的构图、主体位置、姿态、道具状态、场景和镜头方向。

首帧会锁定输出画幅比例。首帧与尾帧应使用相同画幅，避免尾帧拉伸；时长仍由生成页面或接口设置。该规则只用于输入预检，不要写成 Prompt 内的输出参数。

##### 首帧加其他参考

```text
@图片1作为首帧。
该首帧定义视频开始时的构图、主体位置、姿态、道具状态、场景和镜头方向。
<主体>：@图片2用于<主体>的<外貌、服装、结构或材质>，不改变@图片1定义的首帧构图。
<场景或道具叫法>：@图片3用于<场景、道具或光线>，不改变@图片1定义的首帧构图。

画面从@图片1定义的首帧自然开始，随后<连续动作或事件>。
保持<人物身份、道具归属、空间关系和视觉风格>连续。
```

##### 首帧、尾帧加其他参考

```text
@图片1作为首帧。
该首帧定义视频开始时的构图、主体位置、姿态、道具状态、场景和镜头方向。
@图片2作为尾帧。
该尾帧定义视频结束时的构图、主体位置、姿态、道具状态、场景和镜头方向。
<主体A>：@图片3用于<主体A>的<外貌、服装、结构或材质>，不改变@图片1的首帧构图和@图片2的尾帧构图。
<主体、道具或场景叫法>：@图片4用于<主体B、道具或场景>的<指定属性>，不改变@图片1的首帧构图和@图片2的尾帧构图。

<一个连续动作或事件>。
画面从@图片1定义的首帧自然开始，经过连续动作后到达@图片2定义的尾帧。
首尾之间保持<人物身份、道具结构与归属、场景布局和镜头方向>连续。
```

填写示例：

```text
@图片1作为首帧。
该首帧定义烘焙台、裱花师位置、未装饰蛋糕、工具摆放和正面中景机位。
@图片2作为尾帧。

```

用户明确要求中间关键状态时，可以增加一张图片定义该时刻必须出现的人物、动作、道具和空间关系，并描述在某个时间附近自然到达该状态。它是语义锚点，不是静态停留或逐像素固定帧。首尾边界优先时，减少与当前事件无关的其他素材。

##### 多关键帧顺序控制

多张独立图片分别定义过程阶段时，第一句先声明关键帧顺序，再逐张写明每个关键状态。关键帧控制阶段顺序和可见状态，不承诺逐帧复刻，也不要求在某个关键状态静态停留。

```text
以@图片1至@图片N的顺序作为关键帧。

@图片1作为首帧。
该首帧定义<开始时的构图、主体位置、姿态、道具状态和镜头方向>。
@图片2定义第二个关键帧：<第一阶段结束时的可见状态>。
@图片3定义第三个关键帧：<第二阶段结束时的可见状态>。
@图片N作为尾帧。
该尾帧定义<结束时的构图、主体位置、姿态、道具状态和镜头方向>。

画面依次经过@图片1、@图片2、@图片3至@图片N定义的状态，各阶段之间使用连续动作自然过渡。
全过程保持<主体身份、道具结构与归属、场景布局、光线和摄影轴线>连续。
```

##### 宫格分镜与故事板

宫格分镜用于定义整体故事、镜头顺序和大致构图，不用于要求每格细节严格复刻。优先使用 15 格以内、画面干净且文字标注较少的故事板。必须说明读取顺序、采用的镜头结构，以及不采用的线稿画风、标注或占位人物。

```text
<宫格分镜叫法>：@图片1提供<N格宫格分镜>的镜头顺序和大致构图，按照<从左到右、从上到下>的顺序读取；不采用图中的<线稿画风、文字标注或占位人物>。
<主体A>：@图片2定义<主体A>的<外貌与服装>。
<关键道具或场景>：@图片3定义<关键道具或场景>的<结构、材质或光线>。

镜头1：<景别、主体动作、场景状态>。
镜头2：<景别、主体动作、运镜或切换方式>。
……
镜头N：<结束动作和结束画面状态>。

最终画面采用<视觉风格>，声音包括<对白、环境声、动作音效或音乐>。
```

##### 白模参考与渲染

先判断白模视频提供的是运动骨架还是完整结构：

- **粗粒度白模**：简单几何体主要提供动作路径、运动方向、主体站位、进出场、机位、运镜、切镜、光影变化、声音节奏或空间关系。每个几何体必须单独映射到最终主体或道具。
- **细粒度白模**：主体、道具或场景结构已经完整，主要用于更换人物形象、材质、颜色、场景或视觉风格。保持原有结构、动作、空间和镜头。

白模视频作为生成参考，不因为它是视频就自动成为编辑母版。白模画面包含轨迹线、坐标轴、控制器、相机锥体或文字标记时，明确不采用这些制作标记。

###### 粗粒度白模

```text
<白模参考叫法>：@视频1是粗粒度白模参考，仅提供<动作路径、主体站位、机位、运镜、切镜、光影变化、声音节奏或空间关系>，不采用其中的白模外观、材质和场景。
@视频1中的<白模主体A>对应<主体A>。
@视频1中的<白模主体B或几何道具>对应<主体B或关键道具>。
<主体A>：@图片1定义<主体A>的<外貌、服装或结构>。
<主体、道具或场景叫法>：@图片2定义<主体B、关键道具或场景>的<指定属性>。

<主体>在<场景>中完成<主要动作或事件>。
保持@视频1中的<动作路径、站位、运镜、切镜、光影或声音节奏>。
最终画面采用<人物、场景、材质和视觉风格>，声音包括<对白、环境声或动作音效>。
```

###### 细粒度白模

```text
<白模参考叫法>：@视频1是细粒度白模参考，保持<主体结构、动作、空间布局、机位、运镜和切镜>，不采用原有灰模材质、空白背景和制作标记。
<主体>：@图片1定义<主体>的<人物形象、材质、颜色或表面细节>。
<场景>：@图片2定义<场景>的<空间、材质、光线或视觉风格>。

将@视频1中的<主体>重渲染为<最终主体>，场景重渲染为<最终场景>。
保持@视频1中的<结构、动作、镜头和空间关系>，画面呈现<材质、色彩和风格>，声音包括<环境声、音效或音乐>。
```

### 基础设定
- 影像风格、摄影按片子选。
- 摄影只写全片不变的，景别运镜进分镜。

### 本段
- 核心氛围用画面写，不堆形容词。
- 不写总场景，每段只管自己的场景。
- 只写本段拍得到的地方。
- 大环境也当一处分场景，拍到才写。
- 分场景一处一行，各起叫法。
- 同一处地方，叫法、方位、数量各段一样。
- 没有场景图的分场景，用文字锁定。
- 只用一次的分场景，写地点和固定物。
- 分场景照放项目 GEO，不现写。
- 场景段里的逐图句放进素材。
- 传了场景图，在对应场景开头引用。
- 照抄时@编号按本段的图改。
- 没有 GEO，先用 scene-geo 做。
- 人数和道具数量写明。
- 人物只写看得见的长相、衣着。
- 没有图的人，外形要一眼分得开。
- 没要求不写普通话。
- 后面才出现的，写明什么时候出现。
- 站位只写开场那一刻。
- 写谁在哪、朝谁、隔多远，靠固定物说。
- 离开锚物的，写夹在哪两样之间。
- 首帧站位仅用于开场。
- 图外必需内容写明何时如何出现。
- 必要空间关系仍须写清。
- 后上场的人，到上场那镜再写。
- 核心氛围只写在做什么，不写站位。
- 点名的环境音在本段写全，镜头里有变化才写。
- 安静的场面也写声源。
- 不点名声音，就写只要哪几类、按画面配。
- 心里话只做画外旁白。

### 分镜
- 先按「三」填分栏底稿、核对，再转换正文。

一镜写什么：

- 一镜按顺序写七样，没有的不写。
- 一、机位在哪、朝哪拍、景别。
- 二、画面里有谁。
- 三、谁要什么。
- 四、一个主要动作，开镜就做。
- 五、一句台词，配一个语气词。
- 六、听的人一拍反应。
- 七、怎么切。
- 一镜一段话，一件事写到底。
- 背景只当气氛，至多一句。
- 动作因果沿用剧情。
- 后面才出现的，前面的镜头不提。
- 禁止把结尾的状态写成全程的。

机位和运镜：

- 分场景不止一个，每镜开头写叫法。
- 镜头里不重写分场景。
- 机位写清在哪、朝哪拍。
- 运镜与固定机位按剧情选。
- 不以运镜代替主体动作。
- 过肩镜头写明越过谁拍谁。
- 要拍到反应，两人同框或切过去。
- 首镜第一帧起就在动，写清可见动作。

站位：

- 站位变了才在镜头里写。
- 关键帧位置仅限指定时刻。
- 站位随动作更新。
- 位移写清方向、路径与终点。
- 没有图的镜头，用文字写清站位。
- 位置靠固定物说，不只写画面左右。
- 同一钟点的人和机位，用远近或地标分开。
- 机位偏离6点朝12点或过肩，写画面左右。

台词：

- 台词写谁对谁说、什么语气。
- 台词原文只在 `{}` 里出现一次。
- 说话时手上的事不停。
- 画外说话写明画外发声。
- 禁止写“语速快”“停一拍”这类说法。
- 读错的字换成同音常用字。
- 屏幕文字留给后期贴。

声音：

- 音效写发声的物件，后跟 `<>`。
- 本段的声音不够这一镜用，才加一句音效。
- 与动作或切点有明确时序关系的声音写在发生处，其余声场补充写在镜头最后，不另起一行。
- 写什么在响、怎么响、远还是近。
- 一镜只挑一两样，不堆。
- 画面外的声音写明画外。
- 同一声音效只标一次 `<>`。

### 保持一致
- 只留最怕错的两三条。
- 不加新信息。
- 保持一致只列不变属性。

## 五、出了错再补

哪一镜出错补哪一镜，整篇不换写法。补之前先查这一镜是否写多了。

关键帧相关排查：

- 开头停滞：检查起始动作。
- 主体不动：检查全程位置约束。
- 图外缺项：检查出现时机与遮挡。
- 动作不接：检查关键状态可达性。
- 图文冲突：先统一该刻状态。
- 改图或改职责须遵从用户意图。
- 对照测试每次只改一个变量。
- 模式差异需多次对照验证。

其他问题：

- 进出画面、道具位置错：补开始和结束状态。
- 认错人或道具：这一镜补称谓对应@图片N。
- 朝向拍反：补机位在谁身后，不拍反打。
- 站错位、换边：补钟点和画面左右。
- 环境音断了：补这一镜的声源和远近。
- 冒泡、回音、啸叫：删水、浪、回音类词。
- 配乐删不掉：各种叫法都写上，首尾各写一遍。
- 切点生硬：补跟着哪个动作切。
- 拼版图读成两人：补画面只有一个〔称谓〕。
- 还不行：拼版拆成脸和全身两张图。
- 脸被镜头拉变形：补脸和手保持真实比例。

## 六、延长和编辑

模板照 sd25-pe 的「视频编辑模板」「视频延长模板」。

- 只坏开头：没人说话处裁开，后段向前延长。
- 只坏结尾：坏掉之前裁开，前段向后延长。
- 只改某样东西或某段声音：视频编辑。
- 续接下一段：普通生成，上段尾帧当首帧。
- 又改又延长：先编辑，再延长新片。

- [ ] 重复信息只合并表达，不同阶段的动作与必要起止状态未误删。
- [ ] 最终 txt 只有一套连续分镜正文，不含底稿栏目或占位说明。
- [ ] 本段事件写了目标、情绪来由与结束状态。
- 故事合同中的每个必需人物、道具和场景均已覆盖，没有合并两个已命名角色，也没有把素材猜测写成身份、年龄、关系或剧情事实。
- 每份实际使用的素材都有唯一而明确的职责。
- 普通素材参考项以项目中的正式叫法和中文冒号开头，再接素材编号与完整描述。
- 用户原始 Prompt 中已有的素材引用仍原样保留，没有因素材未附带或不可读取而删除、改号、翻译或改写为无参考生成；用户没有写出的素材引用没有被凭空新增。
- 素材未附带、损坏或不可访问时，没有声称已经查看，也没有补写只有查看素材才能确认的外观、音色、动作或场景细节。
- 不强迫无关素材出场；能够取得完整素材清单时，实际可用但未分配职责的素材已逐个列入 `【未采用素材】`。
- 不可访问素材没有被假装理解。
- 不同人物、商品和道具逐条映射，没有用范围句代替。
- 单人设定图没有同时定义两个出场人物；存在多个单人或群体候选时，已先按一人一图、一组一图完成分配。
- 首帧、尾帧和其他参考图逐张定义，没有互相覆盖职责；固定帧使用独立的 `@图片N作为首帧。` 或 `@图片N作为尾帧。` 精确角色句，没有弱化为构图参考；首尾帧画幅已经核对或按不可读取边界处理。
- 多关键帧按顺序逐张定义关键状态，没有承诺逐帧复刻或静态停留。
- 宫格分镜写清读取顺序、每格镜头职责和不采用的线稿、标注或占位内容。
- 白模已经识别为粗粒度或细粒度白模，并分别写清主体映射、继承信息和不采用内容。
- [ ] 必要空间关系未因有图省略。
- [ ] 图外必需内容写明出现方式与时机。
- [ ] 只带了本段出现的人、分场景、道具。
- [ ] 同一件事没有无故写两处。
- [ ] 随剧情变的没写进基础设定和本段。
- [ ] 基础设定、人物、物件、分场景照抄了。

- [ ] 没写总场景；场景只写了本段拍得到的。
- [ ] 同一处地方的叫法、方位、数量各段一样。
- [ ] 场景图在对应场景开头引用了。
- [ ] 写了几个人；道具写了数量和去向。
- [ ] 写了开场站位，各镜跟它对得上。
- [ ] 分场景不止一个的，每镜写了在哪个。
- [ ] 每镜写了机位朝向；站位变了的写了站位。
- [ ] 有钟面的，人和机位都报了钟点。
- [ ] 本段声音不够用的镜头加了音效。
- [ ] 声音行写明了要不要配乐、要哪几类声音。
- [ ] 镜头动静符合剧情需求。
- [ ] 首镜写明第一帧起的可见动作。
- [ ] 动作因果与剧情一致。
- [ ] 没有一直不变的表情姿势。
- [ ] 每句台词写了谁对谁说、什么语气。
- [ ] 有人听的台词，写了听的人的反应。
