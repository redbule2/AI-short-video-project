# 三维物件设计

用于把基础几何体或已有物体组装成目录里没有的新物件。调用和保存方式遵循[导演台](director.md)。

## 先拆解，再动手

先观察参考或构思目标的轮廓、比例、数量、接触和遮挡，写出“成品 → 组件 → 子组件/基础形体”的简短树状计划。按功能和独立编辑需要拆，不按几何体种类拆；分清主体、承托物与环境。查目录确认可以直接复用的预设。重复结构先做一份，独立运动部分预先留出边界。

## 从内到外装配

1. 一次完成一个有意义的组件。在直立、轴向清楚、便于检查的位置搭建，先轮廓再细节；有体积的杆件不能用平面冒充。
2. 优先使用建模参数。最终需要倾斜的组件先正着拼，检查后合并，再整体旋转；内部原本需要的倾角不必取消。
3. 多角度检查数量、厚度和接缝，再用 `object.merge` 合并刚性部件，给新对象语义名称。合并不会焊接、挖孔或修补结构；新基准点在整体底部中心，旧成员 ID 失效。
4. 用 `object.duplicate` 复制已检查的组件。它会产生默认位置偏移，按目标位置重新摆放。先设置整体朝向，再检查承托和接触，不能认为旋转前的贴合仍然成立。
5. 拿小组件继续装配上层。整体交付、复制、旋转或运动且内部无需独立变化时再合并；独立活动部分、支撑家具和环境保留独立。嵌套最多 10 层，不为凑层级增加合并。
6. 完成并合并需要一起运动的刚性物体后，再给新 ID 设置动画。不要先给所有零件复制相同轨迹。检查组件结构后，还要检查最终机位、分镜和连续运动。

可用本机脚本生成重复部件、计算几何和轨迹；脚本自动化不代替组件计划和视觉检查。按 `apply` 当前批次上限组织命令；每批使用成功读回的真实 ID。

## 拆散返修

先定位错误层级，`object.unmerge` 一次只拆一层，内层组件仍是整体。按直接 components 数量提供全新 ids，读回后修改对应部件，再从内到外合并；不要沿用旧成员 ID。

已有动画的合并/拆散须指定 frame，结果定格且无原动画。它不能无损整理运动结构，不为返修擅自删除用户动画。拒绝剪切等不可无损表达的变换时，处理真实原因。

## 示例：带植物的花盆

拆成花盆本体、植物1、植物2、植物3；本体再拆盆身/盆沿，单株再拆有厚度的茎/叶。先搭本体并检查、合并；再正着搭一株植物，检查、合并、复制两份。最后把各株整体转成不同倾角并放入花盆，检查前后左右的轮廓和接触。需要整体移动时再合并成品，需独立调整或运动时保留组件。可见盆口需要真正能表达开口的结构，实心几何叠放不会自动挖空。
