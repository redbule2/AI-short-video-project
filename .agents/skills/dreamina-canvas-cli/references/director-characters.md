# 角色表演设计

用于用户指定角色或确实需要坐卧、手势、互动等表演的任务。一般构图和走位优先简易人体；调用方式见[导演台](director.md)。

## 先安排人物关系和表演

确定人物位置、实际面向、互动对象、动作起止和镜头关系。先搭家具与环境，再选动作、观察动作姿势，最后摆放人物。目录名称只用于筛选，不能证明每帧的姿态或身体正面。

角色不是普通几何体：不要为摆放、贴地或改变身高而修改基准点和缩放。坐姿定位脚在座位前方的地面，再观察臀部与座面的关系，不把脚放上座椅。不同坐卧动作的根节点和身体位置不同，不能一律把人体包围盒最低点贴地。躺姿等按实际动作和画面调整，不凭静态尺寸补偿。

## 行走和跑步

CLI 可以直接组合路线和目录路径动作，不需要内部 Agent 的 perform 工具。

1. 用 `director catalog --kind motion --motion-usage path-traversal` 找标定的走/跑动作，沿 nextOffset 翻页，不用普通动作假冒路径步态。
2. 在 performance 工作区，用脚本或命令生成角色位置关键帧。规划路线与时间、避开障碍和其他人物；默认等时间采样、linear，通过位移改变速度。保持地面路线所需高度。
3. 用 `motion.add` 添加同一时间段的路径动作，使用 `locomotionMode=in-place`、`loop=true`；目录步幅由 CLI 补齐。通过 `object.set` 设置 `pathFacingEnabled=true`，由路径确定前进朝向，不叠加相反的手动转身轨迹。
4. 动作时间以当前时间线的整数帧填写，不把秒直接当帧。位置轨迹、动作片段和停留时段要同步；走到停点后结束步态，停留后用下一段走跑。不要在抬脚时用重复位置冻结整个动作。
5. 检查起步、转弯、停止、动作交界和全程脚步。有需要可使用空间切线、自定义动作或脚本生成路线，但须验证步态匹配；CLI 不自动避障或适配台阶。

## 动作衔接与取景

动作空档显示保存姿势或兼容角色的默认自然站姿，不会保持上一段坐卧。需要持续坐着就覆盖相关镜头及过渡时段；自定义骨架的回退效果须观察确认。

先确认人物真实面向，再安排正面、反打和过肩机位。相机看向角色的位置不等于拍到了其正面。用多角度观察检查脚、家具、身体、互动距离；再检查最终机位是否包含整个目标主体。角色没有静态尺寸不等于素材坏了，普通包围盒检查也不能证明坐卧接触正确。

走跑和动作切换必须检查连续输出。可导出 MP4，用本机播放器、视频理解工具、FFmpeg 抽帧辅助分析；静帧只证明抽查时刻。动作加载失败或时间冲突按真实错误处理，不把回退站姿宣称为完成表演。
