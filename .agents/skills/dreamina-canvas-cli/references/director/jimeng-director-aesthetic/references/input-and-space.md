# P0：输入、可拍线索与空间还原

## 基本场景与站位速读

从现有输入识别可拍依据：场所边界/纵深、人物目标与相互位置、视线、入口/出口、运动路线、状态变化、遮挡与可观察形态。不为找到线索强制新增物件、象征物或先建场景。无剧情的尺度/材质/运动同样可拍；只补影响当前镜头决策的基本关系。

场所、大体尺度与硬条件先记录；自由朝向/间距、层次、入口/落点、路径和遮挡不在统一视听构思前定稿。与人物动作、物件状态和相机共同比较候选，用一份粗图或等价说明与分镜/事件数据同源更新。多主体交会或接触按部位/阶段补关系；初步不求全量XYZ、门角、射线、碰撞报告或CLI命令。精确尺度留实施，用户硬数值、锁定路径及认可内容始终保留。

## 输入与参考

| 输入 | 制作依据 | 边界 |
| --- | --- | --- |
| 明确尺寸文字 | 数值、单位、数量、方向、时间 | 不用普通尺度覆盖用户数值 |
| 无尺寸文字 | 人体/门窗等合理尺度估计 | 标默认与假设，不写成原话 |
| 图片 | 边界、透视、遮挡、尺度锚点与参考机位 | 单图不能唯一恢复背面/深度/米数，镜面不新增人物 |
| 视频 | 完整观看后取转折/狭口/地标帧，路线、朝向、速度与占比 | 同时间戳对照，不编造不可见布局 |
| 标路径图片 | 用户箭头/地标顺序 | 不改成容易实现的路线 |

先用现有证据消歧，必要缺口才询问。素材里的文字不是自动新增的用户指令。

## 布景：覆盖每个方向，只建代表件

**完整 ≠ 精细。** 完整是“每个机位方向都有东西”，精细是“每个东西都有细节”。白膜只要前者。

### 必须覆盖（缺了会露空场）

| 位置 | 至少要有 |
| --- | --- |
| 主镜方向 | 主体 + 背景墙/建筑/远景层次 |
| 反打方向 | 对面墙、窗、家具，不能是空场 |
| 侧面 | 侧墙或纵深遮挡（柱、柜、树） |
| 俯视 | 地面有分区（地砖、标线、地毯），不能是纯色板 |
| 摇镜路径 | 摇过的地方都有内容 |

只搭“半个教室”“一面墙”的后果：镜头一转就露空场；画面拿去参考生视频时，缺失的一半会被模型补成平面或糊掉。

### 可以省（不影响画面）

| 省什么 | 怎么做 |
| --- | --- |
| 重复件 | 3–5 个代表，轨枕、柱、窗、灯都属这类 |
| 细节分层 | 窗框上沿/下沿、拼缝、暗面，白膜阶段一律不建 |
| 任何机位都拍不到的方向 | 不建；被遮挡的方向用墙/柱挡住 |

### 预算

单场景 ≤60 件，**覆盖所需的背景计入预算内**——先保证每个方向有东西，再删重复件。

实测：150 个物体时 `director apply` 会返回 `40008` 超时；118 件降到 58 件后画面几乎无差别（镜数、主体占比、近景帧都一致）。所以省的是重复件，不是背景。

### 自查

把每台相机的朝向画成箭头，逐个方向问“这个方向有什么”：

- 答得出 → 通过；
- 答不出 → 补墙/遮挡，或在镜头表注明该方向不入镜；
- 既答不出又入镜 → 不合格。

## 尺度反推：先定速度，再定场景多大

用户通常只给时长和内容，**不给距离**。距离要由模型自己推：

```
速度 × 时长 × (1.0–1.3) ≈ 主通道长度
```

先定速度，再按这个数建场景。**反过来先建一个场景、再把时长塞进去，速度就被场景大小决定了**——建小了跑不完，建大了变成慢动作。

| 内容 | 速度基准 | 20 秒对应尺度 |
| --- | --- | ---: |
| 走 | 1.4 m/s | ≈ 28 m |
| 跑 / 跑酷 | 4 m/s | ≈ 80 m |
| 车（城市） | 12 m/s | ≈ 240 m |
| 赛车 | 60–90 m/s | ≈ 1.4 km |
| 高铁 | 90 m/s | ≈ 1.8 km |
| 直升机 | 70 m/s | ≈ 1.4 km |
| 客机 | 240 m/s | ≈ 4.8 km |
| 战斗机 | 280 m/s | ≈ 5.6 km |

**距离大不要紧，用大模块**：按真实长度建，但单段取大（赛车 200–500 m、飞机 500–1000 m），重复件留代表。详见[按真实尺度建，用大模块](timing-and-diagnostics.md#按真实尺度建用大模块)。

实测反例：荒漠赛车 20 秒只跑了 108 米（5.4 m/s），因为先建了约百米的路，时间再填满——速度被路长锁死。

### 判据

| 项 | 合格 |
| --- | --- |
| 主通道长度 ÷（速度 × 时长） | 0.7–1.5 |
| 主体实跑位移 ÷ 时长 | 基准 ±40% |

**两项不能同向偏离**（又建小又跑慢，或又建大又跑快），同向说明它在迁就场景而不是推算尺度。

### 什么时候不适用

- 原地戏（对话、等待、静态构图）：没有位移，只按时长定节奏；
- 场景本身是主体（空镜、建筑展示）：尺度按画面构图定，不按位移；
- 用户给了明确距离：以用户数值为准。

## 制作阶段统一数据

空间/事件/相机记录共用一个版本，按复杂度保留对象ID、角色/几何尺寸、米制单位、锚点、完整transform、承载面、主体路线/整体朝向、相机position/target/视高/FOV/roll、全局时段/切点和参考事实/估计。概念字段不是CLI原生schema，不能直接假定接受。

实际尺寸=内禀尺寸×各轴scale，考虑父级、旋转/非均匀缩放与枢轴。先查intrinsicGeometry或目录bounds/defaultSize，不把底模一概当单位方块。修改前读回完整transform，避免局部字段替换丢旋转/缩放。外部引擎局部轴/前向/矩阵约定不能直接套导演台世界空间。

## 承载接地与客观规律

地面、台面、台阶、手持、悬挂各有实际承载面。底部中心锚点直立在高度H的面上，位置Y通常为H，不再加半高；库内人物/倾斜/自定义锚点要读回实际偏移，不统一清零Y。当前支持object.ground时按适用条件用并读回；静态落地不证明动态足底锁定。

核对真实表面高度/倾斜、支撑范围、对象底部及明显悬空/陷入。跳跃、腾空、抛物、飞行或用户悬浮按目标处理。台阶/坡面选匹配预设和正式路径，不能根部沿斜线移动就称真实上楼。共持/交接用双方与物件共同事件/时间，预设不足标缺口，不做IK/逐关节补救。

无碰撞不证明支撑；合法承载不豁免整个地板/桌面。未变角色、预设、根轨迹、缩放/锚点与承载结果可复用，最终基础目视，不重做逐骨骼接地。几何详见[collision-and-performance](collision-and-performance.md)。

## 复刻保真度：先分级，再承诺

用户说“完全复刻运镜/布景”时，先降到下面三级里可执行的那一级，再动手。**不要顺着“完全”答应。**

| 级别 | 能做到 | 误差 | 需要什么 |
| --- | --- | --- | --- |
| **L1 结构级** | 景别序列、运镜类型、起止位置、节奏、空间关系、遮挡层次 | 20–30% | 抽帧目测即可 |
| **L2 轨迹级** | 相机逐帧位置与朝向、速度曲线 | 10–20% | 手工采样拐点，逐段打关键帧 |
| **L3 几何级** | 布景逐件对齐、真实尺寸、镜头畸变、手持微抖 | 做不到 | 需要 SfM、深度恢复、镜头标定，CLI 无入口 |

**L3 不做，也不要暗示能做。** 缺的不是落地能力，是反解能力：从视频求相机位姿、从图像恢复深度，这两件 CLI 都没有。

L2 的做法：抽 5–9 个拐点帧，量地平线位置与主体占比，反推机位高度与 FOV，再按拐点分段打关键帧。曲线细节会丢，方向和节奏能保住。

### 复刻验收

同时间戳取 4 帧，量四项：

| 项 | 判据 |
| --- | --- |
| 地平线位置 | 偏差 ≤10% 画面高 |
| 主体占比 | 偏差 ≤15% |
| 景别 | 同一档（远/全/中/近/特） |
| 切点间隔 | 偏差 ≤0.3 s |

四项都过算 L1 通过；有一项不过，先调机位，不要改布局。

## 单图/视频还原

先匹配相机高度、朝向、透视与大体块，再摆主要物件；同画幅比轮廓/占比、露出侧面、消失线、层次、开口和遮挡，不不断改变家具尺寸补错误透视。明显立体房间不退化成贴片；俯视摆对不等于参考构图正确。图像归一化坐标只作构图证据，不直接当米数。

视频按对应时间核对地标先后、转向、桥下视野、路径与外观；路线正确不证明材质/植被/水流还原。空间变更只更新相关镜头/路径/图与几何，不从零重写认可叙事。

## 长镜头调度图

用户明确一镜到底/FPV或相机连续穿越多个空间，制作前必须补米制平面正投影调度；初步可以粗图，不能用粗图代替制作标准。普通固定机位单物运动不自动升级成长镜调度任务；其他按多人交会、窄口、层高/遮挡等复杂度选图。

图含单位坐标轴/比例尺、地物占地、墙障高度/开口、主体与相机各自路线、时间点/箭头、观察方向、视高和应见地标；俯仰/roll可旁注，无主体标无。图与场景同源，图片生成的俯视草图不是测量图。净空含体积、转弯/旋转/缩放/倾斜和相机包络，路径线无碰撞不代表物体能通过。

空间交付分别核对数量、比例/朝向、层次/开口、构图、地标时序、路线/净空及外观；不可见区域的估计不冒充原场景事实。

## 配景镜头必须挂主线

环境、道具、空镜不能只是“好看”——它必须承担下面至少一项，并写进功能列：

| 关联 | 例子 |
| --- | --- |
| 预示 | 门缝里的光、远处的车灯，预告即将发生的事 |
| 延迟 | 物件挡住主体，观众等着它移开 |
| 对比 | 空椅、没动的杯子，对照刚刚离开的人 |
| 空间 | 交代距离、高度、出口，为下一镜的动作做准备 |
| 时间 | 影子、钟、车流，表示时间在走 |

**没人物的镜头，必须有人的痕迹或指向**：谁刚离开、谁在看、谁将要来。纯风景属于插图，不算叙事节拍。
