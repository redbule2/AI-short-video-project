# P1：时序、剪辑与运动诊断

设计用大致时段，制作落实一个全局帧时钟。不因多镜就全读诊断；指定速度/切点、循环或异常时读对应段。输入为实际fps、全局时间、动作片段和相机轨道，输出为问题对象/镜头/时段、实际证据与最小修复。

## 插值：匀速用 linear

**除刻意的起停缓动外，一律用 `linear`。**

实测（导演台 1.3.0，24 fps，对象位置每 8 帧一个关键帧，匀速折线）：

| 帧段 | linear 每帧位移 | smooth 每帧位移 |
| --- | ---: | ---: |
| 6→7 | 0.80 | 0.73 |
| 7→8 | 0.82 | **0.29** |
| 8→9 | 0.81 | **0.29** |
| 9→10 | 0.77 | 0.72 |

**smooth 在每个关键帧前后把速度压到约 40%**，离开关键帧又恢复——每个键一次“减速—加速”，画面上就是一顿一顿。

规则：

- 走、跑、车、跟拍、匀速摇移：`linear`。
- 只在**起幅/落幅**需要缓入缓出时用 `smooth`，且只给端点键，中间保持 `linear`。
- 一镜里有多个 `smooth` 键 = 多次停顿，等于把人走成机器人。
- 相机轨实测 smooth 与 linear 差别不明显，不要靠它做缓动；要缓动就改关键帧分布。

自查：每个关键帧前后各抽一帧，比较两段位移。**键附近的位移掉到平时的 60% 以下**，就是插值在刹车。

## 速度基准

**世界速度决定“像不像慢动作”，相机速度决定“拖不拖沓”。** 两者分开定。

### 世界速度（主体真实移动）

按真实物理取值，不按“看着差不多”取值。**20 秒距离**指该速度跑满 20 秒的位移，用于反推场景尺度；**负担**指按真实尺度建景的成本。

| 类别 | 对象 | 速度 m/s | 20 秒距离 | 负担 |
| --- | --- | ---: | ---: | --- |
| 人 | 走 | 1.2–1.5 | 28 m | 轻 |
| 人 | 快走 / 小跑 | 2–3 | 50 m | 轻 |
| 人 | 跑 / 跑酷 | 3–5 | 80 m | 轻 |
| 人 | 冲刺 | 8–10 | 180 m | 轻 |
| 骑 | 自行车（休闲 / 竞技） | 5–8 / 12–15 | 280 m | 中 |
| 动物 | 马（慢步 / 疾驰） | 4–6 / 15–20 | 400 m | 中 |
| 动物 | 猎豹冲刺 | 25–30 | 550 m | 中 |
| 路 | 城市车 | 8–15 | 240 m | 中 |
| 路 | 郊区 / 高速 | 20–35 | 600 m | 中重 |
| 路 | 赛车 / 拉力 | 40–90 | 1.4 km | 重 |
| 轨 | 地铁 / 普速列车 | 15–30 | 500 m | 中重 |
| 轨 | 高铁 | 80–100 | 1.8 km | 重 |
| 空 | 直升机 | 60–80 | 1.4 km | 重 |
| 空 | 螺旋桨固定翼 | 80–120 | 2 km | 重 |
| 空 | 客机巡航 | 230–250 | 4.8 km | 很重 |
| 空 | 战斗机（巡航 / 加力） | 250–350 / 400–600 | 6–12 km | 很重 |
| 武器 | 子弹 / 炮弹 | 700–1000 | — | 瞬时 |
| 武器 | 导弹 | 400–1000 | 12 km | 很重 |
| 自然 | 雨 / 雪 / 强风 | 7–9 / 1–2 / 20–30 | — | 轻 |

### 按真实尺度建，用大模块

真实速度 × 20 秒距离不小（赛车 1.4 km、高铁 1.8 km、战斗机 5.6 km）。**不降速，也不需要压缩场景**——白膜烧的是对象数量，不是地面面积。

做法只有一条：**按真实长度建，但用大模块，不按细节密度重复。**

| 速度 | 单段长度 |
| --- | --- |
| 慢（走、跑） | 20–50 m |
| 中（车） | 100–200 m |
| 快（赛车、高铁） | 200–500 m |
| 极快（飞机） | 500–1000 m |

- 对象数 ≈ `长度 ÷ 单段长度 + 道具数`。1.4 km 的路用 14 段 100 m，加边线、车、路标，约 40 件；
- **不按真实细节密度重复**：轨枕、窗格、砖缝、枕木这类，一律用 3–5 个代表，或者干脆不建；
- 两端不建的部分用遮挡（山体、建筑、云墙）收边，不要留空边。

**参照物间距 = 速度 ×（1–2 秒）**（近层），远层 ×（3–5 秒）。飞机 250 m/s，近层云就该每隔 250–500 m 一朵；按“车”的间距摆云，速度对了也会像滑翔。

**暂不做流层与循环复用**：循环接缝、重复感、远近层速度不匹配，比“多建几个大模块”更容易出错。只有当等比建的对象数超过预算（约 60–80 件）时，再考虑压缩，届时单独评估。

### 相机速度

| 运动 | 常见区间 |
| --- | --- |
| 缓推 / 缓拉（情绪镜） | 0.05–0.2 m/s |
| 常规推轨 | 0.3–1 m/s |
| 跟拍 | 与主体同速 |
| 摇臂升降 | 0.3–0.8 m/s |
| 甩镜 | 2 m/s 以上（瞬时） |

### 镜长参照（不是硬指标）

| 类型 | 平均镜长 |
| --- | --- |
| 动作 / 打斗 | 2–3 秒 |
| 常规剧情 | 4–6 秒 |
| 文艺 / 抒情 | 8–15 秒 |
| 极简长镜 | 20 秒以上，靠场面调度支撑 |

### 三条用法

1. **先算再定帧**：有位移的镜头，`时长 = 位移 ÷ 速度`。反过来先定时长再塞动作，就会出现“3 米走 20 秒”。
2. **慢动作判据**：单镜主体速度 < 基准的 60%，且不属于抒情镜 → 判慢动作，缩短时长或加大位移。
3. **抒情镜走举证**，不受 60% 限制：每 2 秒至少写出一次可辨认变化（表情、遮挡、光影、位移、物件状态）；连续 4 秒无变化，就是多余的长度，删掉。

**相对速度**：闪迹、导弹、追击物相对主体的速度，至少是主体的 2–3 倍，否则在画面里“追不上”，也读不出快。

**图元载体补步频**：走、跑时每 6–8 帧给一次轻微上下起伏（±3–5 cm），避免匀速滑行——没有步频，速度对了也会像飘。

## 相机多通道联合节奏

先确定起幅、过渡与落幅的观看关系，再一起定position、target、FOV、roll与事件时间。没有人物动作触发时，尺度/视差、探索、观察距离、等待与节奏也可解释运镜；不要求每次移动新增剧情信息。

| 检查层 | 要看什么 | 常见反例与修复 |
| --- | --- | --- |
| 路径/切向 | 位置是否连续，转弯方向和前进分量如何交接 | 位置接上但切向尖折→修局部弧线/节点/时序 |
| 视轴/target | 指向何处，主体或新目标如何接力 | 平滑位移却突然转头→联合修target及转换时段 |
| 主体屏幕位置 | 是否有意保持或移动，是否误失 | 世界target正确但屏幕跳边→修机位/target/FOV共同构图 |
| 景别/尺度变化率 | 主体放大缩小是否符合观看意图 | 快速膨胀、FOV抵消推进但仍称推近→查距离与投影 |
| 速度与停留 | 谁先启停、追随滞后、落幅识别时间 | 每个节点无意刹停、全程机械匀速→修时间分配/插值 |
| roll与激活区间 | 倾斜有意，通道与相机切点一致 | 位置硬切但视轴继续插值→所有相关通道同边界核对 |

世界速度连续不等于画面自然；各通道smooth也不保证构图、速度或加速度连续。既有tangents/spatialTangents入口不证明其具体求值和端点行为；用当前schema构造、读回并看片，不给无来源参数结构或数值阈值。

实际先看转段前/后及区间连续播放；记录预期保持/变化的屏幕锚点与尺度，不用“smooth”标签作完成证据。可选减速、停留、继续加速或反向，节奏服务任务而非固定缓入缓出。

## 路径时间与速度

路径形状与时间一起设计。直线匀速可用`p(t)=p0+v*t`；曲线按弧长分配或核对实际速度，不能控制点等分时间就称匀速。`linear`不保证方向/速度连续，`smooth`不保证用户要求的匀速。

以`v_i=||p_(i+1)-p_i||/Δt`核对完整段、拐点、切点两侧和片尾；伴飞/环绕分别看共同前进与旋转分量，不要求合成速度恒定。用户指定匀速时保持要求；有意加减速不自动视为故障。

同时看相机、主体屏幕位置、投影速度与大小；屏幕变速可能由距离、FOV、透视或转向造成。查远端关键帧、保持点、方向、切线和覆盖，不用密集烘焙万能补救。

## 持续动作循环

持续走跑优先目录明确的path-traversal素材。当前已有来源入口为`director catalog --kind motion --motion-usage path-traversal`，按hasMore/nextOffset取得必要分页，执行前用当前schema核对。普通表演用其实际用途，不因名字含走/跑就手改motionUsage冒充路径支持。

按官方素材补用途/步幅及类型化motion引用；路径动作按距离驱动，用当前支持的loop、片段完整时长和pathFacingEnabled。loop只管片段内部，不延长durationFrames。先真实短片段验证再扩展，动作结束应接待机/停止，不让后半段回绑定姿势。

源位移、引擎距离驱动与整体轨道要一套一致规则，避免重复位移或未经证据剥离根运动。移动方向与身体朝向分别设计，倒退/侧移不能被自动朝向覆盖。核对多次接缝、转弯、停走和片段切换；位置停而步态还播、源首尾复位和片段重启分别定位。

## 全局时间与硬切

世界动作沿同一全局时间，片段入点/局部时间是映射，不是每次切镜世界归零。切点采用当时实际位置、姿态和物件状态。用户切点原样保留，未指定再按事件/观看节拍安排。

实际fps与边界约定统一：切点c上一镜末帧c−1，输出N帧末帧N−1；保持采样不自动增加影片帧。单相机硬切核对hold真实区间和position/target/FOV/roll一起切；分镜切换核对每台激活相机，默认相机截图不证明分镜生效。

查c−1/c/c+1及邻近连续片段：动作相位、屏幕方向、视线、地标、物件归属与必要重新定向。单镜内部检查状态/注意力接续，多镜检查跨切点的推断依据；有意省略/跳切不自动判失败，但不能掩盖已知错误。

## 按症状定位责任层

| 现象 | 优先核查/修复 |
| --- | --- |
| 主次不清/错误裁切 | 联合核对机位、target、屏幕尺度与人物位置/朝向；锁定项保持，修自由或受影响项 |
| 信息提前显露/揭示过晚 | 遮挡物位置、形体/状态与变化时序，以及人物动作相位和相机视线/路线；不能只修FOV |
| 动作、揭示与转移触发不同步 | 共用事件时钟，核对人物/物件/遮挡状态和相机各自触发时刻 |
| 连续转段生硬 | 速度、方向/路径切向、视轴/target与尺度交接，连同动作相位检查 |
| 动作资源缺失/能力不足 | 标明未查、未验证或已知不可实现；联合改写受影响自由设计或标未完成，不靠切镜藏失败 |
| 世界轨道连续、人物复位 | 预设身份、源入点、循环首尾、片段重启/源位移 |
| 人物和轨道都跳 | 时间、重复帧、插值/切线、远端键与覆盖 |
| 世界速度稳定、观感忽快忽慢 | 相机、FOV、距离、视轴、屏幕尺度/位置 |
| 整体高低/大小错 | intrinsicGeometry、锚点、缩放、单位和承载面 |
| 接触过程脱手/归属错 | 双方事件时间、预设相位、道具附件与整体轨迹，不修手部IK |
| 脚滑/悬空或台阶不适配 | 路径用途、步幅/距离驱动、启停、锚点和表面；不逐关节锁脚 |
| 本地好、远端动作缺失 | 发布/资源引用与fresh pull，不重制本地动作 |
| 标记/追踪异常但目视可见 | ROI、遮挡、颜色/光照与追踪关联，指标须目视复核 |

仅在异常有疑点时用现有数据和原生预览隔离原因，保持原任务与基线副本，一次只改变一个原因层；关联通道一起保持一致。关闭循环/暂去叠加只可定位，最终恢复用户要求的循环、表演、群众与相机。诊断副本不是交付，不为此另造门禁或替代工具。

先修原问题段及前后相邻转段，再按依赖扩大：位置/路线影响构图/碰撞/接触，全局时间影响所有采样与切点。保留修改前计划、实际帧/时段差异、修订原因和修后证据；有意改方案另记新版本，不覆盖旧计划追认。复用未变布景和查询，最后只对最终版本必要全片核对与导出。不把Root Motion、插值底层或骨架错误当无证据根因，不借诊断恢复逐关节/自定义动作流程。

## 依据与并行边界
