按请求/观看构想选条目，不遍历整库套技巧。每段记录**起始观看关系→可选相机/人物变化与节拍→最终视觉落点**。落点可以是信息、关系、细节或有意的观看体验，不必增加剧情事件。用户指定方案优先；数值按真实场景和当前CLI标定。

## 设计前选择与加载

自主新设计前读取本段、共同数据、基础运镜中相关行；选复合运动时，在定稿和首次写相机轨道前读取组合交接及相关时序段。参数/能力未知先查官方契约；设计共同段无需等导出或出现报错才读。加载清单记录时点，补读不追认之前的设计已使用。

从起幅/落幅与注意力触发条件选运动，而非把技术可行的跟随当默认。局部先行时先定能读清的局部/轮廓和必要空间参照，再决定如何让身体、互动对象或环境进入画面；可用已有动作片段取景，不必新增掌指控制或剧情。涉及注意力接力，先定接力前后的对象/视觉区域与转移触发，再协调position、target、FOV和人物相位。

人物登场、目击反应、隐藏物首次露出共用[信息揭示顺序](story-and-camera.md#信息揭示顺序)。同一条规则确定观众何时知道什么，下面的配方负责把结果落到轨迹、取景和事件帧。

核对两个内部候选是否真有不同的观看入口、关注顺序或体验。若差异仅是后拉更远、跟随更久、相机更慢，返回叙事设计重选；用户指定纯参数修改时保留其范围。几何顺畅只是实现条件，不证明选择充分。静镜、纯推进和等距跟随可以被选中，但应由本场景的可见依据而不是实现省事决定。

## 按功能选手法：从 beat 到镜头

不要从“情绪词”直接找运镜。先拆 beat，把每个 beat 写成一句**功能**，再用功能检索手法。

**六步**

1. 拆 beat：这场戏 3–6 个变化点。
2. 写功能：观众此刻该知道什么 / 感到什么 / 期待什么。
3. 检索：用下表找 2–3 个可用手法（多对多，一个功能对应多个手法）。
4. 过滤：导演台能否实现 + 空间是否支持 + 时长是否够。
5. 对比：与前镜不同功能、不同景别、不同方向；同了就换。
6. 定稿：只留一个，写进镜头表的“功能”列。

**功能要用固定句法写：主体 + 动作 + 可辨认的变化结果。**

- ✅ 「他起立（从坐到站）」「她转向窗（背对镜头）」「同学转头（看向他）」
- ❌ 「学生答不出」——里面其实有三拍：起立、张口、同学反应，写成一个功能就必然一镜到底。

**beat 表里至少有一个非人物节拍**：门开合、车窗隔开两人、桌上物件被拿走、空镜。没有这类节拍，全片可切的只有人脸和身体，镜头数一定少。

| 功能 | 可用手法 | 反例（会削弱这个功能） |
| --- | --- | --- |
| 建立威胁 | 低机位推近；背后跟随；前景遮挡后揭示 | 高机位俯拍 |
| 延迟揭示 | 越过遮挡横移；先局部后主体；画外声源 | 开场就给全景 |
| 关系失衡 | 一近一远双人；越肩；偏心构图 | 两人等距同框 |
| 时间压迫 | 递减时长；加速推；甩镜 | 长镜头静止 |
| 孤立无力 | 大远景加负空间；顶视；后拉 | 中景平视 |
| 卷入跟随 | 手持跟随；主观 POV；贴背 | 固定全景旁观 |
| 抽离审判 | 俯视；升高后拉 | 低机位仰拍 |
| 转折重音 | 景别跳两级；静变动；方向反转 | 逐级过渡 |
| 打击重音 | 插入特写（接触点）+ 极短镜 + 留白 | 拍全过程、拉慢动作 |
| 关系缓和 | 双人同框；对称构图；静止 | 手持加偏心 |
| 他人反应 | 反应切（先给反应再给原因）；群像错时 | 反应晚于事件太久 |
| 认知崩塌 | 希区柯克变焦（推拉同时）；固定机位突然失重 | 无理由推拉 |
| 时间凝滞 | 子弹时间（定格 + 环绕） | 站着不动绕圈 |

**三条对比校验（选完必过）**

- 相邻镜同功能 → 换手法。
- 相邻镜同景别 → 跳级（两级）。
- 相邻镜同方向 → 改方向，或插一个静止镜。

功能写不出来，说明这镜还没设计，不要进入分镜表。

## 技术的触发物

任何手法都要有依据，否则是炫技。依据有两类：**戏里已经发生的事**（触发物），或**观众此刻该有的身体感**（情绪依据）。选手法前先回答一句：因为戏里发生了什么，或因为观众该感到什么，所以这镜用它。

| 手法 | 触发物（戏里必须先有） | 没有触发物时 |
| --- | --- | --- |
| 子弹时间 | 人物腾空、翻身、濒临被击中，动作处于未完成状态 | 站着不动绕圈，变成展示台 |
| 速度坡道 | 蓄力 → 悬停 → 出刀，动作本身有停顿与爆发 | 硬做，像掉帧 |
| FPV | 攻击来自空中，或需要交代空间纵深 | 平地上突然飞，没有理由 |
| 低机位出场 | 有更高的东西在场（巨兽、楼体、天） | 空旷地平拍，只是低 |
| 英雄环绕 | 战斗结束、他站着、敌人已倒 | 打斗中环绕，看不清 |
| 打击插入 | 确实发生了接触 | 没接触就插特写，假 |
| 延迟揭示 | 有东西被遮住，且观众知道有 | 藏了不揭示，断 |
| 跟拍 | 主体在移动，且观众需要跟着看 | 静止时跟拍，无意义 |

**第二类依据：情绪依据。** 用户没说技法、戏里也没有明确触发物时，可以用“观众此刻该有的身体感”作依据（见下方[情绪 → 运镜](#情绪--运镜不靠触发词)）。

| 观众该有 | 可用运镜 |
| --- | --- |
| 被压制、不安 | 荷兰角（地平线倾斜）；低机位仰拍；前景遮挡 |
| 对峙、一强一弱 | 背后过肩（前景肩占大）；一近一远双人 |
| 蓄势、即将出手 | 从物件起幅的极低机位（剑尖、枪口、脚） |
| 混战、贴身 | 环绕；手持跟；甩镜 |
| 敬畏、登场 | 斯皮尔伯格登场（局部碎片 → 揭示）；低位爬升 |
| 顿悟、崩塌 | 推近 + 拉焦；dolly zoom |
| 时间凝滞 | 子弹时间 |
| 加速冲击 | 速度坡道 |
| 孤独、渺小 | 大远景负空间；顶视 |
| 胜利、加冕 | 英雄环绕（低位爬升） |

**两种依据有一个就成立。** 两个都没有，这镜的运镜就是装饰。

## 情绪 → 运镜（不靠触发词）

戏里没有明确触发物、用户也没点名时，从“观众该有什么身体感”反推运镜：

| 观众该有 | 可用运镜 |
| --- | --- |
| 被压制、不安 | 荷兰角（地平线倾斜）；低机位仰拍；前景遮挡 |
| 对峙、一强一弱 | 背后过肩（前景肩占大）；一近一远双人 |
| 蓄势、即将出手 | 从物件起幅的极低机位（剑尖、枪口、脚） |
| 混战、贴身 | 环绕；手持跟；甩镜 |
| 敬畏、登场 | 斯皮尔伯格登场（局部碎片 → 揭示）；低位爬升 |
| 顿悟、崩塌 | 推近 + 拉焦；dolly zoom |
| 时间凝滞 | 子弹时间 |
| 加速冲击 | 速度坡道 |
| 孤独、渺小 | 大远景负空间；顶视 |
| 胜利、加冕 | 英雄环绕（低位爬升） |

这套表按**身体感**分类，不按题材。武侠的对立、商战的压迫、亲情的疏离，用的是同一张表。

选定身体感之后，还要定“观众是谁”，再到[运镜矩阵](#运镜矩阵观看关系--起幅落幅)按“起幅 → 落幅”挑具体手法。

三条判断：

1. 说不出“因为戏里发生了什么”，就不要用这个手法。
2. 触发物必须在**前一镜或本镜前半段**看得见，不能靠旁白或事后解释。
3. 一个镜头只承担一个触发物；要叠两个手法（如子弹时间 + 速度坡道），就得有两个触发物，且对齐同一条动作曲线。

## 反向触发：用户点名要某个手法

当提示词直接要求“要有子弹时间”“必须有一次俯冲”，它不是条件，是**目标**。不要因为没有现成时机就硬套，也不要因此丢掉用户要求。做法是倒推：

1. 查上表，写出这个手法需要的触发物。
2. 在当前情节里找最接近的节拍；没有就**补一个动作节拍**。
3. 补的只能落在动作与空间层：人物、结局、已锁定的行为、场景不能动。
4. 检查因果：前一个 beat 是否足以引发这个动作（爪拍下来，所以他腾空）。
5. 补不出来就降级或替换，并明确说明理由（封闭走廊无法腾空，改用静止主体加轻微相机漂移表现时间凝滞）。

补出来的节拍要写进 beat 表，标注“为满足指定手法而补”，让后续修改知道这一拍是为什么加的。

三条反例：

- 不补动作直接套手法：站着绕圈，变成展示台。
- 为了手法改锁定内容：为了子弹时间让他飞起来，改了原意。
- 补了动作但没有触发源：人物自己突然跳起来，观众莫名其妙。

**判断标准**：补完之后，把这一拍单独拿出来问“他为什么会做这个动作”，能答上来才算成立。

## 剪辑层：镜头之间怎么接

白膜也能做，四招够用：

| 手法 | 做法 | 反例 |
| --- | --- | --- |
| 匹配剪辑 | 前后镜的形状、动作或构图相似，切点对齐 | 形状差太远，观众接不上 |
| 跳切 | 同机位同景别，时间跳一下 | 无理由跳，像穿帮 |
| 遮挡转场 | 前景物体扫过画面时切 | 遮挡没扫满就切，露缝 |
| 反应切 | 先给反应，再给原因 | 反应早于事件太久，观众困惑 |
| 打击插入 | 0.2–0.4 s 特写，框住接触点、碎片、衣角或地面裂纹 | 拍全过程；白膜里试图做凹陷变形 |

切点落在动作进行中（match on action），不要等动作做完。

### 打击插入（impact insert）

打击感靠三件事：**插入特写 + 极短镜 + 留白**。三样缺一样，力量就散。

- **拍什么**：刃与身体接触的那一点、飞起的碎片、被踩裂的地面、绷紧的衣角。不拍整个人。
- **拍多长**：0.2–0.4 s。超过 0.5 s 就变成"展示"，不是"击中"。
- **怎么接**：插在接触前一帧或接触后 1–2 帧之间；前后镜必须留有可辨认的锚点（同一位置、同一颜色、同一动作方向）。
- **白膜怎么做**：白膜没有形变和破坏，只能"框住那个位置"。裂口用一块黑色小几何、碎片用小方块，不要试图做凹陷。
- **反例**：插入镜拍的是脸——那是反应镜，不是打击镜；插入镜拍全身——那是中景，不是重音。

### 参考片驱动生成时的切点

不需要为了“怕切点被吞”而把镜头拉长。实测 12 秒 9 镜、最短 0.5 秒，生成 3 次切点全部保留。

如果两个镜头看起来几乎一样，切了也等于没切——先做差异，再考虑时长。

## 时间戏法：子弹时间、速度坡道、升降格

白膜没有时间重映射。能做的只有三件事：**定格、改相机速度、改剪辑节奏**。速度坡道与慢放本身交后期。

### 子弹时间 = 冻结环绕

- 用 `pose.set` 把人物定在动作中段（不要挂动作片段，避免循环复位）。
- 相机绕 120°–180°，半径 2–3 m，高度同时升 0.5–1 m；每 0.25 秒一个关键帧。
- 白膜能证明：环绕弧度、主体占画面、背景如何流转。
- 反例：一圈 360°（时长不够会赶）；绕圈时主体姿态在变（等于穿帮）。

### 速度坡道 = 常速 → 时停 → 爆发

术语：**speed ramp**（速度坡道）。中间完全静止时叫 **freeze + ramp**；游戏/动画里打击瞬间停几帧叫 **hit stop**（顿帧）。它属于**时间重映射**，不是剪辑手法，也不是运镜手法。

白膜没有时间重映射，所以一条镜头内的连续坡道做不出来，只能拆成三段：

| 段 | 白膜怎么表达 | 参数 |
| --- | --- | --- |
| 常速 | 正常镜头，交代动作 | 1.0–1.5 s |
| 时停 | **切一个静止镜头**：相机与主体都不动 | 0.5–1.0 s |
| 爆发 | 极短镜头 + 大位移 | 0.2–0.4 s；位移 1.5–3 m 或甩镜 90°–180° |

为什么必须切开：白膜是匀速播放，相机加速能被看出来，但**主体不会慢下来**。所以“时停”只能靠一个静止镜头表达。

真正的连续坡道交后期：导出后对这一段做时间重映射（0.3x → 0 → 2x），白膜只提供三段的长度与位移依据。

反例：
- 时停段相机还在漂 → 看起来是慢放，不是时停。
- 爆发段只用变焦 → 没有空间位移，不像冲出去。
- 三段等长 → 没有坡道感。

### 升降格近似

- 白膜只能改动作片段的 `speed`，不能改时间轴。
- 升格（慢）：片段 `speed` 0.5，相机同距离走更长时间。
- 降格（快）：`speed` 2.0，同时缩短该镜时长。
- 反例：人物 slow、相机不 slow——主体慢背景快，像穿模。

### 三条总反例

- 全程环绕 → 眩晕，没有落点。
- 升格不降相机速度 → 主体和背景速度不一致。
- 用变速补节奏 → 白膜里看不出，导出后才发现镜头长度不对。

## 运镜与人物共同数据

观看关系、场景遮挡物位置/状态、物件归属、人物世界路线/整体朝向/预设相位与相机position/target/FOV/roll来自同一空间/事件/全局时间版本。在自由布局、路径和动作定稿前共同选择，不先锁scene再把相机贴上去。每个候选都是完整观看方案，至少说明这些通道如何共同支撑关注顺序与触发；仅相机参数差异不充数。移动人物不能一直用起始位置作环绕中心。只改相机时保留锁定主体数据；联合调整只涉及自由或受影响项。关键画面同时核对人物动作、物件状态、遮挡和机位，不能只检查相机轨迹。单镜强耦合通道由同一方案协调，独立查询/计算可并行，汇合后按[统一写入](execution-and-recovery.md#并行执行与统一写入)串行提交。

制作时用米、秒和角度记灰盒初值，按当前CLI核对FOV轴、单位及范围。取主体根部或明确世界点 `P(t)` 作轨迹锚点，另选实际注视点 `Q(t)`，例如脸、两人之间、通道远端。水平跟拍可用 `C=P+aF+bR+hU`，`F` 是水平单位前进方向，`U` 是向上单位向量，`R=U×F`，`a/b/h` 分别为前后距、侧距、高度差。若配方按离地机高给值，取当地地面作 `P` 的高度基准。人物朝向可与路线方向不同，转弯用连续切向，停步延续最近有效方向。用同一全局帧记录 `C、Q、FOV、roll` 与动作/揭示。普通直线可从起、中、末及事件点开始，曲线按弧长和实际构图补点。各配方的数值皆为灰盒起算值，按画面、净空和用户给定数据修正。

## 基础运镜：编排与实际差异

既有public 1.3.0核验通道：`camera.keyframe`的`position.x/y/z`、`target.x/y/z`、`lens.fov`、`lens.roll`；插值`linear/smooth/hold`及`tangents/spatialTangents`有入口。执行时仍读当前help/schema/commandFields，不从名称猜嵌套结构、单位、端点行为或效果保证。

| 方法 | 现有通道可编排的变化 | 实际验收/反例 |
| --- | --- | --- |
| 固定 | position/target/FOV/roll保持 | 画内可动，但相机无意外漂移；固定机位不等于固定朝向的跟随 |
| 推进/后拉 | 真实靠近/远离，target/FOV按目的协调 | 距离与视差改变；仅缩放FOV不是推进 |
| 水平摇/俯仰 | 机位固定，target控制朝向 | 转头不是横移；俯仰不是升降；target不是焦点距离 |
| 横移 | 侧向位移，目标保留或有意切换 | 前后景视差真实变化，不只是摇镜 |
| 升降 | 世界高度变化，target选择注视区 | 只看上方不等于爬升；落幅环境提前准备 |
| 跟随 | 相机和主体保持/有意改变相对位置 | 占比、屏幕方向、转弯与节拍；不自动把所有任务改成等高等距跟拍 |
| 弧线/环绕 | 围绕关注对象真实弧线位移 | 方位与背景流转；一圈回原方位，不自动看见正脸 |
| 甩镜 | 快速朝向变化并落定 | 两端可读，角度跨界与停留核对；模糊效果另验 |
| 纯变焦 | 固定机位改变FOV | 取景变化，无新移动透视 |
| Dolly zoom（推拉变焦） | position与FOV反向协同，几何可近似 | 主体尺度近似稳定、背景关系变化；不是拉焦，效果须看片 |
| 摇臂/复合调度 | 位移、高度、朝向和景别联合 | 观看阶段与过渡成立，不以技巧数量验收 |
| 光轴滚转 | 保持视线或沿既定路线改变roll | 地平线或框线按设计旋转，注意画幅边缘裁切 |
| 手持感 | 跟随/观察轨迹中有意小幅扰动 | 属轨道近似，非真实设备模拟；不靠随机抖动制造自然 |
| 无人机/FPV | 连续空间飞行与转向 | 路线/朝向/净空/地标时序成立；速度感须实际画面 |

## 运镜幅度分档

| 档 | 位移 | 用途 |
| --- | --- | --- |
| 小 | 0.2–0.5 m | 微调、呼吸感 |
| 中 | 0.5–1.5 m | 常规推进、跟随 |
| 大 | 1.5–4 m | 揭示、冲击、空间转换 |

**全片至少一次大位移。** 全是 0.3–0.5 米的缓推，画面会像幻灯片。分档写进镜头表的“运动”列，例如「推 0.4（小）」「后拉 3（大）」。

## 运镜矩阵：观看关系 × 起幅/落幅

按“观众是谁”入手，再按“起幅 → 落幅”挑手法。记法：`全=远景 中=中景 近=近景 特=特写`；`平/仰/俯/斜` 是视轴。

### 一、旁观（站在场外看）

观众不进戏，只负责看清空间与关系。

| 手法 | 起幅 → 落幅 | 用途 |
| --- | --- | --- |
| 固定全景 | 全 → 全（平） | 交代空间、阵位 |
| 固定中景 | 中 → 中（平） | 对话、日常 |
| 长焦压缩 | 全 → 全（平，压缩纵深） | 把远近压到一起，制造拥挤 |
| 横移（truck） | 全 → 全（视角平移） | 展开空间、带出前景 |
| 摇镜（pan） | 中 → 中（平，视线转） | 跟随注意力转移 |
| 俯仰摇（tilt） | 全 → 中 或 中 → 全 | 揭示高度、上下关系 |
| 缓推（dolly in） | 全 → 中 | 从环境收到人物 |
| 后拉（dolly out） | 中 → 全 | 人物被环境吞掉 |
| 变焦推（zoom in） | 全 → 中（透视不变） | 强调，不做位移 |
| 变焦拉（zoom out） | 中 → 全 | 抽离 |
| 甩镜（whip pan） | 中 → 中（运动模糊） | 转场、暴力转视 |
| 横移视差 | 中 → 中（前景掠过） | 揭示被遮的东西 |
| 遮挡后拉揭示 | 局部 → 全 | 先藏后露 |
| 升格 / 降格 | 全 → 全（时间变） | 强调或省略 |

### 二、跟随（跟在人物身后或身侧）

观众跟着走，身体感强。

| 手法 | 起幅 → 落幅 | 用途 |
| --- | --- | --- |
| 前导跟 | 中 → 中（主体后退） | 看表情，也看前方 |
| 并行侧跟 | 中 → 中（横向） | 走路、奔跑的稳定节奏 |
| 背后跟 | 中 → 中（背影） | 未知、进入 |
| 手持跟随 | 中 → 中（摇晃） | 混乱、纪实 |
| 贴背越肩 | 中 → 近 | 压迫、私密 |
| 跟拍交接 | 中 → 中（A 交到 B） | 换主体不换空间 |
| 跟拍转环绕 | 中 → 中（绕） | 从跟随变围观 |
| 一镜到底（oner） | 全 → 近 或 中 → 全 | 沉浸、不打断 |
| FPV 穿越 | 全 → 近（穿门/拐角） | 速度、纵深感 |
| 车载跟拍 | 中 → 中 | 速度、平行竞速 |

### 三、当事人（用人物眼睛看）

观众就是那个人。

| 手法 | 起幅 → 落幅 | 用途 |
| --- | --- | --- |
| 纯 POV | 近 → 近（眼位） | 代入 |
| POV 转身 | 近 → 近（视线转） | 发现 |
| POV 推进 | 近 → 特 | 逼近、恐惧 |
| 过肩双人（OTS） | 中 → 中（前景肩占 1/4） | 对话的权力关系 |
| 过肩推进 | 中 → 近 | 逼问、压迫 |
| 反打（reverse） | 中 → 中（对切） | 对峙、争论 |
| 拉焦（rack focus） | 中 → 中（焦点转移） | 注意力切换 |
| 身体固定（snorricam） | 中 → 中（背景晃） | 失控、醉酒 |
| 越轴反转 | 中 → 中（方向反转） | 关系翻转 |

### 四、审判（从高处看）

观众俯视，人物被审视。

| 手法 | 起幅 → 落幅 | 用途 |
| --- | --- | --- |
| 俯视固定 | 全 → 全 | 无助、被安排 |
| 顶视（top shot） | 全 → 全 | 阵型、仪式感 |
| 高位环绕 | 全 → 全（转） | 被围观 |
| 升起（crane up） | 中 → 全 | 抽离、结束 |
| 下降（crane down） | 全 → 中 | 介入 |
| 高位跟拍 | 全 → 全（横移） | 大规模调度 |
| 航拍 / 无人机 | 全 → 全（大范围） | 地理交代 |
| 俯视变焦 | 全 → 中（透视不变） | 从格局收到个人 |

### 五、共谋（贴近、低于人物）

观众贴得很近，甚至低于人物。

| 手法 | 起幅 → 落幅 | 用途 |
| --- | --- | --- |
| 低仰视固定 | 中 → 中（仰） | 威压、崇高 |
| 贴地跟 | 近 → 近（地面） | 速度、脚步 |
| 低机位推进 | 中 → 近（仰） | 威胁逼近 |
| 荷兰角固定 | 中 → 中（斜） | 失衡、不安 |
| 荷兰角推进 | 中 → 近（斜） | 崩溃迫近 |
| 光轴滚转（roll） | 中 → 中（旋转） | 天旋地转 |
| 从物件起幅 | 特 → 中 | 剑尖/枪口/脚先入画，再揭人 |
| 极低环绕 | 中 → 中（仰 + 绕） | 被围、被审视 |
| 英雄环绕 | 中 → 全（仰 → 平，低位爬升） | 加冕、胜利 |
| 子弹时间 | 中 → 中（冻结 + 环绕） | 时间停住 |
| 速度坡道 | 中 → 中（常速→时停→爆发） | 冲击 |
| 甩镜进出 | 中 → 中（模糊） | 突发、失控 |
| 斯皮尔伯格登场 | 局部 → 全（碎片→动作→全貌） | 人物第一次出现 |

### 起幅、运动、落幅与人物配合

三种基本配合：

| 配合 | 镜头 | 人物 | 用途 |
| --- | --- | --- | --- |
| 镜带人 | 动 | 不动或微动 | 揭示空间、扫过群像 |
| 人带镜 | 跟 | 走 | 跟随、追逐 |
| 人镜对向 | 后退/前进 | 朝镜头走或背向走 | 压迫、抽离 |

每种关系的默认配合：

| 关系 | 起幅人物位置 | 运动中 | 落幅人物位置 |
| --- | --- | --- | --- |
| 旁观 | 已在画中，或从画外走入 | 自己走，镜头不动或横移 | 停在构图位，不贴边 |
| 跟随 | 背对或侧对镜头 | 领走、并行 | 停下或回头，落幅给正脸或背影 |
| 当事人 | 前景肩/后脑在画 | 转身、前倾 | 视线落点在画内，不空 |
| 审判 | 散在空间各处 | 聚拢或散开 | 被围住，或孤立成一点 |
| 共谋 | 贴近镜头、低于镜头 | 逼近、后退 | 压迫或放松，占画面变大或变小 |

**写作要求**：每镜在表里写清三件事——起幅人物在哪、运动中人物怎么动、落幅人物停在哪。三句写不出，说明这镜只是把相机放过去，没有调度。

### 排列成序列：三件事同时成立

1. **关系要换**：连续三镜同一关系 = 视角单一。
2. **起幅接上一镜落幅要有差**：景别跳档、视轴变化、占比差 ≥15%。
3. **落幅要给下一镜留接口**：本镜收在近景，下一镜起幅就别再从近景开始。

### 示例：竹林对峙（30 秒）

| 段 | 关系 | 手法 | 起幅 → 落幅 |
| --- | --- | --- | --- |
| 对峙 | 旁观 | 长焦压缩 | 全 → 全（压缩） |
| 对峙转拔剑 | 当事人 | 过肩双人 | 中 → 中（肩占 1/4） |
| 拔剑 | 共谋 | 从物件起幅 + 低仰视 | 特 → 中（仰） |
| 逼近 | 跟随 | 并行侧跟 | 中 → 中（横） |
| 混战 | 共谋 | 极低环绕 | 中 → 中（仰+绕） |
| 断竹 | 旁观 | 遮挡后拉揭示 | 局部 → 全 |
| 蓄力 | 共谋 | 荷兰角推进 | 中 → 近（斜） |
| 绝技 | 共谋 | 子弹时间 | 中 → 中（冻结） |
| 收束 | 审判→共谋 | 升起 + 英雄环绕 | 中 → 全（仰→平） |
| 落定 | 旁观 | 固定全景 | 全 → 全 |

**同一套结构换成审讯室、球场、会议室，关系序列不变，只换手法。**

### 边界

- 表里的“起幅/落幅”是设计意图，不是渲染保证；写完要抽首末帧核对。
- 导演台不支持的（真实变焦镜头、机械臂、无人机自由轨迹）用等效：FOV 近似变焦、升降近似摇臂、路径近似航拍。
- 一个镜头只承担一种关系；要换关系就切一刀。

## 常用组合：交接不是固定配方

任选需要的段，可以减速、静止、留看或反向；不要求串完表格。以下是几何/观看设计推论，不是全部组合已实测自然的承诺。

| 组合候选 | 交接方式（position、target、FOV、节奏一起决定） | 落点与失效风险 |
| --- | --- | --- |
| 跟随→侧移 | 前进分量延续，路径渐向侧面弯；视轴留主体或渐交同行者 | 从同行转看关系/侧面层次；突然横跳或丢主角 |
| 侧移→爬升 | 横向揭开遮挡后逐步加入高度，不用target向上代替位移 | 展开布局/尺度；升高后只见空地或目标太小 |
| 爬升→环绕 | 垂直分量渐收、弧线分量渐起，视轴持续协调 | 获得另一侧视点/背景重排；方向突然折断、原地转头 |
| 环绕→推进 | 缩半径或平顺离开弧线，先定最后看的人/物/空间细节 | 注意力收束；只收脸、主体瞬间放大或切向尖折 |
| 推进→跟随 | 主体离开时由靠近改为同向伴随，可先观察后追随 | 行动延续/身体参与；人物与相机启停不匹配 |
| 运动→留看→再运动 | 到达可读构图后停留，再按行动或体验转向 | 等待/反应/对比；每节点无意刹停或毫无辨识时间 |

自然衔接不等于机械匀速，也不等于每通道都smooth。转段前后核对路径切向、速度/加速度观感、视轴转向、主体屏幕坐标/尺度变化率与停留。详见[timing-and-diagnostics](timing-and-diagnostics.md#相机多通道联合节奏)。

## 低机位出场

人物第一次出现时，用低机位把他“抬”起来：

- 机高 0.3–0.5 m，仰角 5°–10°，人物从画面一侧进入或从暗处走出。
- 起幅留空（天空、门框、墙线），人物进入画面后缓推 0.3–0.8 m。
- 剪影优先：让主体压暗、背景亮，轮廓比细节重要。
- 落幅不要给正脸，给肩线或背影，把正脸留到下一镜。
- 反例：低机位 + 广角贴脸（变形）；起幅就把人放正中（没有“进入”的过程）。

## 常用跟拍与揭示

### 前导跟拍

- **主体**选脸部或上半身能表达行动意图的人。沿角色实际前进方向取机位锚点，脸部或与同行者的关系取注视点。
- **轨迹与参数**用 `a=2–3.5 m`、侧偏 `|b|=0.3–0.8 m`、机高约 `1.3–1.6 m`、FOV `38°–55°` 起算。相机在前方同向退行取景，沿路线采样重算位置。先给转弯留净空，再用前后控制点平顺改方向。
- **触发与验收**以角色起步或望向目的地带动镜头。转角后可留看反应或转交目的地。核对脸/动作的可读性、相对领距、背景流动和退行段障碍。

### 并行侧跟

- **主体**选需要看轮廓、步态或并排行动关系的人物/物体。双人以实际两人的中点作取景起点，按前后层次偏置注视点以留出两张脸或关键动作。
- **轨迹与参数**从 `a≈0 m`、侧距 `2.5–4 m`、机高 `1.2–1.6 m`、FOV `40°–55°` 起算，相机沿主体同向路线移动。双人速度差明显时，先定需要保留两人的时间窗，再按投影边界微调机距与侧前角。
- **触发与验收**并肩、超前或错位时调整构图，留出行动方向。以腿部动作、两人间距、前后景视差及相邻帧的屏幕相对速度核对效果。

### 定点跟摇

- **主体**选横穿可见空间或需要被固定视点观察的主体，注视其脸、车头或轨迹前方能留出行进空间的点。
- **轨迹与参数**固定 `position`，保持 `FOV 40°–55°` 起算。按主体经过的起、中、末世界点生成 `target`，典型横穿可从 `45°–90°` 总摇角、`2–4 s` 起算，实际角度由两端视线计算。停步后短暂留看，检查同向转动和近处目标距离。
- **触发与验收**人物进入构图边缘或动作开始时起摇，停步、离画或抵达下一个对象时落定。核对提前留白、主体未无意居中锁死及最后朝向。

### 后拉揭示

- **主体**选起幅清楚的反应/细节A，以及只有在更宽关系中才有意义的人物B、物件或场所。落幅提前布好二者的距离和空间参照。
- **轨迹与参数**沿初始视线后退 `1.5–3 m`，运动 `2–3 s`，FOV `40°–50°` 起算并尽量保持稳定。以落幅的投影范围定终点，如B被A遮住则加入能解除遮挡的侧向偏移。需要时把 `target` 从A平顺改到关系中心。
- **触发与验收**从反应读清或动作完成时开始后拉。记录B首次可读和A、B同框可辨的时刻。检查落幅是否确实解释环境关系，以及相机后退净空。

### 快速变焦

- **主体**选突然被注意到、细节能解释上一节拍的对象。放宽画幅时选揭晓后需要一起入画的关系对象。
- **轨迹与参数**机位固定，选定注视点后写 `lens.fov`。可先试 `50°→30°` 或反向，过渡 `0.25–0.4 s`，落幅留 `0.4–0.8 s` 看片调整。移动主体先核对缩窄后边界仍容纳关键部位。
- **触发与验收**与视线落定、道具变化或一个清楚的动作节拍对齐。看触发前后的取景尺寸、关键边界及落幅读图时间。

### 跟拍交接

- **主体**先选带动首段的A、接住动作/线索的B，再定交会点。两者可以是人、正在递交的物件或引导下一段的空间目标。
- **轨迹与参数**先布两端跟拍机位，交会处保留可见的共同构图。可从 `0.4–1.0 s` 视线转移、交会前后各约 `0.3–0.6 s` 双方可辨、FOV `45°–55°` 起算。相机路径接续原切向，`target` 由A经交会点转B。两端视线跨度大时增加中间方向键，避免视轴穿过相机。
- **触发与验收**用交会、对视、交接完成或A让出画幅作为触发。若A的行动引起B反应，给A的线索和B改变前后的状态可读空间。可同框呈现，也可在切点前给线索、切后接到响应。沿[信息揭示顺序](story-and-camera.md#信息揭示顺序)回看视线、屏幕方向与物件归属，确认B接管后留得住。

## 特殊运镜

### 横移视差揭示

- **主体**选能形成清楚轮廓的前景遮挡体和揭晓对象B。先确定B必须露出的部位，然后从落幅反求遮挡边缘两侧的机位。
- **轨迹与参数**示例中 `C=(0,1.4,6)→(2.25,1.4,6)`，匀速 `2.5 s`，FOV `40°`。B位于 `z=0`，关键横向范围 `x∈[-0.25,0.25]`。遮挡面在 `z=2`，横向范围 `[-0.45,0.45]` 且覆盖视线高度。视线与遮挡面交点为 `x=Cx/3+2Bx/3`，中心于 `Cx=1.35 m` 通过边缘，关键范围约在 `0.85 m` 首露、`1.85 m` 完整露出。真实场景以遮挡面和主体关键轮廓重算。
- **触发与验收**起幅让前景线索可读，接近首露时将 `target` 交给B。按首露、关键部位完全出遮挡和落幅三个事件安排速度。转角检查实际相机包络和视锥。 [Blender 路径与追踪约束](https://docs.blender.org/manual/en/5.0/animation/constraints/relationship/follow_path.html)

### 低位跟拍转越肩

- **主体**选具备可靠整体路径的角色。脚步、轮子或地面纹理作为前段视觉线索，肩背和前方地标组成落幅。
- **轨迹与参数**按共同跟随公式，`a=−1.8→−1.3 m`，同侧 `|b|=0.7→0.6 m`，机高 `0.35→1.55 m`，FOV约 `45°`。4秒起算，前约1秒维持低位，中段爬升，后约1秒稳定越肩。视线从脚部/地面逐渐抬到通道地标，越肩高度按人物实际身高调整。
- **触发与验收**在迈过门槛、抬头或看向目的地时爬升。检查转弯切向、肩部是否挡住地标、地板及门楣净空。 [《1917》摄影采访](https://www.arri.com/news-en/roger-deakins-cbe-asc-bsc-on-his-journey-to-arri-large-format/arri-trinity-on-1917--177696)

### 车载机位转向驾驶员

- **主体**车辆提供世界轨迹和转向，路面是首段视觉对象，驾驶员脸或头盔是落幅对象。先定从同一车载偏移能看清两端的安装点。
- **轨迹与参数**在车内实测横向/前后/高度偏移 `o`，由车辆位姿生成 `C=P车+R车·o`。固定相对机位时保留 `o`，转向用 `0.6–1.2 s`、FOV `50°–65°` 起算。按起落两条视线及中间方位生成 `Q=C+L·视线单位向量`，`L>0`。落幅注视跟着驾驶员实际位置更新。
- **触发与验收**用驾驶员发现路况、操纵动作或视线变化触发。核对转弯时相机跟位、方向变化、玻璃/座椅/车顶净空及两端可读性。 [《F1》车载摄影采访](https://theasc.com/article/f1-the-movie-cinematography/)

### 荷兰角（倾斜构图）

把相机绕视轴滚 5°–20°，让地平线不再水平。作用是制造失衡、不安、失控，不是“酷”。超过 30° 会变成风格化海报，叙事里读不出空间。

用法：

- 只在**关系失衡或认知动摇**时用；同一场戏里用一次，不要连续用。
- 倾斜方向有意义：向左倾（人物朝画右）通常更不安；同一场戏里方向别来回换。
- 倾斜后要重新核构图：原本水平的地面线会切过人物，容易切边。
- 落幅可以回正（回正 = 恢复秩序），也可以停在倾斜上（失衡未解决）。

导演台里用相机的 `lens.roll` 通道，别用相机位置旋转代替。

### 斯皮尔伯格登场

用“局部碎片 + 动作”介绍人物，而不是直接给全身正面：先看到手、背影、鞋、手里的东西，再在一个动作里揭示全貌。

- 第一刀给**碎片**（手/工具/背影/影子），观众先记住一个特征；
- 第二刀给**动作**（他做了什么），身份通过行为确认；
- 第三刀才给**全貌或反应**，此时观众已经有预期。
- 常配长镜头跟随入场，让揭示发生在运动里，不是站着摆姿势。

判断标准：把人物的脸遮住，观众还能不能说出“他是谁、靠什么吃饭”。说不出，说明碎片没选对。

### 光轴滚转

- **主体**选画面中稳定可认的脸、物件或地标，边缘留地平线、门框或建筑竖线体现角度变化。
- **轨迹与参数**固定或延续已有 `position/target`，FOV从 `45°` 试起。用 `roll=0°→15°` 约 `0.6 s`，留看 `0.4 s`，约 `0.8 s` 回正。连续翻转按需要设置更大角度并补中间键，先核对角度符号、范围和跨界行为。
- **触发与验收**在失衡、视点转换或空间翻转的动作相位起滚，回正后看清新方位。检查头脚裁切与边角，组合运动时同查轨迹净空。 [ARRI TRINITY 2 手册](https://www.arri.com/resource/blob/294190/8d5d22f8d8978fbf3f03ccf698585962/trinity2-usermanual-download-data.pdf)

### 凝固时刻环绕

- **主体**选从侧面仍能读出轮廓和关系的动作相位，关键部位或双方交会点的水平投影作圆心，主体与静止配景同时提供空间信息。
- **轨迹与参数**沿[环绕与爬升](#环绕与爬升)的弧线设 `r≈3.5 m`、机高约 `1.6 m`、弧角 `110°`、`2.5 s`、FOV `42°` 起算。注视点落在选定姿态的关键部位或关系中心。先确定主体时钟的保持/慢速段，再分配相机弧长与时间。
- **触发与验收**在动作剪影最清楚时开始环绕，落幅交代之前被挡住的关系。验证人物/物件的相位保持与相机连续运动同时成立。当前入口只能保留静态相位时，以静态相位预演；动态时间控制需实证。 [《黑客帝国》摄影案例](https://theasc.com/article/flashback-the-matrix-cinematography/)

## 导演案例的镜头配方

导演名用于定位参考。以各条的可见目标选择配方，按场景和预设重定参数。

### 跟随进场

- **主体**选带路人作移动锚点、同行者作观众进入空间的参照。入口、门厅、路过者和最终主厅负责依次补充人物地位或空间关系。
- **轨迹与参数**镜头可从后距 `1.5–2.5 m`、侧偏 `0.4–0.8 m`、机高 `1.4–1.7 m`、FOV `45°–55°` 起算。以真实通道的门槛、转角、会面点和终点定相机路径。8秒示意按入口约2秒、过渡约3秒、进入主空间约3秒分配，依交互与路长调整。连续穿越多个空间时制作前补米制正投影调度图。
- **触发与验收**在开门、招呼、让路等实际可读动作处放缓/转视轴，下一段由明确行动接走。末段同时保留主角与欢迎/让路的空间关系。案例为斯科塞斯《好家伙》的夜总会进场。 [摄影机操作员麦康基访谈](https://filmmakermagazine.com/93916-steadicam-operator-larry-mcconkey-on-filming-the-goodfellas-copacabana-tracking-shot-and-the-early-days-of-steadicam/)

### 双轨滑行

- **主体**选体态稳定且能承担情绪的角色。站姿/片段相位与前移轨道配合，配景提供能掠过的近远层次。
- **轨迹与参数**人物与相机同向同步平移，机位用固定相对偏移跟前脸或胸口。灰盒可用 `4 s`、行程 `3.2 m`、领距 `2.5 m`、FOV `40°`；启停共用一条距离进度。保持角色局部姿态的意图按当前预设支持实现。
- **触发与验收**在角色决定、察觉或恍惚时进入滑行，落幅由环境变化或角色的新反应收住。检查主体尺度和位置稳定、背景持续移动、漂移观感符合意图。案例见斯派克·李《马尔科姆·X》。 [斯派克·李访谈](https://www.dga.org/craft/dgaq/issues/0801-spring-2008/dga-interview-spike-lee)

### 横移甩摇与急停

- **主体**选两至三个有明确接力关系的人或物，在各自独立落幅中可读。先给每个落幅定正面/侧面角度及空间参照。
- **轨迹与参数**以A、B、C的落幅机位定轨道停点。灰盒相邻机位可差 `1–1.5 m`，转向 `45°–90°`、`0.3–0.6 s`，落定 `0.4–0.8 s`，FOV约 `42°`，由实际人物位置修正。分别给位置减速点、朝向到点与停留时间；中间方向键明确甩摇方向。
- **触发与验收**用说完、转身或道具交接触发下一段。查看急停后中心、地平线和新主体的清晰构图，检查每段动作落点是否按顺序读到。案例为韦斯·安德森《法兰西特派》。 [罗伯特·约曼等主创访谈](https://theasc.com/article/the-french-dispatch/)

### 低位走廊跟拍

- **主体**选小车、脚步或贴地移动对象。走廊门框、地面材质和转角提供速度、深度和下一处线索。
- **轨迹与参数**参照[贴背跟随与前景遮挡](#贴背跟随与前景遮挡)，机高 `0.25–0.45 m`、前导或跟随间距 `1.6–2.6 m`、FOV `50°–65°` 起算。用走廊轴线与真实转角定相机路线，独立校验车/人和相机的转弯净空。机高和镜头俯仰分别设置。
- **触发与验收**主体转向时才让下段走廊进入画面。核对近地参照、转角的首露和落幅地标，材质或声响变化可辅助节奏。案例为库布里克《闪灵》中的儿童骑车镜头。 [操作员加勒特·布朗回顾](https://theasc.com/article/steadicam-shining-revisited/)

## 指定方案按条件读取

### 越肩正反打

建立双人连线、说话/倾听时段与同侧机位。前景肩头只占必要边角，目标脸/手势可读；预设变化可能遮脸，联合修高度、横向/后向偏移、target与FOV。切点接动作/视线，不按每句话自动切。用户时长/切点原样保留。

以听者肩外侧作起算机位，肩后距 `0.4–0.8 m`、侧偏 `0.25–0.5 m`、机高接近坐姿/站姿眼高，FOV `38°–50°`。两台机位分别瞄说话者的眼位或上半身。切点优先给发言、反应或关系变化，在同一全局时钟校对。肩部进入说话者脸部投影时，先微调机位和视轴。

### FPV一镜到底

制作前由同源数据补米制正投影调度图，含连续路线、观察方向、视高与地标时序。相机与主体各自核对狭口、转弯和上下净空；近景掠过、速度与落幅看片。不要把参考绕行简化成直线。

每个门洞/转角标注入口、通过中心与出口，再用前后控制点连接。相机取 `C(s)`，目标沿路径预看 `C(s+ℓ)` 或在揭示点转向地标。室内灰盒可从 `0.8–1.8 m/s`、预看 `1–2 m`、FOV `55°–75°`、roll `0°` 试起。按空间、参考与节拍调速，窄口核对可通过的真实体积。地标首次可读和视轴切换写在同一路线上。

### Dolly zoom／希区柯克变焦

先明确推进配放宽FOV，或后退配缩窄FOV。简化透视且主体深度近似固定时，以`d × tan(FOV/2)`近似恒定作初算，target保持眼位/选定屏幕锚点，再用同画幅预览校正。检查FOV范围/钳制、起中末主体边界和背景地标、连续过程稳定性。不把等效毫米值当已校准镜头，不附带承诺景深；它与清晰平面转移的拉焦是不同效果。

优先选能保持轮廓的脸/上半身或静态物体，背景要有不同纵深地标。以主体意识变化或空间感变化起动。后退示例用 `3 s` 沿视轴从轴向深度 `3 m` 到 `6 m`，同一轴FOV从 `50°` 到约 `26.25°`。中点 `4.5 m` 对应约 `34.54°`，用实际 `d(t)` 计算各关键帧。回看主角高度与眼位，以及背景地标相对大小和间距变化。 [Adobe 推拉变焦说明](https://www.adobe.com/creativecloud/video/production/cinematography/camera-shots-and-angles/dolly-zoom-shot.html)

### 前推越人再回转（反向包抄）

用户明确指定时，按其定义先从肩后外侧沿面对方向直线前推，真正越过人物使肩部出画，再在前方快速水平回转落正脸；不是反向绕圆弧。位置越人、target多点回转、FOV与落幅停留联合核对。近柱/越人净空与角度跨界单查，不用硬切代替。

锚点选面向通道的人，起幅看肩与通道，落幅看脸及身后的背景。先试后距 `1.2–1.8 m`、肩外侧偏 `0.6–1.0 m`、肩高机位、FOV `45°–55°`。沿人物朝向在 `1.5–2.5 s` 推到人物前方约 `1.5–2 m`。实际越人且肩部离画后，用 `0.35–0.7 s` 经中间方向键水平回转，最后约 `0.5–1 s` 留看脸。回转段可保持位置或按净空小幅对中，检查镜头朝向与主体正脸能同时成立。

### 环绕与爬升

用户需要此技法时实际改变方位与高度，可同时改变半径、景别和预设/整体状态。是否绕满一圈取决于要求；绕满回原方位，要正脸落幅需另安排人物朝向或终点。英雄感/压迫感是可选解释，不固定为环绕默认；不必全加逆光、尘土、慢镜或光晕。

以主体或关系中心的水平投影为 `A(t)`，在米制 +Y 向上场景用 `C=A+(r cosθ,h,r sinθ)`。视轴按脸、胸或关系中心取 `target`，独立于轨道圆心。随主体移动实时取 `A(t)`，定好起落方位、角度和高度再分配时间。等半径等高环绕按等弧长/角速度起算，变半径、升高或主体移动时重新计算实际机位速度。

- **等距环绕揭示**选空间层次丰富且轮廓可从多面读到的主体。可从 `r=3–4 m`、机高 `1.4–1.7 m`、FOV `40°–50°` 起算，要求完整一圈时以 `6–8 s` 编排。以到达关键方位为揭示事件，检验背景流转与稳定占比。
- **低位爬升英雄环绕**选轮廓可读且有抬头、迈步或转向等可用预设的角色。侧后起，`r=3.2→2.8 m`、机高 `0.35→1.9 m`、FOV `50°→42°`、`5–7 s` 起算。先按用户意图定角度，若需要正脸终幅，按角色实际终朝向求最终方位并对齐动作。核对极低起幅、真实爬升、人物塑造的可见变化。贝式英雄环绕是这一配方的风格案例。

### 贴背跟随与前景遮挡

肩背与前方通道先可辨，前景随真实位移掠过；揭示点或体验落点明确。遮挡有节拍，不让一根柱长挡全画面；主体与相机分别核对转弯/净空。并非全程遮黑才有压力。

以人物前进路线取后方机位，后距 `1.4–2.4 m`、侧偏 `0.3–0.8 m`、机高 `1.35–1.65 m`、FOV `45°–60°`。先布能读方向的肩背和地标，再选遮挡物。对齐角色经过遮挡边缘的事件，在落幅看到前路或下一个对象。

### 低位推进、升降揭示与顶视下降

低位指相机真实低高度，仰角单独设计；近地纹理/前景是否入镜按目的选，不强制脚部开头。升降揭示用真实高度/距离变化展开或收束环境，不以放宽FOV代替。顶视应正上方垂直俯视，斜高位不命名为正顶视；下降过程检查建筑和主体全边界，滚转可选而非必加。

- **低位推进**以脚步、地面参照或向上揭晓的主体为锚点，机高 `0.3–0.5 m`、前进 `1.5–2.5 m`、FOV `50°–65°`、`2–3 s` 起算。起幅看近地参照，在脚步或跨过地标时逐步抬 `target`，落幅保留应见到的身体范围。
- **升降揭示**以近处人物作尺度，预先选需出现的远处场所/群体。可从机高 `1.5→3.5 m`、同时后退 `1–2 m`、FOV `45°–55°`、`3–4 s` 起算。用穿过遮挡上缘、远处首次可读和关系完整出现三个机位控时。
- **顶视下降**以队形或交会点水平投影作锚点，沿同一世界垂线从 `8→4 m`、FOV `45°–55°`、`2–3 s` 起算。事件以队形开始变化或路线交会为准。检查最小高度仍容纳各主体全边界，核对画面上方向及俯视稳定性。

### 固定机位滚动

相机位置、朝向与视角保持；匀速按用户时间线性平移。理想无滑动转角约为路程/半径，核对枢轴、接地、纹理与标记。底部中心锚点直接旋转可能陷地；特殊枢轴在当前能力与检测覆盖内核验。表面标记模拟只称视觉预演，不冒称真实刚体滚动。不固定案例时长。

### 甩镜与注意力转移

从可读A快速转向B，再让B稳定可辨；理由可为动作/视线、信息或有意观看对比。角度跨界多点核对；运动模糊和真实焦点转换有独立入口才实现。不把FOV、target动画当拉焦。

两端先定能解释事件的主体A/B与稳定构图。定点甩镜可从 `45°–90°` 转角、`0.2–0.4 s` 转向、`0.4–0.8 s` 落幅、FOV `42°–55°` 起算。沿预定方向用中间视轴生成 `target`，动作/视线触发时起摇。若与剪辑结合，两镜的中段转向和屏幕运动方向连续，切前后的可读落幅仍各自验收。

### 拉焦交接

- **主体**选画内距离明显分离、都能辨认的两个对象。近处的线索A、远处角色B或反向皆可，保持两个落点在画幅内。
- **轨迹与参数**可先用固定机位、FOV `40°–50°`，以距相机约 `1.2 m` 与 `4 m` 的目标做光学设计。起幅留 `0.5–1 s`，转焦 `0.4–0.8 s`，落幅留时间读清B。相机移动时按已确认的引擎对焦定义重算两端对焦距离，当前CLI入口状态见上表。
- **触发与验收**以道具变化、视线或人物动作触发焦点交接，查看A/B实际清晰度变化。能力待核验时可先用已支持的构图/遮挡预演信息转移，将光学拉焦列待验证。 [Epic Cine Camera 的独立对焦与取景控制](https://dev.epicgames.com/documentation/unreal-engine/cinematic-cameras-in-unreal-engine?lang=en-US)

## 完成标准与来源

起中末预览核对真实位移、朝向、FOV、主体运动各自差异；再看连续节奏与落幅。相机名称/关键帧数量/参数保存不证明技法完成。用户指定固定镜头时不为用新知识强行移动。

- [Camera Trajectory Generation: A Comprehensive Survey（2025，v1）](https://arxiv.org/html/2506.00974v1)：研究综述，公开全文于2026-11-11获取；构图、轨迹、朝向与速度等联合优化提供方法依据，不证明本CLI实现或smooth的数学保证。
- [BFI《十二怒汉》25帧分析](https://www.bfi.org.uk/features/how-12-angry-men-works-25-frames)：单镜注意力接力与后拉关系变化的具体文本依据，非固定风格模板。
- [Oklahoma State Editing](https://open.library.okstate.edu/introfilmtv/part/editing/)：连续/省略/非连续表达是选择工具。
- [Oklahoma State Cinematography](https://open.library.okstate.edu/introfilmtv/part/cinematography/)：公开正文于2026-11-11读取，明确运镜可与动作协调或独立，reframing可替代剪辑连接构图；Focus and Lenses区分景深/浅焦与rack focus清晰平面转移。这些是电影方法定义，不是CLI景深支持证明；真实焦距的经验描述不替代虚拟机位/FOV标定。

public 1.3.0既有通道及本次实证按上述具体条件使用；未测组合、光学入口及任意轨迹效果仍分别取证。不包含未读取候选Skill的推荐。
