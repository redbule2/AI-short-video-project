# 碰撞、装配与性能（人工核对版）

本版不含脚本。碰撞与净空靠**抽帧目测 + 手算**，结论必须写清覆盖范围与依据。

## 接触意图

用户要求接触、装配、交接、击打时，先标清：**哪个部位、哪个阶段、预计何时分离、哪些穿透必须避免**。

- 只允许限定部位/时段的接触，不能用整对象、整时段白名单代替；
- 不全局禁止接触，也不删关键行为；
- 关系确定就直接做，不把精密接触验证当前置关卡。

## 核对流程（六步）

1. **列候选对**：人物×墙柱、人物×道具、人物×人物、相机×人物、相机×墙柱。
2. **换包络**：人物按 0.5 × 1.75 × 0.5 米（原点在脚底）代替真实外形；道具按外接盒。
3. **选帧**：每镜的起、中、落 + 运动最快的一段 + 切点前后各一帧。**只抽落幅等于没查。**
4. **判读**：看有没有穿插、悬空、穿地、相机贴进物体。相机贴脸只持续几帧，要专门在“离得最近”的位置抽。
5. **单列允许接触**：门与框、轨道与枕木、人物手持道具的接触，写进“允许接触”，不算碰撞。
6. **写覆盖声明**：查了多少物体、多少帧、哪些是允许接触、哪些没查到。

## 手算参考

没有脚本时，用这三个式子代替逐帧计算：

| 项 | 算法 | 判据 |
| --- | --- | --- |
| 相机净空 | 机位到角色轴心的水平距离 − 0.25 米 | 跟拍 ≥1.2、贴背 ≥0.8、特写 ≥0.4 |
| 主体占画面高 | `(角色高 ÷ 2) ÷ (深度 × tan(FOV ÷ 2))` | >0.9 预警；近景约 0.5–0.9 |
| 切边 | 角色左右边界与画面边界的重叠比例 | 可见 <15% 且持续 >0.5 秒即不合格 |

`深度` 是角色到相机的距离，`FOV` 用垂直视角（导演台默认给的就是垂直 FOV）。

## 方法边界

| 情况 | 能做 | 不能证明 |
| --- | --- | --- |
| 静态构件 | 看一次装配关系 | 不动也不能跳过检查 |
| 直线平移 | 抽起止两帧 + 中点 | 两帧之间是否穿过 |
| 旋转/变速 | 抽更多帧，标“未连续验证” | 连续安全 |
| 人物整体 | 用包络粗查 | 内部肢体、手脚接触、自然度 |
| 相机 | 每台激活区间分别查 | 切镜前后的连续性、近裁剪面 |

**抽帧多不等于连续证明**：没覆盖到的区间要写“未验证”，不能写成通过。

## 常见失败

| 表现 | 问题 |
| --- | --- |
| 只看落幅 | 运动中段的穿插全部漏掉 |
| 只看出画 | 贴脸、穿身都在画内 |
| 把容差当净距 | 容差是允许穿入的程度，不是安全距离 |
| 允许接触不单列 | 门框、轨道接缝会被误报成碰撞 |
| 合并模型后不复核 | 外包络看不到内部问题 |
| 检查失败改成通过 | 缺文件、缺包络、抽帧不够，都是“未验证” |

## 记录格式

```text
覆盖：12 个物体 × 5 镜 × 每镜 4 帧（起/中/落/最快）
允许接触：门-框、车厢-枕木
未验证：第 3 镜 180–220 帧的转身段只抽了 2 帧
结论：无穿插；相机最近 1.35 米（镜 2 第 96 帧手算）
```

结论要能被别人按同样的帧复现；写不出帧号与数值的结论不算通过。
