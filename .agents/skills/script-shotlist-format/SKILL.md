# 剧本与镜头表 · 固定格式

本目录所有项目的剧本和镜头表都按这份格式写。提示词另有格式（`.agents/skills` 里的 `sd25-pe`、`seedance-prompt-format`），这里只管剧本和镜头表。

根目录的 `项目管理.html` 是按这份格式做的编辑器：读写 DOCX，一段一段地改。用别的方式写，也照这里的格式写，编辑器才能读回来。

## 使用方式

1. 一段一个剧本、一个镜头表，两个都要有（项目 AGENTS.md 的规定）。
2. 照「二、剧本骨架」「四、镜头表骨架」写，把 〔 〕 里的内容换成本段的，括号本身删掉。
3. 写完按「七、交付前自检」过一遍。
4. 按旧样子写的剧本和镜头表，下次修改时改成本格式。旧镜头表里的细节不再保留在镜头表里，随原文件一起移进 `历史记录`。

---

## 一、总规则

1. **一段一个文件**：剧本 `定稿的剧本/第N段/第N段_剧本.docx`，镜头表 `定稿的剧本/第N段/第N段_镜头表.docx`。段号写成 `集-段`，如 `1-1`、`3-2`；不分集的项目直接写段号，如 `第3段`。
2. **不写时长和秒数**：剧本、镜头表里都不写时长、成片时间、总秒数这类规格。时长在生成视频时设。
3. **剧本写戏，镜头表只列镜头**：机位、运镜、声音这些拍法写进提示词的分镜；剧本最多在 △ 后面带一个景别提示。
4. **一行一件事**：一个段落只写一个标签、一个动作、一句台词或一个镜头。
5. **只留一个当前版本**：改版前先把原文件移进 `历史记录`，再放新版本（项目 AGENTS.md 的规定）。编辑器保存时自动做这一步。

## 二、剧本骨架

```text
第〔N〕段｜〔段名〕
场景：〔时间〕｜〔内/外〕｜〔地点〕
人物：〔角色〕（〔年龄、外形、服装，一两处看得见的特征〕）、〔角色〕（〔……〕）
梗概：〔本段从头到尾发生了什么，一两句话讲完，写到结束时的状态〕

正文
△ 〔开场画面：在哪、谁在干什么〕
字幕：〔后期加的字幕，没有就不写〕
△ 〔景别提示〕：〔看得见的动作和画面〕
〔角色〕（〔表演提示〕）：〔台词〕
〔角色〕：〔台词〕
△ 〔动作〕。（音效：〔声音〕）
音效：〔单独的一声，没有就不写〕
……

备注
〔修改记录、待定事项；没有就不写这一节〕
```

## 三、剧本各部分怎么写

### 标题
- `第N段｜段名`。段名四到八个字，概括本段的事，如 `面馆打烊`。没想好可以只写 `第N段`。

### 段头
- 三行依次是：场景、人物、梗概。场景、人物必写；梗概可以先空着，定稿前补上。
- **场景**：`时间｜内/外｜地点`，三项用 `｜` 隔开。时间写画面里看得出来的：清晨、白天、傍晚、夜。地点从大到小，用 `·` 连接，如 `老街·面馆`。
- **人物**：本段出场的人全部列出，用 `、` 隔开；每个人后面的括号里写年龄、外形、服装，只写看得见的。群众写成 `路人若干`。
- **梗概**：让人一眼看懂本段，不写台词。
- 不写时长。

### 正文
正文只有四种行：

| 行 | 写法 | 例子 |
|---|---|---|
| 动作 | `△ ` 开头 | `△ 店员把面放到女主面前。` |
| 台词 | `角色：台词`、`角色（表演提示）：台词` | `店员（随口）：趁热吃。` |
| 字幕 | `字幕：` 开头 | `字幕：1996 年` |
| 音效 | `音效：` 开头，或写在动作行末尾的括号里 | `△ 筷子落在碗沿上。（音效：嗒）` |

- **动作**写画面里看得见、听得见的：谁、做什么、怎么做。不写心理活动，心里话写成台词行 `角色（内心）：……`。
- **景别提示**可以写在 △ 后面、冒号前面：`△ 特写：……`。机位、运镜不写进剧本。
- **台词行**的角色名和人物表里的名字一致。画外、旁白、内心都写在括号里：`摊贩（画外）：城管来了！`、`女主（内心）：……`。
- 一个 △ 只写一个画面或一组连着的动作；台词一人一行。
- 剧本里可以用括号、引号（招牌字、屏幕字写在 “ ” 里）；写提示词时再按提示词格式改写。

### 备注
- 只放修改记录和待定事项，如 `11-06 按批注改一句：……`。不写进正文。

## 四、镜头表骨架

```text
第〔N〕段｜镜头表｜〔段名〕
镜头1｜〔不超过十个字〕
镜头2｜〔不超过十个字〕
……
```

## 五、镜头表怎么写

- **标题** `第N段｜镜头表｜段名`，段名和剧本一致。
- 标题下面**一个镜头一行**：`镜头N｜概述`，镜头从 1 连续编号。
- **概述不超过十个字**，标点也算。只说这一镜拍什么，如 `推门进店`、`特写面碗落桌`、`店员说要打烊`。
- 镜头表里只有这些：不写时间、秒数、机位、声音、站位。这些细节写进提示词的分镜。
- 镜头表的一镜对应提示词分镜里的一个 `镜头N｜标题`，镜数、顺序一致；提示词的标题可以直接用这里的概述。

例：

```text
第2-1段｜镜头表｜打烊前的一碗面
镜头1｜推门进店
镜头2｜店员说要打烊
镜头3｜特写面碗落桌
```

## 六、文件和存放

| 内容 | 放在哪 | 文件名 |
|---|---|---|
| 剧本 | `定稿的剧本/第N段/` | `第N段_剧本.docx` |
| 镜头表 | `定稿的剧本/第N段/` | `第N段_镜头表.docx` |
| 改版前的原文件 | `历史记录/` 下面同样的路径 | `原名__日期-时间.后缀` |

- 剧本和镜头表一律 DOCX，不用 TXT。
- 修改中和定稿的版本都放在 `定稿的剧本/第N段/`，每段只有这一份。
- 一个文件里写了好几段的汇总稿可以留着当底稿，但每段还要有自己的分段文件。

---

## 七、交付前自检

剧本：
- [ ] 标题是 `第N段｜段名`；段头有场景、人物，场景是 `时间｜内/外｜地点`。
- [ ] 正文每一行都是 △ 动作、台词、字幕、音效四种之一。
- [ ] 台词行的角色名都在人物表里；画外、旁白、内心写在括号里。
- [ ] 没有时长、秒数、机位、运镜；修改记录放在备注里。

镜头表：
- [ ] 标题是 `第N段｜镜头表｜段名`，段名和剧本一致。
- [ ] 一镜一行 `镜头N｜概述`，从 1 连续编号，没有别的内容。
- [ ] 每条概述不超过十个字；没有时间和秒数。
- [ ] 镜数、顺序和提示词的分镜一致。
