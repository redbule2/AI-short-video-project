# 常见错误速查

写完底稿或场景段，对一遍。

| 错误 | 后果 | 改法 |
|---|---|---|
| 把底稿原样贴进提示词 | 两套左右和制图记号可能增加解释负担；具体影响尚待对照实测 | 翻译成场景段（SKILL.md §六） |
| 场景段写成房间说明书，每个地标都写一句 | 太长；每多一句都是给模型多派一个任务 | 两三句、120 字以内是软目标；先删非必要细节，逐图职责和剧情关键关系必须保留 |
| 场景段把未绑定参照的“画面左右”当固定布局 | 可能与当镜构图混淆 | 优先地标相对；非关键手性可交给图，关键手性首次绑定具体图或观察基准写清 |
| 把风险描述（DRIFT-RISK）喂给模型 | 把要防的东西请进上下文 | 只喂真值 |
| 无依据的防御性排除（“没有看台”“没有第二个出口”） | 可能增加无关概念 | 额外防御句踩过才加；用户要求与剧情必需事实首次写清，优先正面表达 |
| 为保证某个动作，把两个实体写得很紧 | 合成新物体（球门实心板事故） | 删掉，退回已验证的朴素写法 |
| 底稿里写了人、动作或逐镜状态 | 改动作时房间被连带重算 | 挪进分镜 |
| 复述参考图的颜色纹样 | 和图抢解释权 | 删；但关系照写 |
| 屏幕左右不写，指望模型从地标推出来 | 看模型，有的基本都翻 | 分镜逐镜写，正反打各写一遍 |
| 轴线死锚在地板上的某个点 | 人一动轴就错 | 轴线挂当前对戏的两人 |
| 用轴线上的地标命名机位侧 | 分不出是哪一侧 | 换一个不在轴线上的地标 |
| 两个方向矛盾的主光 | 每个新角度重新发明照明 | 单光逻辑 |
| 只喂一个朝向的场景图 | 反打方向弄反，或另一半房间被模型现编 | 几个朝向一起喂，逐张写朝向 |
| 把场景图那套"只采用……"套到首帧、尾帧图上 | 首尾帧失效 | 两类图两套写法（SKILL.md §七） |
| 同一镜里实体和镜面反射一起出现 | 场景地理被破坏 | 反射当独立场景，切开 |
| 把第四个具名角色自动降为群演 | 篡改角色设定 | 不降格；出问题再按 sd25-pe 核一人一图、考虑拆镜 |
| 把俯视图当参考图喂视频模型 | 模型映射不了平面几何 | 俯视图只给人看 |
| 证据标签、版本号跟着进提示词 | 流程标记混进生成内容（sd25-pe 第 6 条） | 只在底稿里用 |
