# 翻译示例：底稿 → 场景段 → 轴线行 → 分镜

一间小面馆。两张场景参考图：@图片3 从店门往里、朝柜台方向拍；@图片4 从柜台后面、朝店门方向拍。本场的对戏一直在柜台后操作区里的店主和柜台前的顾客之间。

## 一、底稿（人审用，不进提示词）

```
GEO 底稿（小面馆 v1；人审用，不进提示词；状态＝草案）
—— 方位基准 ＝ M0 相对。
—— MAIN VIEW M0 ＝ 取 @图片3 的机位（按 M0 第①条）：站在店门内侧正中，面朝柜台；
   以 M0 看：左＝窗墙，右＝冰柜墙，近＝店门墙，远＝柜台墙。【素材可见｜待拍板】
—— ANCHOR ＝ 柜台，长方约 2.4×0.6 m，与柜台墙平行、相距约 1 m、左右居中，正面朝店门；
   柜台与柜台墙之间是操作区。【素材可见｜待拍板】
—— ENVELOPE ＝ 从店门墙起俯视顺时针：店门墙 → 窗墙 → 柜台墙 → 冰柜墙 → 店门墙。【素材可见｜待拍板】
—— OPENING 店门 ＝ 通行口，店门墙正中；连接店内与临街人行道；净宽约 1.2 m，门内外无台阶。【素材可见｜待拍板】
—— OPENING 窗 ＝ 采光口，窗墙中段，两扇并排，透光。【素材可见｜待拍板】
—— LANDMARK 冰柜 ＝ 立式，位于 FR 角：背贴冰柜墙、靠店门墙那一端，正面朝店内。【素材可见｜待拍板】
—— LANDMARK 方桌 ＝ 四张，分两列摆在柜台与店门之间，两列中间留一条从店门直通柜台的过道。【素材可见｜待拍板】
—— LANDMARK 价目牌 ＝ 挂在柜台墙上、正对柜台中部，正面朝店门。【素材可见｜待拍板】
—— 180° AXIS ＝ 店主与顾客的连线（垂直于柜台，从柜台中点指向店门）；机位始终在窗墙那一侧，不越轴。【用户明示｜待拍板】
—— LIGHT ＝ 主光是窗墙进来的天光，照向冰柜墙；方桌的影子朝冰柜墙一侧落。【素材可见｜待拍板】
—— SET BOUNDARY ＝ 权威参考集合为 @图片3、@图片4；"场内"指四面墙以内；只限永久布景，不限登场的人物与道具。【用户明示｜待拍板】
```

俯视草稿（只给人看）：

```
             柜台墙（价目牌）
   +---------------------------+
   |          操作区           |
   |       [   柜 台   ]       |
 窗|                           | 冰
 墙|   桌       过道     桌    | 柜
   |   桌                桌    | 墙
   |                      冰柜 |
   +----------[ 店门 ]---------+
                M0 ↑（@图片3 的机位，面朝柜台）
```

这份底稿过得了多解检测：M0 取自 @图片3，左右由那张图钉死；ENVELOPE 给了顺序；每个地标都有方向和位置约束；店主站在操作区里，地图自身说得通。

## 二、场景段（进【主体与关系】，本场各段逐字一致）

逐图声明，再补必要关系；120 字是软目标，不为压字数合并素材职责：

```
@图片3：面馆从店门朝柜台，借方向、布局、陈设、材质和灯光，不采用图中人物。
@图片4：同一面馆从柜台朝店门，借方向、布局、陈设、材质和灯光，不采用图中人物。
柜台正对店门，窗在一面侧墙，冰柜在对面侧墙靠门那头；主光从窗户照进来。
```

逐行对照——底稿十几行，场景段只留了四件事：两张图的朝向、柜台对着门、窗和冰柜各在一侧、主光从哪来。

| 底稿行 | 场景段 | 为什么 |
|---|---|---|
| MAIN VIEW M0（左＝窗墙，右＝冰柜墙） | 不写；逐图声明各自朝向 | M0 的左右可能与当镜画面左右混淆；本例非剧情关键手性由图提供，关键手性须首次明确 |
| ANCHOR 柜台 | "柜台正对店门" | 锚点和出入口，本场戏要用；尺寸、操作区图上看得见 |
| ENVELOPE | 不写 | 记号；墙的顺序图上看得见 |
| OPENING 店门 | 并进"柜台正对店门" | 同上；"门内外无台阶"没出过问题 |
| OPENING 窗 | "窗在一面侧墙" | 轴线要用它命名机位在哪一侧；哪一面交给图 |
| LANDMARK 冰柜（FR 角） | "冰柜在对面侧墙靠门那头" | 轴线另一侧的参照；不写"紧挨店门"——写太紧，模型可能把冰柜和门合成一个东西 |
| LANDMARK 方桌 | 不写 | 图上看得见，本场戏用不到；漂了再补 |
| LANDMARK 价目牌 | 不写 | 图上看得见；要用时在分镜里写"店主身后是挂着价目牌的后墙" |
| 180° AXIS | 不进场景段，进轴线行 | 跟在场景段后面 |
| LIGHT | "主光从窗户照进来" | 一句；明暗和影子方向漂了再补 |
| SET BOUNDARY | 由"只借……"承担 | "店里的陈设就是两张图里的这些"踩过才加 |
| （没写的） | 不写"店里没有第二个出口" | 成片冒出过第二扇门，才补"店里只有临街那一扇门" |

若本场剧情依赖窗和冰柜的左右手性，首次就补；本例未将它列为剧情关键事实，可由图提供，成片换边后再补："在@图片3 的画面里，窗在左侧。"——M0 就取自 @图片3，底稿的"左＝窗墙"可以原样这样翻。

## 三、轴线行（跟在场景段后面）

```
轴线：店主和顾客之间；机位留在靠窗一侧，不越到冰柜那侧，在这一侧内照常运动。
```

窗不在轴线上（轴线从柜台中点直通店门，窗在侧墙），所以能用它命名机位在哪一侧。

## 四、分镜里的屏幕投影（节选）

```
镜头3：顾客过肩拍店主。店主在画面左，顾客的肩背在画面右前景；店主身后是挂着价目牌的后墙。
镜头4：反打，店主过肩拍顾客。店主的肩背在画面左前景，顾客在画面右；顾客身后是店门那面墙。
```

**方位是推出来的，不是猜的。** 把俯视草稿放进坐标：窗墙在左、冰柜墙在右、柜台墙在上、店门在下；店主在柜台后的操作区，顾客在柜台前，两人连线是竖的。机位在连线左边（靠窗）时：

- 镜头3：机位在顾客身后偏左，朝上看向店主。离机位近的顾客落在画面右，店主在画面左；店主身后是柜台墙，价目牌就在他身后。
- 镜头4：机位在店主身后的操作区里偏左，朝下看向顾客。店主落在画面左，顾客在画面右；顾客身后是店门那面墙。

所以店主始终在画面左、顾客始终在画面右，两镜写法一致。v6 改版时按 35mm 视角、人体宽约 0.45 m 用坐标算过：两镜的说法都成立；在靠窗一侧抽样一万六千多个有效机位，店主没有一次跑到顾客右边。

底稿里的"窗墙在左"是 M0 的左。镜头4 朝店门方向拍，窗墙在画面右侧以外——两套左右不能混用，所以 M0 的左右只留在底稿里。
