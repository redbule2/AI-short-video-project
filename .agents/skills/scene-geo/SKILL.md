# 场景空间锁（GEO 底稿 → 场景段）

v6.5（2026-11-13）。改动与各节去向见 `references/changelog.md`；**改本 skill 之前先读 `references/maintenance.md`。**

视频模型每次生成都失忆。不锁的东西它每次重新发明——墙会挪、门会换边、桌子变形、机位跳到轴的另一侧、过肩镜里同一个人被画两次。

产出分两份，读者不同、写法不同：

| 产物 | 给谁 | 写法 | 进不进提示词 |
|---|---|---|---|
| **GEO 底稿** | 人（及做核对的 agent） | 记号语言：M0、FL/FR、W1、四态与证据标签 | **不进** |
| **场景段** | 视频模型 | 简短的中文自然句（默认两三句），只写必要的地标关系 | 进【主体与关系】（写法二进【场景】），本场各段逐字一致 |

底稿把空间核到唯一、无矛盾；场景段把核过的结论，用模型读得懂、不会读错的话说出来。**不要把底稿原样贴进提示词**（原因见 §六）。

先弄清用户要哪一样：给一场跨镜复用的戏做底稿＋场景段，还是只核对几个镜头的空间描写（后者见 `references/shot-checks.md`）。

## 与 sd25-pe 的分工（先读）

- 写／改 Seedance 2.5 提示词以 sd25-pe 为准；与本 skill 冲突时，以 sd25-pe 为准。
- 用户要成品提示词（"写第三段提示词"之类）时，按 sd25-pe 和用户的模板完整写；本 skill 只供空间部分（场景段、轴线行、逐镜空间核对），**不得拿本 skill 的权限边界拒绝**。
- 素材引用沿用用户写法（`@图片N`）；素材职责、【未采用素材】、参数不进提示词、不写时间码、不自动加通用负向约束，都按 sd25-pe。

用户模板照 sd25-pe：生成目标 → 参考素材职责 → 基础设定 → 主体与关系 → 事件脚本 → 保持一致；素材多时用写法二，不写主体与关系，按人物、道具、场景、动作与声音分组。下文的「分镜」指事件脚本里的各镜，「人物栏」指【主体与关系】（写法二【人物】）。空间内容这样放：

| 内容 | 放哪 |
|---|---|
| 场景段：场景图各是哪个朝向、地标关系、主光方向 | 【主体与关系】（写法二放【场景】） |
| 整体光色、色调 | 【基础设定】的光色基调（只写宏观） |
| 轴线、机位留在哪一侧 | 场景段后面一句（同上） |
| 逐镜谁在画面左右、本镜看得到哪些地标、运动方向 | 【事件脚本】里那一镜 |
| 剧情必需的人数与身份（首次写清）；额外防重复句踩过才加 | 【主体与关系】（写法二放【人物】） |

源仓库的 LOCATION MAP、Spatial Layout Block，在这套模板里对应的都是事件脚本里那一镜。

## 铁律 0 · 如无必要，勿增实体

**GEO 的价值是揪出矛盾和多解，不是把每样东西都写死。** 每写死一个本来没出问题的关系，就是给模型派一个新任务——新任务会长出新东西。

- **出问题先删，不先加。** 成片冒出不该有的东西，先找"哪句话把它招来的、能不能删"，而不是"再加一句压住它"。
- **额外防御句在上一版没写时出问题了吗？** 没有 ⇒ 通常不加。此判断不用于删减用户要求或剧情必需事实；已验证的朴素写法优先于更精确的新写法。
- **负断言也在增实体。** "没有看台"里就有"看台"两个字，等于把它请进上下文。额外防御性排除只留**真正踩过且有依据的**；用户要求或剧情必需的排除事实首次写清，优先写成正面唯一句（"店里只有临街那一扇门"）。
- **两个实体写得很近、很紧时最危险**——模型容易把它们合成一个新物体。
- **底稿可以写全，场景段要短、不加料**：场景段以两三句为简洁目标；图片已充分表达、且非剧情关键的内容不复述。必要关系优先于字数，不写无依据的防御性排除、风险提示或没验证过的紧贴描述（§六）。

**事故（2026-08-25，第五场·弧线刀）**：为保证"球门翻筋斗撞到后面的铁丝网"，给铁丝网补了一句"紧挨球门正后方、几乎贴着球门背面、网顶低于横梁"，成片里球门框内凭空立起两块深色实心板。底稿的 DRIFT-RISK 早就写着"铁丝网的规则网格易糊成一堵实墙"——照着 GEO 加约束时，没防 GEO 自己列的风险。正确修法：删掉那句，退回上一版已验证的"球门后一道约两米高的铁丝网"（那一版球门照样撞烂了网）。

**“踩过才写”只限制额外的防御性补句。** 用户明确要求、剧情因果或连续性交接必需的人数、身份、道具数量、出入口、连接关系与左右手性，首次就按已批准信息写清；有缺口则标未决项，不等生成失败，也不凭空补值。人物与道具事实放对应栏，场景关键关系放场景段。下文同类条目均受此范围限制。

## 权限边界

- 产物只有空间部分：底稿、场景段、轴线行、对逐镜空间描写的核对意见。
- **GEO 任务里不代写**分镜、站位、走位、入退场、动作、机位、对白、节拍、越轴方案、开场定场镜头。逐镜空间由用户写；本 skill 给空模板、转录、检查、局部评改，不从空白起草人物调度。（用户要成品提示词时见上一节。）
- 素材没规定、而场景级静态几何必须闭合时，给**一个最小草案或至多两个互斥方案**，标【待拍板】；涉及人物、动作、机位、节拍的**只报缺口**。
- **不自行生图。** 用户决定生图后，按本项目的 `chatgpt-mode-image` 出图；生图提示词写清前后镜的逻辑连续性（人物、道具、光的状态），含可识别道具时写清它和周围固定物的位置关系，出图后对照底稿验收。
- 用户只要求**检查**现有空间描写时，不强制交审三件套。

**两轴标注（只在底稿里用）**：证据来源【素材可见】【用户明示】【几何推断】；批准状态【待拍板】【已锁定】。

## 一、三层锁

跨镜空间要同时锁三样，谁也替代不了谁：

| 层 | 锁什么 | 写在哪 |
|---|---|---|
| **世界层** | 地标身份、相对关系、距离、朝向、光、轴线 | 底稿 → 场景段＋轴线行（进【主体与关系】，写法二进【场景】） |
| **屏幕层** | 本镜／本组镜头的画面投影：谁在画面左右、往哪边动 | 【事件脚本】各镜；正反打两镜各写一次 |
| **身份计数层** | 恰好几个人、谁是谁、不许重复 | 【主体与关系】（写法二【人物】）；剧情人数与身份首次写清，额外防重复句踩过才加 |

屏幕层要单独写，别指望模型从地标推出来：图片模型实测里，不写时有的模型基本都翻、有的基本都对；写明之后四个模型全对，没有一个变差（`references/evidence.md`；Seedance 2.5 视频未测）。这和 sd25-pe 的"围绕稳定物体写、不要只写屏幕左右"不冲突：世界层写关系，屏幕层逐镜补左右。

## 二、铁律

1. **底稿只写不会动的**；人进分镜，人数进人物栏。"不会动"按整场剧情核：本场会被推走、掀翻、搬动的，进分镜的状态描写，底稿里最多写"某状态默认位"，并注明位移属逐镜。
2. **按语义分层，不按"图上看不看得见"分层。** 关系和数量，图上看得见也照写（判定程序见下）。
3. **前后一致只是必要条件。** 穿墙、门通向不存在的空间、与反打素材冲突、光影物理上不可能的地图，前后一致也是错的。多份素材冲突（镜像、裁切、换景）时并列证据，请用户裁定。
   **图文冲突默认以图为准改文字**（复刻类项目）：已入库、会被逐镜引用的参考图与底稿冲突时改文字，除非该项是叙事关键（人数、出入口、轴线、手性）——文字迁就图只改一次，图迁就文字要重生成，还会波及所有引用它的镜头。（霍元甲彩玻隔扇：原片读作五扇、入库图四扇，用户裁定改成四扇，"复刻不是还原"。）
4. **地标行 AND 必填**：① 唯一身份 ② 相对 M0（或已声明基准）的方向 ③ 至少一种尺度或位置约束（距离、区间、接触、邻接、共线、有序拓扑）④ 证据标签。
   - 开口按 §四"开口分档"补字段：**通行口**（门、拱门、缺口、楼梯口）要宿主墙段与位置、连通到哪个已存在的空间、门槛尺度；**采光口**（窗、高窗）和**装饰口**（漏窗、格栅）不要求连通对象。
   - **有正反面的地标**（球门、门框、神龛、屏风、柜子）再加朝向，否则它能原地转 180° 而不违反任何一行（实测被攻破过）。
   - "距锚点约三米"没有方向，"在一端／旁边／对面"没指名哪一端、相对什么，都不算完整位置。
   - 人物遮挡依赖机位 → 分镜；固定物之间的恒定遮挡才进底稿。
   - **多解检测（锁定前必做）**：仅凭底稿文字，还能把任一地标绕锚点旋转、镜像、换到另一侧而不违反任何一行 → 多解，标【未知／阻断】，不得锁定。
5. **跨调用逐字复制的是场景段，不是底稿。** 同一版场景段随本场每次调用、每个段文件逐字复制，特写和空镜也照贴（图片模型实测：特写贴了空间描写，背景就是那间屋、手性正确；不贴，背景整个重造）。底稿改版 → 场景段重译 → 本场所有段文件换新。

### 判定程序：这条信息放哪

1. 用户批准了吗？没有 → 只进未决项。
2. 本版本所有相关镜头里都一样吗？不是 → 分镜的状态描写。
3. 是**关系或数量**吗（两个以上实体的位置、朝向、相邻、包含、连通、通行、顺序、距离，或可数的数量）→ 进底稿，图上看得见也照写——单张图只从一个角度看，定不住这些关系。要不要再翻进场景段，见 §六。
4. 只是单个物体的颜色、纹理、材质、风格 → 交给参考图。两个例外要写：**识别钩子**（最小可区分量："带彩玻隔扇的开口"要写，色号纹样不写）、**图文冲突项**（图里有但本场不要／图里没有但必须有）。
5. 人物或可移动道具的部件、握持、开合、损坏、功能 → 资产与状态描写（项目另有道具白名单门禁）。
6. 依赖当镜机位才成立的（屏幕左右、人物遮挡、谁逆光）→ 分镜，逐镜核对。

## 三、什么时候建底稿

条件是**跨镜／跨调用复用**，不是人数：同一个固定空间要在两个以上镜头或调用里保持不变 → 建。独立单镜通常不建（门口入场、走廊方向、绕家具这类高失败镜型，仍要在分镜里写清空间）。同一间屋但陈设大改（墙体、门洞、主光逻辑重置）→ 视同换场，另起一份；只有人物或可移动道具变化 → 不另起。

## 四、工作流

### S1 收料

- 场景参考图：几张？各是哪个朝向？是不是 3/4 或天花角视图（正面"美图"在大全景里会变成平面墙纸，画外每次现编）？图里有没有人？有没有镜像、裁切、其实不是同一个空间？
- **同一室内的几个朝向图一起喂**（如店内朝柜台方向和朝门口方向），场景段里逐张写清朝向；只喂一张，模型容易把方向弄反。
- 原片帧、已定分镜、用户已写的站位；这场几个镜头，有没有反打、走动、穿门、镜面反射。
- 生成方式：一段一次调用、段内多个分镜（用户的常用做法），还是一镜一调用。
- 目标模型默认 Seedance 2.5，其它见 `references/other-engines.md`。画幅只用来规划构图，不写进提示词；没定不阻塞。

**必须真的看图**，读不到就说读不到；没有图时按用户的文字做提案，全部标【几何推断】【待拍板】。

**地点母板验收**：优先 3/4 或天花角视图 · 至少一个反复认得出的固定地标 · 只有一套说得通的主光方向 · 场地容得下本场的人数、动作、绕障和机位，并留出干净的行动走廊 · 正式开拍前各做一次短视频测试。

### S2 锚点与地标

**每个地点都要有锚点**——一个有名字的视觉地标，给相对定位一个固定点。没有锚点的地点会漂。

- 全局锚点标准：**唯一、固定不动、各角度看得见、能绑定站位**——不是"最大"。"固定不动"按整场剧情核：霍元甲议事厅拿红桌当锚，原片里桌子被推到大门前，不合格——换成厅心吊灯、香案这种真不动的，或在锚行写明"此为某状态默认位，位移属逐镜状态"。
- 找不到全局锚点时，用最少数量的局部锚点：逐个注明唯一身份、覆盖区和整场不动的状态；共用同一 M0，写清锚间方向、尺度或连接关系。局部锚只须在各自覆盖区内可辨认，不要求某一个锚跨所有角度可见；连接缺失或仍有多解时不锁定。
- 室内用**墙上独特、看得见的特征**给墙起名（"门窗墙＝装着彩玻隔扇开口和两扇拱窗的那面"）。
- 素材里看不到的墙：给稳定编号（"反打墙 W3"）＋拓扑定义，标【待拍板】，**不编造墙上的装饰**。

### S2b 主视角 M0（只在底稿里用）

**锚点 ≠ 坐标系**：一个中心点加若干距离只能得到同心圆，分不出"门窗墙在红桌的哪一侧"。M0 就是那条定了方向的射线，底稿里一切 FL/FR、左右都相对它给。

- **M0 不是机位**，是这张地图的"正北"。**M0 要锁位姿**：站在哪、朝哪看都要写（"站在店门内侧正中，面朝柜台"）；只写朝向，M0 自己就是多解的。
- **M0 怎么挑**——按顺序取第一个可用的，并写明按的是哪一条，让下一个人能复现：① 定场镜或地点母板的机位，**优先取某一张场景参考图的机位**，写明是哪张；② 本场主对峙轴的一端（取素材覆盖更全的那端）；③ 唯一通行口的中点，朝屋里看。
- **按①选时，底稿里的左右＝那张图画面里的左右。** 翻译成场景段时手性不丢，靠的就是这一条（§六）。
- **方位定义不许绕圈**："画面左＝缺口那一侧"＋"缺口在画面左半段"，等于没说。每个方位都要追到一个不依赖其他方位的源头（某张场景图本身、太阳、唯一的高地、水流方向、素材里看得见的不对称物），先用它钉死左右，再定位其他地标。互不矛盾 ≠ 说清楚了。

### 三条元规则

1. **术语完整性**：底稿里被任何一行引用的术语（"右立柱""缺口""场内"……）都要有一条 `＝` 定义行；悬空引用判不合格。
2. **溯源与作废**：每一行都能追到已批准的素材编号或用户明示；锁定后改任何一行，本版作废。没有出处的**负断言**（"没有第二道围墙"）和正断言同样对待，不许凭空加。
3. **域定义**：SET BOUNDARY 要写明"场内"到哪为止（围墙以内？含远景？），并写明它**只限永久布景，不限登场的人物与道具**。

### 词汇表

| 词 | 定义 |
|---|---|
| 表面标签 | 边界段的名字（"W1 门窗墙"），用墙上独特、看得见的特征命名 |
| FL／FR／BL／BR | 相对 M0 的前左／前右／后左／后右；前＝靠近 M0，后＝远离 M0 |
| 占地轮廓 | 锚物俯视的形状和尺寸（"长方 1.8×0.6 m"）；点状锚物（吊灯、柱子）写"点锚，无轮廓" |
| 朝向零点（yaw） | 有正面的物件，正面朝哪个已命名地标（"香案正面朝厅内、背贴彩龛墙"） |
| 门槛尺度 | 开口的净宽×净高；有没有台阶或门槛，在门内还是门外一侧 |
| 连续边界特征 | 跨多个边界段连续存在的东西（绕四墙的高窗带、通铺护墙板）——单列一行，不挂在某一面墙下 |

### 开口分档

| 类型 | 必填 |
|---|---|
| 通行口（门、拱门、缺口、楼梯口） | 宿主边界段＋段内位置＋连通到哪个已存在的空间＋门槛尺度 |
| 采光口（窗、高窗） | 宿主边界段＋段内位置＋数量＋是否透光；不要求连通对象 |
| 装饰口（漏窗、格栅） | 宿主边界段＋段内位置＋数量；不要求连通对象和门槛 |

### 方位基准

- **底稿**：M0 相对（推荐）／地标相对／罗盘，三选一，首行声明，全场不混用。
- **场景段**：优先用地标相对关系（正对、背靠、贴哪面墙、夹在什么之间、在哪一头）。**不用未绑定参考图或观察基准的“画面左右／画面深处”描述固定布局**，否则可能被误读成当镜构图。需要明确手性时按 §六绑定具体参考图或观察方向。
- "一端／旁边／对面"不算方位，必须指名是哪一端、相对什么。

### S3 距离与尺度

- 底稿用绝对化写法：`A 距 B 约 2 m，C 在 A 身后 1.5 m、被角柱挡住一部分`，好过 `A 在桌边，B 在旁边`。
- **巨物不给米数**：给人体倍数＋画面里的参照物＋失败判据；高风险同框另附尺寸参考图。
- 位置进底稿；**状态**（门开着还是关着、桌子掀翻没有）写进事件脚本那一镜的开头、结尾。人物之间的距离、身高锁见 `references/shot-checks.md`。

### S4 轴线与机位侧

- **180° 轴＝本镜对戏两人当前位置的连线**；对戏的人或位置变了，就重算。
- **机位侧用地标命名**（"机位始终在靠窗那一侧"），这个地标本身不能在轴线上。这只限定机位在哪一侧，**不是固定机位**——机位在这一侧里照常运动。
- 对戏两人全场固定时，轴线行跟在场景段后面；对戏的人会轮换，就逐镜写进事件脚本。屏幕左右、运动方向、越轴的核对见 `references/shot-checks.md`。

### S5 光

- **单光逻辑**：全场一个主光源、一个影子方向，不出现两个方向矛盾的主光。
- 写到**物理事件**的粒度：主光从哪个地标方向进来、在哪个固定面上反弹、固定物的影子朝哪落、雾的浓淡和位置。被点名的光件，模型会跨镜重建；"阴郁""戏剧化"这类形容词只能近似。
- 色温数值（K）只补充看得见的描述（"暖黄色的灯光"），不代替它；写了就全场一个值，不逐镜变。
- **多面采光**（四面高窗带、两头都透光）：底稿写光的事实分布＋默认主光方向＋"逐镜另锁单一主光方向与影子落向"，三样缺一不可。
- 底稿不写"谁逆光"（取决于当镜机位）；机位侧全场固定时，场景级的背光关系可以进底稿。
- 以上是底稿的写法；场景段里主光只写一句（§六）。

### S6 自检、交审、锁定、翻译

§八 自检 → **交审三件套**（底稿草案〔带两轴标签〕＋俯视关系草稿＋未决项清单）→ 用户拍板 → 底稿标"已锁定 vN" → **按 §六 翻译成场景段**（场景段同样标 vN 存档，编号不进提示词）。

俯视草稿用 ASCII 画墙、开口、固定物和 M0，不画人；**只给人看，不当参考图喂给视频模型**。锁定后改任何一行：版本 +1 → 场景段重译 → 本场所有段文件换新；一场不许两版同时在用。

### S7 调用结构（Seedance 2.5）

| 结构 | 怎么用 |
|---|---|
| 一段一次调用、段内多个分镜（常用） | 场景段写一次；事件脚本每一镜**开头**重述人在哪个地标旁、朝哪、谁和谁对着——这就是切镜后的重新锚定。各段场景段逐字一致；下一段第一镜的开头承接上一段最后一镜的结尾 |
| 按阶段写（sd25-pe 的长视频写法） | 场景段写一次；每个阶段的"开始时"重述位置和朝向，"结束时"写清可见状态 |
| 一镜一次调用 | 每次带同一版场景段；本镜站位、人数、初始状态写在分镜里 |
| 跨段续接 | 可以把上一段结尾的片段当参考视频，按 sd25-pe 写清职责（承接人物位置、姿态、光线和运动趋势）；2.5 上未验证 |

**开场定场（只问不写）**：源仓库经验——一次调用拍多个镜头时，开场先给人物都已就位的全景、动作先压住，后面各镜不容易换位。2.5 上未验证，只在未决项问用户；要的话写成"开场先是人物都已就位的全景"，不写秒数。

**提示词太长时**按 sd25-pe 的压缩顺序处理；场景段不在优先压缩之列，要压先压它里面的重复描述。

## 五、GEO 底稿模板（人审用，不进提示词）

每个字段只能取四种状态之一，不许留空：

| 状态 | 含义 | 能否锁定 |
|---|---|---|
| 【已锁定】 | 有素材、用户明示或已批准的几何支持 | ✅ |
| 【待拍板】 | 几何推断，等用户点头 | ❌ 只在草案里 |
| 【未知／阻断】 | 现有证据定不了，要补素材或请用户裁定；多解检测不过也标这个 | ❌ 阻断整份锁定 |
| 【不适用】 | 条件行在本场不成立 | 锁定版删掉该行 |

- **填不出的格**：标状态＋进未决项＋写明回补条件（什么时候、靠什么补），三样都要。
- **标【待拍板】之前先问自己：是真的查不到，还是没去查？** 未决项要写明已经查过哪些素材。（教训：霍元甲那份把"兵器架在哪一端"挂成硬阻断，结果原片里有正对那面墙的帧，翻一张就有。）
- 不许用"以后补""凡入画再点名"这类未来的动作冒充字段值；地标行只填了距离不算填上——沿着圆周处处成立，等于没写。

```
GEO 底稿（<场景名> vN；人审用，不进提示词；状态＝草案／已锁定）

—— 方位基准 ＝ M0 相对（或：地标相对／罗盘）。
—— MAIN VIEW M0 ＝ <取自哪张图的机位／按 M0 第几条选>：站在 <地标或墙面>，面朝 <地标>；
   以 M0 看：左＝<>，右＝<>，近＝<>，远＝<>。底稿一切方位都相对 M0，不随实际拍摄机位改变。【】
—— ANCHOR ＝ <唯一固定锚物>，其中心为 ORIGIN；<占地轮廓 + 固定朝向>。
   锚物近似圆形或中心对称时，写明"它只提供原点、不提供方向"，方向另找源头。【】
   局部锚方案：逐项列 ANCHOR ID、覆盖区、固定状态，共用 M0；指定其中一个为 ORIGIN，写清其他锚相对它的方向与尺度或连接关系，不强求单锚覆盖全场。【】
——（人物、机位围着锚物时）CLOCK ＝ 以 ORIGIN 为中心的俯视钟面：12 点＝<M0 正前方的地标>，3 点＝<M0 右手>，6 点＝<M0 身后>，9 点＝<M0 左手>；钟点钉在锚物默认位上，不随机位转。【】
—— ENVELOPE ＝ 从 <边界段 W1> 起俯视顺时针：W1 → W2 → … → Wn → W1；
   逐段写表面标签、相邻关系、开口、已知还是未知。【】
—— LANDMARK <ID> ＝ 位于 ANCHOR 的 <L/R/F/B/FL/FR/BL/BR 或明确角度>；距 ANCHOR <约 X m／区间／已批准拓扑>；
   与 <相邻地标／边界段> 为 <接触／邻接／共线／包含> 关系；有正反面的写朝向零点。
   墙的"端"和"侧"必须指名（"贴挂画墙的 FL 端"）；写"一端／一侧／旁边"一律打回。【】
—— OPENING <ID> ＝ <通行口／采光口／装饰口>，位于 <边界段 ID> 的 <左／中／右 或 距端点约 X m>；
   按开口分档补字段（通行口：连接 <空间 A> 与 <空间 B>，门槛尺度 <值>）。
   素材没拍到门后 → 标【未知／阻断】，不许编。【】
——（仅当本场对戏两人全场固定、轴线不变时）180° AXIS ＝ <两人连线>；机位始终在 <不在轴线上的地标> 那一侧，不越轴。【】
—— LIGHT ＝ 主光自 <方向／地标> 进入，<固定物> 的影子朝 <方向> 落；一个主光源、一个影子方向。
   多面采光：事实分布 + 默认主光方向 + "逐镜另锁单一主光方向与影子落向"。【】
—— SET BOUNDARY ＝ 权威参考集合为 <素材编号清单>；"场内"指 <边界到哪>；
   只锁该集合已建立并获批的空间与陈设；只限永久布景，不限登场的人物与道具。
   未知的一侧不得用"参考图里没有"推成"不存在"——那要反打证据。【】
——（有反打时）REVERSE SIDE ＝ <该方向有什么>；<没有什么> 写用户已明确批准的事实；额外防御性排除只写踩过且有反打证据的。【】
——（有固定动线时）WORLD ROUTE ＝ <起点地标> → <经过的门洞／走廊／绕开的障碍> → <终点地标>。
   只写世界层路径；画面上从左往右还是从右往左，写进分镜。【】
——（有镜面／水面时）REFLECTIONS ＝ <反射面位置>；反射和实体不在同一镜里连续出现。【】
——（有文字招牌／强几何时）DRIFT-RISK ＝ <逐项点名 + 基准真值：招牌写的什么字、网破在哪块、多大……>。【】
   验收用，不进场景段；真值里需要模型照着画的部分（如招牌文字），在场景段里写成正面描述。
   给不出真值时不删行：整行标【待拍板】+ 回补条件（"待第一条出片后抽帧确定"）；场内确实没有可核对的文字和强几何时才标【不适用】。
```

屏幕投影不写在底稿里，写进分镜，正反打两镜各写一次。

## 六、翻译成场景段（喂给模型的那一段）

**为什么不能把底稿原样贴进提示词：**

- 底稿的“左右”属于 M0，可能被误读为当前镜头的画面左右。即使底稿已声明基准不随机位变化，两套左右仍有混淆风险；改用地标关系是减少误读的策略，不代表原写法必然矛盾。
- M0、FL/FR、W1、ORIGIN、ENVELOPE 是人审制图记号，转换成自然语言可减少解释负担；尚无本项目 Seedance 2.5 对照结果证明模型读不懂这些记号或转换后一定更稳。版本号、“已锁定”、证据标签按 sd25-pe 第 6 条留在底稿，不进 Prompt。
- DRIFT-RISK 是写给人的验收提醒。"铁丝网易糊成一堵实墙"喂进去，等于把"实墙"请进上下文（铁律 0）。

### 写什么

**场景段要短**：两三句、120 字以内是默认软目标（包含逐图职责声明），不是字数上限或判废条件。先删重复和非必要细节；多图声明、复杂空间或剧情关键关系确需更多文字时可以超过，保留必要事实。不得为凑字数合并逐图职责、删掉必要的出入口、朝向、连接关系或数量；额外防御句仍只在有依据时简短补充。

1. **每张场景图拍的是哪个朝向、采用什么。** 同一室内的几个朝向图一起喂，朝向写在括号里，并点明是同一个空间：
   ```
   @图片3：面馆从店门朝柜台，借方向、布局、陈设、材质和灯光，不采用图中人物。
   @图片4：同一面馆从柜台朝店门，借方向、布局、陈设、材质和灯光，不采用图中人物。
   ```
2. **地标关系只写三类**：本场戏要用到的（锚点、出入口、给机位侧命名的那个地标）、图上看不出的、成片里漂过的。用正对、背靠、贴着哪面墙、夹在什么和什么之间、在哪一头这类说法；其余交给场景图，距离只在要紧时写。
3. **非关键左右手性可由场景图承担。** 涉及用户要求、剧情因果或连续性交接的关键手性，首次就用文字写清；图上看不出或成片已经左右翻过的，也补文字。方位要**绑在具体的图上**：“在@图片3 的画面里，窗在柜台左侧”，不把该图的左右当成本镜构图。
   - M0 是按①从某张图选的 → 底稿的左右可以直接翻成"在@图片N 的画面里……"。
   - M0 不是任何一张图的机位 → 手性没有图可以托付：优先补一张该方向的场景图；补不了，才写"从<地标>朝<地标>看，<X>在左边"，并在未决项标【待实测】。
   - 底稿有 CLOCK 行（人物、机位围着锚物时才设）→ 写钟面一句：以<锚物>为钟面：<地标>在12点，<地标>在3点，<地标>在6点，<地标>在9点；只挑一张场景图绑左右：在@图片N 的画面里，<地标>在<左／右>侧，其余场景图照旧只写朝向。不写俯视、顺时针这类会被读成运镜的词。没有 CLOCK 行的，照上面两小条写。
4. **主光一句**：从哪个地标照进来，有钟面的带上几点。明暗、影子方向，成片漂过再补。
5. **固定动线**（有的话）一句：用地标写起点、经过、终点（"从店门进来，绕过冰柜，走到柜台前"）；画面上的左右方向留给分镜。
6. **DRIFT-RISK 的真值**：只在需要模型照着画、图上又看不清时写，写成正面描述（"后墙上的价目牌是白底黑字"）。

建筑、光质、色彩处理、关键环境细节这四项交给场景图，场景段不复述；场景段写的是关系，以及本场相对图有变化的地方。

### 不写什么

- 图上看得见、本场戏又用不到的地标和陈设（方桌、价目牌之类），以及尺寸。
- 底稿记号：M0、FL/FR/BL/BR、W1…、ORIGIN、ENVELOPE、ANCHOR、LANDMARK 之类的字段名。
- 未绑定具体参考图或观察基准的“画面左／画面右／画面深处／画面近处”作为固定布局；当镜构图放分镜，固定手性按 §六绑定参照后表达。
- 版本号、"已锁定""逐字复制"之类的流程说明，以及【素材可见】等标签。
- 风险描述（"易糊成实墙"）；只写真值。
- 无依据的额外防御性排除（如擅加“没有第二个出口”“没有看台”）；用户明确要求或剧情必需事实首次写清，不受“踩过才加”限制。
- "几乎贴着""紧挨着正后方"这类没验证过的紧贴描述——写得太紧，模型会把两个实体合成一个新物体（铁律 0 的事故）。
- 英文词（locked、frame-left 之类）、秒数和时间码。
- 人物站位和动作（开场站位进【主体与关系】，写法二放【场景】最后；变动进事件脚本）；用"以@图片N 为准"去定构图（场景图只借方向、布局、陈设、材质和灯光）。

### 额外防御句：踩过才加（剧情必需事实首次写清，补句优先正面表达）

| 成片出过的问题 | 补一句 |
|---|---|
| 冒出第二个出口 | "店里只有临街那一扇门" |
| 环境自作主张，多出家具或房间 | "店里的陈设就是两张场景图里的这些" |
| 窗和冰柜换过边 | "在@图片3 的画面里，窗在左侧" |
| 招牌、价目牌的字走样 | 写出真值 |
| 不可能同框的地标挤进同一个画面 | 写在分镜里："本镜只看得到柜台和价目牌" |

### 示例

完整推导（底稿全文、每一处取舍、方位怎么验算）见 `references/translation-example.md`，**第一次做翻译时先读它**。下面是结果：

底稿的 M0 取自 @图片3（站在店门内侧正中，面朝柜台），以 M0 看"左＝窗墙，右＝冰柜墙"。翻成场景段（进【主体与关系】，本场各段逐字一致；逐图声明后补必要关系，字数服从信息完整）：

```
@图片3：面馆从店门朝柜台，借方向、布局、陈设、材质和灯光，不采用图中人物。
@图片4：同一面馆从柜台朝店门，借方向、布局、陈设、材质和灯光，不采用图中人物。
柜台正对店门，窗在一面侧墙，冰柜在对面侧墙靠门那头；主光从窗户照进来。
```

方桌、价目牌、柜台后的操作区都没写——图上看得见，本场戏也用不到；成片漂了再一句一句补。

轴线行（跟在场景段后面；本场对戏的始终是柜台后的店主和柜台前的顾客）：

```
轴线：店主和顾客之间；机位留在靠窗一侧，不越到冰柜那侧，在这一侧内照常运动。
```

分镜里的屏幕投影（节选）：

```
镜头3：顾客过肩拍店主。店主在画面左，顾客的肩背在画面右前景；店主身后是挂着价目牌的后墙。
镜头4：反打，店主过肩拍顾客。店主的肩背在画面左前景，顾客在画面右；顾客身后是店门那面墙。
```

底稿的"左＝窗墙"是 M0 的左，和分镜的画面左右是两回事，所以它只留在底稿里；场景段里窗在哪一侧交给两张图。

## 七、场景参考图的写法（按 sd25-pe）

- 素材的职责看它在本次生成里的实际用途，不看文件类别；一张图可以兼几个职责。只继承用户指定、且素材里确实有的属性，只排除用户明确不要的。
- 每张实际使用的场景图单独一句职责，**一行一张**，不用范围句。没附的图不写；附了不用的，按 sd25-pe 写进【未采用素材】。
- 场景图只采用拍摄方向、空间布局、陈设、材质和灯光；图里有人而本镜不用 → 写"不采用图中人物"（防多出人最直接的一句）。
- 场景图是参考，不是定死的画面：允许模型顺着图把画外延伸出去。分镜里不写"以@图片N 为准"去定构图，景别和人物位置在分镜里用文字写清。
- 首帧、尾帧图按 sd25-pe 的精确句式（`@图片N作为首帧。`），继承构图、人物位置、姿态、道具、机位方向——**不套用场景图那套"只采用……不采用……"**。
- **反打方向当成独立的地点素材**：最好有自己的场景图，和正面方向一起喂；墙面顶面材质、地面、纹理颗粒、调色、光质与正面一致，多角度的图先对母板统一曝光。该方向的必要排除事实按用户批准信息首次写清；额外防御句踩过且有证据才加。
- 本镜不出现的角色或道具，素材引用不要留在提示词里。

## 八、自检清单

**底稿**

- [ ] 首行声明了方位基准；MAIN VIEW 是实际值（站在哪、朝哪看，取自哪张图、按第几条选），不是照抄选项
- [ ] 全局锚唯一、整场不动、跨角度可辨认；或局部锚各有唯一身份、覆盖区、固定状态，共用 M0 和明确锚间关系，在各自覆盖区内可辨认；圆形或中心对称锚没被当成方向轴
- [ ] 每个地标行 AND 必填四项齐（身份＋方向＋尺度或拓扑＋证据）；开口按分档补齐；有正反面的写了朝向
- [ ] **多解检测**：试着只凭文字画出第二张不同的合法地图——画得出来就不合格
- [ ] **绕圈检测**：每个方位定义往上追，都追得到一个不依赖其他方位的源头
- [ ] **逐行唯一**：盖住其它行，只凭这一行能唯一摆出该地标；只有距离、"一端／一侧／附近"没指名的一律打回（被 M0 当作朝向目标的那个地标除外）
- [ ] 俯视草稿和文字互查：草稿上画得出的每条方位，文字里都有对应行
- [ ] 每个字段都是四态之一，没有留空和"以后补"；有【未知／阻断】时不锁定
- [ ] 必要排除事实有用户明示或已批准证据；额外防御性排除才要求踩过且有反打证据，不从“参考图里没有”推成不存在
- [ ] ENVELOPE 按顺序闭合；未知边界明确标出，没被 SET BOUNDARY 盖过去
- [ ] 单光逻辑，写了影子落点；SET BOUNDARY 在，并定义了"场内"
- [ ] 有文字招牌、强几何、镜面、水面时逐项点名；DRIFT-RISK 带基准真值
- [ ] 地图自身合理：门通向存在的空间、路径不穿墙穿桌、光影说得通、不与已定分镜冲突

**场景段**

- [ ] 没有底稿记号、版本号、状态、证据标签
- [ ] 固定布局没有使用未绑定参照的画面左右；非关键手性可交给场景图，关键手性首次绑定具体图或观察基准写清
- [ ] 每张场景图写了朝向和采用范围；几个朝向一起喂，并声明是同一个空间；首帧、尾帧图没被套用场景图写法
- [ ] 以两三句、120 字以内为软目标；超出时保留必需的逐图职责和关键关系，只删冗余，不因字数判废；没有没验证过的紧贴描述
- [ ] 用户要求或剧情必需的排除事实首次写清；额外防御性排除才按踩过且有依据补充，优先正面唯一句；没有风险描述
- [ ] 主光一句；没有英文词、秒数、时间码
- [ ] 有 CLOCK 行的：场景段有钟面一句和绑图的左右句，四个钟点和场景图一致
- [ ] 与当前锁定版底稿一致；本场各段文件里逐字相同

**轴线与逐镜**（核对分镜时）

- [ ] 轴线挂在当前对戏的两人上；机位侧用不在轴线上的地标命名，没写成固定机位
- [ ] 多人镜写了谁在画面左右，正反打两镜各写一次；运动方向写了起止地标
- [ ] 每镜的进入状态承接上一镜的退出状态
- [ ] 用户要求或剧情必需的人数、身份、道具数量、关键手性首次已写清；额外的可见范围限制、防重复句、身份强化与身高防漂移句才按“踩过才加”（见 `references/shot-checks.md`）
- [ ] 抽一个反打镜做定性投影核对（没有镜头参数时只做定性，或报缺口）

写完再对一遍 `references/pitfalls.md` 的常见错误表。

**480p 草稿能验什么**：人数、站位、方向、入退场、场景污染（由提示词决定，跨次生成比较稳）；**不能**据此判断相机的细微轨迹、细节表演和最终清晰度。

**选景本身就是空间稳定手段**：圆形场地、重复纹理、雾和尘的环境容忍几何漂移；著名地标、强透视建筑、连续反射、能核对的文字最惩罚漂移。

## 九、按症状排查

先按铁律 0：**先找是哪句招来的、能不能删，再考虑加。**

| 症状 | 先查 | 第一步 |
|---|---|---|
| 房间每镜重构、陈设乱跳 | 场景段、场景图 | 几个朝向的场景图是否一起喂；场景段各段是否逐字一致；底稿记号或"画面左右"有没有混进场景段。都没问题仍重构，再把漂掉的那条关系用一句补进场景段 |
| 冒出不该有的东西（多一面墙、实心板、第二扇门） | 铁律 0 | 找招来它的句子（紧贴描述、负断言、风险描述），先删；删了还冒，再写正面唯一句 |
| 两人换边、左右互换 | 分镜的屏幕投影 | 每镜写清谁在画面左右；正反打两镜各写一次 |
| 越轴、机位跨镜漂移 | 轴线行 | 轴线行跟在场景段后面，用地标命名机位在哪一侧 |
| 人物瞬移 | 进入／退出状态 | 每镜进入状态是否承接上一镜退出状态 |
| 反打对不上 | 场景图 | 反打方向有没有自己的场景图；没有见 §十 |
| 门内外接不上 | 门槛 | `references/shot-checks.md` 门槛戏 |
| 过肩镜多出人、同一人画两次 | 人数身份 | 先换机位（双人侧面、正面、干净的单人反打），再考虑正面人数句；见 `references/shot-checks.md` |
| 身高被拉平 | 人物 | 踩过才加真身高与相对锁；见 `references/shot-checks.md` |

## 十、缺反打母版

只报告缺口、列路线，不自行生图（生图走权限边界里的门禁）：① 用图像模型生成"同一间屋的另一个角"，对齐原图质感；② 生成一段空场景、镜头缓慢走过去的视频，截需要的角度再做质感增强（源项目后期摸出来的，更稳）；③ 其它平台的反打和多视图工具（3D Mode、五视图地点表），见 `references/other-engines.md`。
