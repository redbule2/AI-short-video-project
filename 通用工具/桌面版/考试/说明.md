## 和旧网站不一样的五处

1. 登录归桌面软件管。页面不存凭证，问服务器经 `window.desk.api`（壳子带上凭证，过期自己续）。
2. 没有侧边栏，改成顶上一排菜单。
3. 题图、答题图的地址是 `/uploads/exam/…`，壳子转到 video8.online 去拿。
4. 团队单独成一项：桌面软件左边菜单里「考试」「我的团队」是两项，开的是这同一份页面，各进各的首页（`#/exam/my`、`#/team`，见 `lib/routes.js` 的「起」），顶上那排菜单也各摆各的（`pages.ts` 的 `MENU`、`TEAM_MENU`）。
   - 「我的团队」（`/team`）：人人能进，一个部门一组、一页看全（2026-11-26 改的，原先左边部门树、右边成员）；建部门、调人、改职位只有团队负责人有。后台接口 `/api/collaboration/team`（new-video8-8 的 `CollaborationTeamController`）。
   - 照搬来的「协作中心」（`/collaboration`）在这一排里叫「账号管理」，只有负责人有：建账号；停用、重置密码、移除在每行后面的「管理」里。
5. 「消息」（`/chat`）也是左边菜单里单独一项，顶上不摆菜单（路由上 `bare`）。全员群和一对一私聊，能发字和图；负责人看不到别人的私聊。
   - 左边一列：全员群在最前，再是说过话的私聊（最近的在前），再是团队里还没说过话的人（写着职位），点名字就聊（11-26 用户要的，原先的「＋私聊」钮和挑人小窗删了）。
   - 新消息由壳子在后台收（`lib/chat.js` 等 `/api/collaboration/chat/updates`），经 `desk.onChat` 转给这一页；没看的条数写在左边菜单上，人不在眼前时右下角提醒。
   - 「我的团队」里每个人后面的「发消息」调 `desk.openChat`，跳到「消息」进那个私聊。老软件没有这两样：「发消息」不摆，「消息」页顶上说一句要升级。
   - 后台接口 `/api/collaboration/chat`（new-video8-8 的 `CollaborationChatController`），图存在服务器硬盘上，记录一直留着。

## 怎么打、怎么测

在 `通用工具\桌面版` 里：`pnpm run exam` 打到 `页面\考试`（不进 git，打安装包时会现打），`pnpm run exam:test` 跑测试。
这台电脑上装的软件直接用 `页面\考试`：`pnpm run exam`、`pnpm stage` 一跑就换了它。没定的改动在 `build\` 下的副本里打、试（例：`build\聊天试看`）。
本机服务只发 .html .js .css .json .svg .png：别引进字体和别的图片格式。
