## 每课怎么做（给 AI 看的）

文件夹 `第N课_标题`，里面：解说词.txt → 截图步骤.json → 画面.json → 图文.html，过程文件都在这一个文件夹里。

1. 截图：`node 截图.js 第N课_…`（用项目副本开的试验服务，别点正式项目）
   副本在 `%TEMP%\tut-sandbox`，在 `E:\AI短视频项目` 下开：`ANTOU_ROOT=C:/Users/li/AppData/Local/Temp/tut-sandbox ANTOU_TOOLS=E:/AI短视频项目/通用工具 ANTOU_PORT=8797 node .agents/skills/annotate-live/server.js`
2. 配音：`D:/Apps/VoxCPM2/venv/Scripts/python.exe 配音.py 第N课_…`（音色照 声音参考.wav，设置在 配音设置.json；每句念几遍挑最像的，记在 配音_记录.json）
   查像不像：`D:/Apps/VoxCPM2/venv/Scripts/python.exe 像不像.py 第N课_…`（和本人说同样长短的句子比）；差得多的句子 `配音.py 第N课_… 5 8 --几遍=6` 重念
3. 视频：Codex 自带的 Python 跑 `合成视频.py 第N课_…`
4. PDF：Codex 自带的 Python 跑 `出PDF.py 第N课_…`
