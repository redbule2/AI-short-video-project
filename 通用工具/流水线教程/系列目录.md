## 每课怎么做（给 AI 看的）

文件夹 `第N课_标题`，里面：解说词.txt → 截图步骤.json → 画面.json → 图文.html，过程文件都在这一个文件夹里。

1. 截图：`node 截图.js 第N课_…`（用项目副本开的试验服务，别点正式项目）
   副本在 `%TEMP%\tut-sandbox`，在 `E:\AI短视频项目` 下开：`ANTOU_ROOT=C:/Users/li/AppData/Local/Temp/tut-sandbox ANTOU_TOOLS=E:/AI短视频项目/通用工具 ANTOU_PORT=8797 node .agents/skills/annotate-live/server.js`
   副本里没有风格库：要截风格弹窗，临时在副本的 `通用工具\AI短片风格库` 建个目录联接指向正式的，截完删掉联接。点了会写数据的，先备份副本的 流水线.json，截完还原（「定下来」还会在副本的 历史记录\定稿的剧本 留一份，也删掉）。
   整页截完紧接着点开小窗（如「选人物、场景、道具」），会被缩回视口时关掉：中间先等 1 秒。
2. 配音：`python 配音.py 第N课_…`（哪个 Python 起都行，它会换成引擎自己的；跑之前去掉代理）
   显卡只有一块：配音前先 `rq.sh lease` 占住显卡，配完 `rq.sh release`（第 3 课起这样跑，和 Blender 出图错开）；`--private` 指临时文件夹，别指课的文件夹（排队记录会写进去）
   引擎照 配音设置.json 的「引擎」，现在是 IndexTTS2.5（第 2 课起）；`--引擎=VoxCPM2` 是第 1 课那个。音色照 声音参考.wav，每句念几遍挑最像的，记在 配音_记录.json。
   多音字在设置的「读音」里标，如 `"一行一": "一<行|HANG2>一"`；只对 IndexTTS2.5 有用。
   查像不像：`D:/Apps/VoxCPM2/venv/Scripts/python.exe 像不像.py 第N课_…`（和本人说同样长短的句子比）；差得多的句子 `配音.py 第N课_… 5 8 --几遍=6` 重念
3. 视频：Codex 自带的 Python 跑 `合成视频.py 第N课_…`
4. PDF：Codex 自带的 Python 跑 `出PDF.py 第N课_…`
