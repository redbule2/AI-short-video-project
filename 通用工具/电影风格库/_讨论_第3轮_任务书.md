# 写法规矩（我们实测得来的，务必遵守）

1. 「写进提示词」那几行只写画面上看得见的东西和拍法：色调、光、镜头、景深、质感、节奏。不写剧情、不写人物在干什么、不写导演名和片名。
2. 写成正面描述，不写「不要……」「没有……」「避免……」。我们实测过：Seedance 看到负面说法，反而会把那个东西画进来。要排除的东西放进「容易跑偏」，那一栏只给人看。
3. 光色基调只写色调、光质（硬光／柔光）、光比、颜色倾向；时间和主光方向由剧情决定，统一写成「〔时间、主光方向按剧情〕」。
4. 摄影一行只写全片不变的（摄影机或胶片感、焦段倾向、景深），景别和运镜写在「分镜常用拍法」里。
5. 规模和氛围写画面感（铺满画面、压得很低、望不到头），不写具体数字；焦段可以写一个大概范围。
6. 「写进提示词」每行不超过 60 个字。
