# 开发规范

改 `通用工具`、`.agents\skills` 里的代码时照下面这些条。

总的原则：极简，复用优先，代码简洁。

## 写代码

1. 同一功能只写一套：先找现成的，共用的放 公用。
2. 没用的代码，查过没人引用就当场删。
3. 流水线不装包、不打包，装好 Node 就能跑；桌面壳除外，照「桌面版」。
4. 刷新界面不许冲掉光标、滚动和没存的字。
5. 界面默认用 h()，不拼 HTML；不引整页框架，只引单用途小库。考试除外，照第 26 条。
6. 超 1500 行不添功能，新功能另起文件；修毛病可小改。

## 改代码时

7. 改共用代码先搜全部引用，一起改、一起测。
8. 改完跑测试；新逻辑必须配测试。测试文件统一放在 `通用工具\测试`。
9. 页面先在副本改、试验端口点通再换上。
10. 同一文件一次一个 AI 改；不自己提交，别人的改动要保住。

## 桌面版（2026-11-24）

桌面壳就是把流水线装进去的那一层：登录、窗口、更新、报错。

11. 桌面壳放 `通用工具\桌面版`，用 pnpm 装包、锁版本。
12. 壳只管登录、窗口、更新、报错，流水线照旧跑。
13. 壳的窗口只开本机服务和自带的外框页，外链交给系统浏览器。
14. 写死本机的路径，改成先看设置、再自动找。
15. 安装包只装 git 里登记过的工具文件。
16. 密钥、账号、登录凭证不进安装包，也不进仓库。
17. 升级只换工具，禁止动工作文件夹里的 `项目`。
18. 交给 AI 一律开看得见的新对话，开不了才给提示词复制。
19. 对话名照【项目简称 · 做什么 · 哪一样】。
20. 出错都记下，带报告号传回 video8.online；不带密钥。
21. 版本号只升不降；先提交、本机装一遍点通，问过用户再发。
22. 改 video8.online 后端，照 new-video8-8 自己的规矩。
23. 窗口不带系统边框和系统菜单；顶栏、按钮、菜单、设置都画在外框页。
24. 加模块在菜单路由加一行，各是一整页，不混进外框。
25. 外框颜色只走 `--k-` 变量，换皮肤只换这一组。
26. 考试、团队页是从 new-video8-8 照搬的 Vue 页面，放 `桌面版\考试`，单独打成一页；别处不引 Vue。
27. 考试页打出来不进 git，打安装包时现打；它的测试跟着源码，用 `pnpm run exam:test` 跑。
28. 页面要问 video8.online，一律经壳子（`window.desk.api`），凭证不进页面。
29. 注册必须填对一个已有团队，不能新建团队；软件、网站、后台一个规矩。
30. 安装包和后端分开发；改了两头的约定，先发后端，再发安装包。
31. 页面的颜色只走 `公用\皮肤.css` 的变量，不写死；纯黑除外。
32. 加皮肤：`routes.js` 的 SKINS、`外框.css`、`公用\皮肤.css` 各加一段，变量给全。
33. 纸面的底色只写 `--sheet`、`--white`、`--warm`；校样台靠它认纸面。
34. 登录服务器直连 IP、不加密（2026-11-26 定）；升级包都签名，软件验过才装；私钥只在发版电脑上。

## 公共资源页的空项目状态（2026-11-17）

- 风格库等公共资源页不应被“尚无创作项目”拦截，也不能为浏览公共资源自动创建占位项目或写业务文件。项目页继续按原有项目校验打开。
- 公共页面复用项目初始化时，须覆盖空项目、已有项目、服务离线和资源读取失败；除页面返回 200 外，还要核对初始化后实际生成了内容节点，不能把初始 HTML 可下载当作内容已显示。浏览器实测受环境限制时明确记录。

- 媒体库回归必须覆盖有样片和无样片两种状态。DOM 替身应支持页面实际使用的事件注册与触发，并验证点击后会建立视频播放器；不能因文字卡片测试通过，就认定样片入口已验证。
